---
title: "Dissolve"
description: Crossfade transition where the current image fades out as the next image fades in at the same time.
---
> Available on [Image](/docs/narraleaf-react/core/elements/image) changes and on [scene jumps](/docs/narraleaf-react/core/types/JumpConfig).

Dissolve from the current image to the next image.  
The current image will fade out, and the next image will fade in at the same time.

## Usage

```tsx
import { Dissolve } from "narraleaf-react";

image.char("image1.jpg", new Dissolve({ duration: 3000 }));
```

## Public Methods

### constructor

- `options: DissolveOptions`
  - `duration: number` - The duration of the transition in milliseconds
  - `easing?: TransformDefinitions.EasingDefinition` - The easing function, see [TransformDefinitions](/docs/narraleaf-react/core/types/TransformDefinitions).[EasingDefinition](/docs/narraleaf-react/core/types/EasingDefinition)
