---
title: "文本"
description: 用于舞台文本的 `Text` 元素，涵盖内容、字号、字体颜色与过渡动画
---
> 该类继承自 [Displayable](/zh/docs/narraleaf-react/core/elements/displayable)

`Text` 用于在舞台上显示文字

```ts
const t1 = new Text("之后，另一个故事发生了...", {
    position: CommonPosition.Positions.Center,
    fontColor: "#f00",
    fontSize: 20,
});

scene2.action([
    scene2.setBackground("#000", new Dissolve({ duration: 1000 })),
    t1.show({
        duration: 1000,
        ease: "easeInOut",
    }),

    Control.sleep(1000),

    t1.hide({
        duration: 1000,
        ease: "easeInOut",
    }),
]);
```

### setFontSize

<Steps>
<Step>

```ts
element.setFontSize(20, 1000, "easeInOut");
```

- `fontSize: number` - 字号（px）
- `duration?: number` - 过渡时长（ms）
- `easing?: TransformDefinitions.EasingDefinition` - 缓动函数，参见 [TransformDefinitions](/zh/docs/narraleaf-react/core/types/TransformDefinitions).[EasingDefinition](/zh/docs/narraleaf-react/core/types/EasingDefinition)
