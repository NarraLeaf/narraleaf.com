---
title: "服务"
description: 用于构建跨场景共享自定义逻辑的 `Service` 抽象类，涵盖动作、序列化与异步处理
---
Service 是一个抽象类，用于创建自定义操作与行为，或在多个场景之间共享自定义逻辑

使用时需要继承它，并实现全部抽象方法

```typescript
import {Service} from "narraleaf-react";
```

## 示例

以下是一个实现简单画廊服务的自定义服务示例

```typescript
type GalleryActions = {
    "add": [name: string]
};

class Gallery extends Service<GalleryActions> {
    // 自定义数据
    unlocked: string[] = [];

    constructor() {
        super();

        // 注册操作处理程序
        this.on("add", (ctx: ServiceHandlerCtx, name: string) => {
            console.log("添加", name);
            this.unlocked.push(name);
        })
    }

    /* 实现 serialize 和 deserialize 方法 */
    serialize(): Record<string, any> | null {
        return {
            unlocked: this.unlocked
        };
    }
    deserialize(data: Record<string, any>): void {
        this.unlocked = data.unlocked;
    }

    /* 自定义服务逻辑 */
    add(name: string) {
        // 触发操作
        return this.trigger("add", name);
    }
}
```

在游戏中使用该服务：

```typescript
const gallery = new Gallery();

myScene.action([
    gallery
        .add("image1")
        .add("image2")
        .add("image3"),
]);

```

## 创建自定义服务

### 实现服务

要实现服务，请继承 `Service` 类并实现抽象方法：

```typescript
class MyCustomService extends Service {
    /**
     * 将服务序列化为数据
     *
     * **注意**：数据必须是 JSON 可序列化的，如果不需要保存则返回 null
     */
    serialize(): Record<string, any> | null {
        return null;
    }

    /**
     * 将数据加载到服务中
     * @param data 从 toData 导出的数据
     */
    deserialize(data: Record<string, any>): void {
    }
}
```

### 注册操作

要注册操作，请使用 `on` 方法，所有注册都在构造函数中完成：

```typescript
class MyCustomService extends Service {
    constructor() {
        super();

        this.on("myAction", (ctx: ServiceHandlerCtx, ...args: any[]) => {
            // 自定义逻辑
        });
    }
}
```

关于 `ServiceHandlerCtx` 的详细说明见 [ServiceHandlerCtx](/zh/docs/narraleaf-react/core/types/ServiceHandlerCtx)

要启用类型检查，可以定义操作类型：

```typescript
type MyCustomActions = {
    "myAction": [arg0: string, arg1: number]
};

class MyCustomService extends Service<MyCustomActions> {
    constructor() {
        super();

        this.on("myAction", (ctx: ServiceHandlerCtx, arg0: string, arg1: number) => {
            // 自定义逻辑
        });
    }
}
```

### 异步操作 [#async-actions]

处理函数返回 promise 时，故事会停在这里等它结算，就像等一句对话那样；返回其他值时，故事立即继续。

```typescript
this.on("load", async (ctx: ServiceHandlerCtx, url: string) => {
    const response = await fetch(url, { signal: ctx.signal });
    const data = await response.json();
    if (ctx.signal.aborted) return; // 等待期间被取消：不要再动游戏

    this.data = data;
});
```

如果 promise 被拒绝，故事会停在这个操作上，并报告错误。

<Callout type="info">
    自 `1.3.0` 起，只要处理函数返回 promise 就会被等待。此前只有声明为 `async` 的函数才会被等待：直接返回 promise 的普通函数（如 `(ctx) => fetch(url)`）运行后故事不会等它；promise 被拒绝时故事会永远停在那里，而且不报告任何错误。
</Callout>

在故事等待它的这段时间里，处理函数会通过两种方式得知玩家的操作：游戏离开它时，它会被**取消**；玩家跳过时，它会被**催促**。

#### 取消 [#cancellation]

以下情况会取消一次运行：玩家回退到它之前、故事跳转离开它、它所在的 `Control.any` 被其他分支抢先完成，或者读取了存档。此时 `ctx.signal` 会被中止。它是标准的 `AbortSignal`，可以直接交给 `fetch` 等接受它的 API。

取消不能拒绝，也不会等待处理函数：信号触发时，游戏已经继续往下走了。**脚本有义务**停止仍在进行的工作（网络请求、定时器、动画等），并撤回已经产生的副作用，以确保回退后再次执行同一操作时得到完全相同的结果。每次 `await` 之后，先检查 `ctx.signal.aborted` 再去动游戏。被取消的运行最后抛出的拒绝（例如 `fetch` 的 `AbortError`）不会被报告。

#### 跳过 [#skipping]

玩家跳过时（单按或长按跳过键，或宿主调用了 [skipDialog](/zh/docs/narraleaf-react/core/game/live-game#skipdialog) 或 [fastForward](/zh/docs/narraleaf-react/core/game/live-game#fastforward)），正在让故事等待的处理函数会通过 `ctx.skip` 收到催促。被催促并不会结束它：被跳过意味着什么，由处理函数自己决定。

| 回应 | 做法 | 长按跳过键 | `fastForward` |
| --- | --- | --- | --- |
| **立即完成** | 在 `ctx.skip.onRequest` 里把正在做的事设为最终状态，然后返回 | 继续往下 | 继续往下 |
| **不理会** | 什么都不做。`1.3.0` 之前写的处理函数都属于这一种 | 等待处理函数 | 最多等待 `stepTimeout`，然后报告 `"stalled"` |
| **拒绝** | `ctx.skip.refuse(message?)` | 等待处理函数 | 立即停下，报告 `"refused"` |

```typescript
type MinigameActions = {
    countdown: [seconds: number];
    fishing: [];
};

class Minigames extends Service<MinigameActions, null> {
    constructor() {
        super();

        // 立即完成：跳过会让倒计时马上结束。
        this.on("countdown", async (ctx, seconds) => {
            await new Promise<void>(resolve => {
                const timer = setTimeout(resolve, seconds * 1000);
                ctx.skip.onRequest(() => {
                    clearTimeout(timer);
                    resolve();
                });
                ctx.signal.addEventListener("abort", () => clearTimeout(timer));
            });
        });

        // 拒绝：快进无法替玩家玩小游戏，所以停在这里。
        this.on("fishing", async (ctx) => {
            ctx.skip.refuse("waiting for the fishing minigame");
            await playFishing(ctx.signal);
        });
    }

    serialize() {
        return null;
    }

    deserialize() {
    }
}
```

- `onRequest` 在玩家第一次跳过时调用一次，在第一次以跳过模式跳过（`request.forced`）时再调用一次。这与对话的区分一致：单按跳过键会把一句话显示到下一个停顿处，长按则连停顿一起跳过。跳过模式下的每次重复都不会再调用它。
- `refuse` 返回一个用于撤回拒绝的函数。拒绝可以叠加：全部撤回后，这个操作才能再被跳过。消息是给人看的，会写进日志，并由 `fastForward` 返回；引擎不会根据它做任何判断。
- `ctx.skip.fastForwarding` 表示游戏当前是否正在快进，处理函数可以在开始时检查它，直接进入最终状态。
- 催促是广播，和舞台上其他东西收到的一样：在 `Control.all` 分支或异步分支里运行的处理函数，也会在玩家每次跳过时收到。点击舞台不算催促。
- 只有返回 promise 的处理函数才会收到催促。同步处理函数在玩家能催促之前就已经执行完了。

全部成员参见 [ServiceHandlerCtx](/zh/docs/narraleaf-react/core/types/ServiceHandlerCtx)。

<Callout type="info">
    `ctx.signal` 和 `ctx.skip` 自 `1.3.0` 起可用。与 `ctx.signal` 在相同时机触发的 `ctx.onAbort` 已弃用。
</Callout>

### 触发操作

要触发操作，请使用 `trigger` 方法：

```typescript
const service = new MyCustomService();

scene.action([
    service.trigger("myAction", "foo", 123)
]);
```

也可以把操作包装进自定义方法：

```typescript
class MyCustomService extends Service<MyCustomActions> {
    myAction(arg0: string, arg1: number) {
        return this.trigger("myAction", arg0, arg1);
    }
}

const service = new MyCustomService();

scene.action([
    service.myAction("foo", 123),

    service
        .myAction("foo", 123)  // 操作被包装并可链式调用
        .myAction("bar", 456), // 游戏将自动管理链式行为
]);
```

### 访问服务

创建服务后，要在游戏中注册它：

```typescript
const story = new Story(/* ... */);
story.registerService("gallery", gallery);
```

之后就可以通过 `ctx` 访问服务：

```tsx
// 例如，在组件中
const game = useGame();
const liveGame = game.getLiveGame();

const gallery = liveGame.story?.getService<Gallery>("gallery");

return (
    {gallery && gallery.unlocked.map((name) => (
        <div key={name}>{name}</div>
    ))}
);
```

## 公共方法

### on\<K extends StringKeyOf\<Content\>\>

<Steps>
<Step>

注册一个操作处理程序

```typescript
type MyCustomActions = {
    "myAction": [arg0: string, arg1: number]
};

class MyCustomService extends Service<MyCustomActions> {
    constructor() {
        super();

        this.on<"myAction">("myAction", (ctx: ServiceHandlerCtx, arg0: string, arg1: number) => {
            // 自定义逻辑
        });
    }
}
```

- `key: K` - 操作键
- `handler: ServiceHandler<Content[K]>` - 详细说明参见 [ServiceHandlerCtx](/zh/docs/narraleaf-react/core/types/ServiceHandlerCtx)
- 返回 `this`
</Step>
</Steps>
