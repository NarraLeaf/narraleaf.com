`Video` 用于在舞台上播放视频，占用整个舞台。

```typescript
const video = new Video({
    src: "https://example.com/video.mp4",
    muted: true,
});

scene.action([
    video
        .show()
        .play()
        .hide(),
]);
```

<Step>

## 链式方法

### show

<Steps>
<Step>

显示视频。

```typescript
video.show();
```
</Step>
</Steps>

### hide

<Steps>
<Step>

隐藏视频。
</Step>
</Steps>

### play

<Steps>
<Step>

播放视频并等待完成。

```typescript
video.play();
```
</Step>
</Steps>

### pause

<Steps>
<Step>

暂停视频，保留当前播放位置。

```typescript
video.pause();
```
</Step>
</Steps>

### resume

<Steps>
<Step>

从当前位置继续播放。与 `play` 不同，不等待播放结束。

```typescript
video.resume();
```
</Step>
</Steps>

### stop

<Steps>
<Step>

停止视频：暂停播放，结束任何等待中的 `play()`，让剧本继续推进。

```typescript
video.stop();
```
</Step>
</Steps>

### seek

<Steps>
<Step>

- `time: number` - 跳转目标时间（秒）

```typescript
video.seek(3);
```
</Step>
</Steps>
