---
title: "图层"
---
> 此类继承自 [Displayble](/zh/docs/narraleaf-react/core/elements/displayable)

你可以使用 `Layer` 类来管理可显示元素的图层

## 用法

```typescript
import {Layer} from "narraleaf-react";
```

```typescript
const layer = new Layer("图层名称", {
    zIndex: 1
});

const scene = new Scene("带有图层的场景", {
    layers: [layer] // 将图层注册到场景中
});

const image = new Image({ /* ... */}).useLayer(layer); // 将图像链接到图层
```

```typescript
layer.opacity(0.5, 1000, "linear"); // 更改图层的不透明度，所有链接到图层的元素都会受到影响
```

<Callout type="info">
    **自 `0.26.0` 起，图层不会把自己的姿态带出声明它的那个场景。** 离开场景现在会把该场景摆上舞台的图层还原到配置的 z-index 与姿态，而不只是还原站在图层上的可显示元素；`newGame()` 同样如此。在此之前，被移开或淡出的图层会在之后的每个场景里都保持那个样子。故事[镜头](/zh/docs/narraleaf-react/core/elements/camera)是刻意的例外：一个故事只拥有一个镜头，而它要跨场景切换地为舞台取景
</Callout>

## 链式方法

### setZIndex

<Steps>
<Step>

设置图层的 z-index。z-index 越高，图层越靠前

- `zIndex: number` - 图层的 z-index
</Step>
</Steps>

## 公共方法

### constructor

<Steps>
<Step>

- `name?: string` - 图层的名称
- `config?: Partial<ILayerUserConfig>` - 图层的配置，参见 [ILayerUserConfig](/zh/docs/narraleaf-react/core/types/ILayerUserConfig)
</Step>
</Steps>

### include

<Steps>
<Step>

将可显示元素包含到图层中

- `elements: (Image | Text)[] | Image | Text` - 要包含的可显示元素，例如 [Image](/zh/docs/narraleaf-react/core/elements/image)、[Text](/zh/docs/narraleaf-react/core/elements/text)
- 返回 `this`
</Step>
</Steps>
