---
title: "TransformersMap"
description: 可动画属性名（位置、透明度、缩放等）到 `transform` 接受取值类型的映射
---
```typescript
type TransformersMap = {
    "position": RawPosition | IPosition;
    "opacity": number;
    "scale": number;
    "rotation": number;
    "display": string;
    "src": string;
    "backgroundColor": {
        url: string;
    } | color | null | undefined | StaticImageData;
    "backgroundOpacity": number;
    "transform": TransformDefinitions.Types;
};
```
