title: "color"
description: "NarraLeaf-React 全体で受け付けられる `Color` 型：CSS の名前付きカラー、`{r,g,b,a}` オブジェクト、または16進数文字列"
---
Color は NarraLeaf-React がサポートするすべての色を定義します。

Color は [NamedColor](https://developer.mozilla.org/en-US/docs/Web/CSS/named-color)、`r`、`g`、`b`（および省略可能な `a`）プロパティを持つオブジェクト、または16進数カラーのいずれかです。

type RGBAColor = {
    r: number;
    g: number;
    b: number;
    a?: number;
};
