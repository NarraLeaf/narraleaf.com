---
title: "NotificationToken"
description: "The handle returned when showing a notification: a `cancel()` method plus a `promise` that resolves once the notification is consumed."
---
```ts
interface NotificationToken extends LiveGameEventToken {
    promise: Promise<void>;
}
```

For `LiveGameEventToken`, see [LiveGameEventToken](/docs/narraleaf-react/core/types/LiveGameEventToken)

## promise

The promise that will be resolved when the notification is consumed (finished)
