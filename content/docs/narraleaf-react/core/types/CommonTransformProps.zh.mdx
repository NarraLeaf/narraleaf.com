---
title: "TransformDefinitions.CommonTransformProps"
description: 每个变换定义共有的持续时间、缓动、延迟与同步选项
---
```typescript
type CommonTransformProps = {
    duration: number;
    ease: EasingDefinition;
    delay: number;
} & {
    sync: boolean;
};
```

## duration

过渡的持续时间，以毫秒为单位

## ease

过渡的缓动函数，参见 [EasingDefinition](/zh/docs/narraleaf-react/core/types/EasingDefinition)

## delay

过渡的延迟时间，以毫秒为单位

## sync

为 `true` 时，当前步骤完成后才执行下一步
