---
title: "KeyBindingValue"
description: "`KeyMap.setKeyBinding` が受け付ける値の型：単一のキー、キー配列、または割り当てを解除する `null`"
---
`KeyBindingValue` は、特定の `KeyBindingType` に関連付けられたキーを表すユニオン型です。

```typescript
type KeyBindingValue = WebKeyboardKey[] | WebKeyboardKey | null;
```

- `WebKeyboardKey` は `string` のエイリアスです（大文字・小文字は区別されません）。有効な値については [MDN key values](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/key/Key_Values) の一覧を参照してください。
- `null` は**バインディングなし**を示します（キーが割り当てられるまでそのアクションは無効になります）。

## 例

### 単一キー

```typescript
game.keyMap.setKeyBinding(KeyBindingType.skipAction, " "); // スペースキー
```

### 複数キー

```typescript
game.keyMap.setKeyBinding(KeyBindingType.skipAction, ["Control", "F3"]);
```

### バインディングの削除

```typescript
game.keyMap.setKeyBinding(KeyBindingType.skipAction, null);
```

参照：[KeyBindingType](/ja/docs/narraleaf-react/core/types/KeyBindingType)、[KeyMap](/ja/docs/narraleaf-react/core/game/key-map)。
