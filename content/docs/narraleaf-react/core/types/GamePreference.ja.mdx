---
title: "GamePreference"
description: 自動前進、スキップ、ダイアログ速度、テキスト速度、各種オーディオ音量など、ゲームの環境設定として永続化されるプレイヤー操作可能な設定
---
```typescript
type GamePreference = {
    /**
     * true の場合、現在の文が終わったら自動的に次の文へ進みます
     * @default false
     */
    autoForward: boolean;
    /**
     * true の場合、プレイヤーはダイアログをスキップできます
     * @default true
     */
    skip: boolean;
    /**
     * true の場合、ダイアログを表示します
     * @default true
     */
    showDialog: boolean;
    /**
     * ダイアログ速度の倍率
     * 
     * ダイアログ速度は次に適用されます。
     * - テキスト速度
     * - 自動前進の遅延
     * @default 1.0
     */
    gameSpeed: number;
    /**
     * 1 秒あたりの文字数で表したテキストエフェクトの速度
     * @default 10
     */
    cps: number;
    /**
     * ボイスの音量
     * @default 1
     */
    voiceVolume: number;
    /**
     * フェードモードでボイスを終了する際のフェード時間（ミリ秒）
     * @default 0
     */
    voiceFadeDuration: number;
    /**
     * 文末でのボイス再生の終了方法
     * @default "stop"
     */
    voiceEndMode: "fade" | "stop" | "none";
    /**
     * 背景音楽の音量
     * @default 1
     */
    bgmVolume: number;
    /**
     * 効果音の音量
     * @default 1
     */
    soundVolume: number;
    /**
     * 全体の音量
     * @default 1
     */
    globalVolume: number;
    /**
     * ゲームがアクションのスキップを開始するまでの遅延時間（ミリ秒）
     *
     * プレイヤーがスキップキーを押したときに、ゲームが速すぎるスピードでアクションをスキップしないように
     * するためのものです。
     *
     * 0 に設定すると、スキップキーを押した瞬間に即座にスキップします
     * @default 500
     */
    skipDelay: number;
    /**
     * 各スキップアクションの間隔（ミリ秒）
     * 例: 100 ミリ秒は、1 秒間に 10 個のアクションをスキップできることを意味します
     * 値が大きいほどスキップは遅くなります
     * @default 100
     */
    skipInterval: number;
};
```

## autoForward

ゲームを自動的に進めるかどうか。

有効にすると、現在の文が完了したときにゲームは自動的に次の文へ進みます。

ゲームは [GameConfig.elements.say.autoForwardDelay](/ja/docs/narraleaf-react/core/types/GameConfig) に指定した時間だけ待ってから進みます。

行は、テキストの表示が完了し、**かつ**ボイスの再生が終わった時点で「完了」とみなされます。0.24.0 以降、ボイス付きの行はクリップが終わるのを待ってから遅延のカウントを始めるため、自動モードが文の途中で進んでしまうことはありません。ボイスがない行、またはすでにクリップが終わっている行の挙動は、以前と変わりません。

## skip

有効にすると、プレイヤーは [GameConfig.elements.say.nextKey](/ja/docs/narraleaf-react/core/types/GameConfig) を押すことで現在の文をスキップできます。

## showDialog

ダイアログボックスを表示するかどうか。

## gameSpeed

ダイアログ速度の倍率。既定値は 1.0 です。

ダイアログ速度は次に適用されます。

- テキスト速度
- 自動前進の遅延

## cps

1 秒あたりの文字数で表したテキストエフェクトの速度。

## voiceVolume

ボイスの音量。

## voiceFadeDuration

`voiceEndMode` が `fade` に設定されている場合に使用される、フェードアウトの時間（ミリ秒）。

次の文が始まる前にボイスをどれだけの時間かけてフェードアウトさせるかを制御します。

## voiceEndMode

文が完了したときのボイス再生の終了方法を制御します。

- `fade`: `voiceFadeDuration` ミリ秒かけてボイスをフェードアウトします。
- `stop`: 即座に再生を停止します（既定）。
- `none`: 文が終わった後もボイスを再生し続けます。ボイスは自然に終わるか、次に**ボイス付きの**行が始まるまで、どちらか早い方まで再生されます。ボイスのない行は、まだ再生中のクリップを止めずにそのまま通過します。2 つのボイスが同時に再生されることはありません（0.24.1 より前は、この末尾のクリップを止める仕組みがなかったため、ボイス付きの対話を連続して進めると重なって再生されていました）。

滑らかに切り替えたい場合は、`voiceFadeDuration` を `fade` と組み合わせて使用します。

## bgmVolume

背景音楽の音量。

## soundVolume

効果音の音量。

## globalVolume

全体の音量。ゲーム内のすべてのオーディオに影響する、独立した倍率です。

## skipDelay

ゲームがアクションのスキップを開始するまでの遅延時間（ミリ秒）。

プレイヤーがスキップキーを押したときに、ゲームが速すぎるスピードでアクションをスキップしないようにするためのものです。

0 に設定すると、スキップキーを押した瞬間に即座にスキップします。

## skipInterval

各スキップアクションの間隔（ミリ秒）。

たとえば、100 ミリ秒はプレイヤーが 1 秒間に 10 個のアクションをスキップできることを意味します。値が大きいほどスキップは遅くなります。
