---
title: "GameHistoryAction"
description: 历史记录中单条动作的 token、动作本体与是否待定的标记
---
```typescript
type GameHistoryAction = {
    token: string;
    action: Action;
    isPending?: boolean;
};
```

`GameHistoryAction` 类型表示游戏历史中的单个动作。它包含：
- `token`: 动作的唯一标识符
- `action`: 实际执行的动作
- `isPending`: 是否正在执行。例如，菜单弹出但用户尚未做出选择时，动作处于挂起状态
