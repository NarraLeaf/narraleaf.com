ドキュメントの他の箇所で名前が出てくる設定オブジェクト、ユニオン型、ヘルパー型には、それぞれ専用のページがあります。各ページでは型の構造、各フィールドの意味、そしてどの API が受け取るのかを説明します。

以下のグループは、その型がどの領域のために定義されたかで分けています。複数の箇所で使われる型も、定義された領域に一度だけ掲載します。
