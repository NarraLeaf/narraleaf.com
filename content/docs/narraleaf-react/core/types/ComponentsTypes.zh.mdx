---
title: "ComponentsTypes"
description: 可通过 Game.configure 覆盖的对话、菜单、通知与 NVL 组件插槽映射
---
```typescript
type ComponentsTypes = {
    say: SayComponent;
    menu: MenuComponent;
    notification: NotificationComponent;
    nvlDialog: NvlDialogComponent;
};
```

游戏可以用自己的组件替换的全部槽位，通过 [`Game.configure`](/zh/docs/narraleaf-react/core/game/game) 传入。

## say

参见 [SayComponent](/zh/docs/narraleaf-react/core/types/SayComponent)

## menu

参见 [MenuComponent](/zh/docs/narraleaf-react/core/types/MenuComponent)

## notification

`Components<INotificationsProps>` —— 绘制游戏通知的组件。参见 [Notification](/zh/docs/narraleaf-react/player/notification)。

## nvlDialog

`Components<INvlContainerProps>` —— 绘制 NVL 模式的组件。参见 [NVL Container](/zh/docs/narraleaf-react/player/nvl-container)。
