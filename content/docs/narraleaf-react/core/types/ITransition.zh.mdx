过渡效果用于在更换场景的图像或背景时，为 Image 或 Scene 播放动画

```ts
interface ITransition<T extends ElementProp = Record<string, any>> {
    events: EventDispatcher<EventTypes<[T[]]>>;
    controller: AnimationPlaybackControls | null | undefined;
    start(onComplete?: () => void): void;
    toElementProps(): T[];
    copy(): ITransition<T>;
}
```

## 公共方法

### start

启动过渡效果

- `onComplete?: () => void` - 过渡完成时调用的回调函数

> 如果你继承了 `Base` 类，可以调用 `Base.prototype.requestAnimation` 来请求动画
> 
> ```ts
> super.requestAnimation({
>     start: 0,
>     end: 1,
>     duration: this.duration
> }, {
>     onComplete,
>     onUpdate: (value) => {
>         this.state.opacity = value;
>     }
> });
> ```

### toElementProps

返回 ElementProps 数组，每个元素表示一个图像元素的属性

[Dissolve.ts](https://github.com/NarraLeaf/narraleaf-react/blob/master/src/game/nlcore/elements/transition/transitions/image/dissolve.ts) 示例：

```ts
public toElementProps(): (DissolveProps & ElementProp)[] {
    return [
        { // for the first image
            style: {opacity: this.state.opacity},
        },
        { // for the second image
            style: {opacity: 1 - this.state.opacity},
            src: this.src,
        }
    ];
}
```

溶解图像时，实际会同时渲染两张图像：第一张的不透明度为 `this.state.opacity`，第二张为 `1 - this.state.opacity`，于是第一张逐渐消失，第二张逐渐出现

### copy

返回过渡效果的一个新实例

## 公共属性

### events

无需重写此属性

### controller

无需重写此属性

## 自定义过渡

你可以实现 [ITransition](https://github.com/NarraLeaf/narraleaf-react/blob/master/src/game/nlcore/elements/transition/type.ts) 接口并继承一个过渡基类（如 [ImageTransition](https://github.com/NarraLeaf/narraleaf-react/blob/master/src/game/nlcore/elements/transition/transitions/image/imageTransition.ts)），创建自己的过渡效果

[Dissolve.ts](https://github.com/NarraLeaf/narraleaf-react/blob/master/src/game/nlcore/elements/transition/transitions/image/dissolve.ts) 示例：

```ts
import {Base, ITransition} from 'narraleaf-react';

type DissolveProps = {
    style: {
        opacity: number;
    },
    src?: string;
};

/**
 * @class Dissolve
 * @implements ITransition
 * @extends Base
 * @description Dissolve transition effect
 */
export class Dissolve extends Base<DissolveProps> implements ITransition<DissolveProps> {
    private duration: number;
    private opacity = 0;
    private src: string | undefined;

    /**
     * Image will dissolve from one image to another
     */
    constructor(duration: number = 1000, src?: string) {
        super();
        this.duration = duration;
        if (src) {
            this.src = src;
        }
    }

    setSrc(src: string) {
        this.src = src;
    }

    public start(onComplete?: () => void): void {
        this.state.opacity = 1;

        this.requestAnimation({
            start: 1,
            end: 0,
            duration: this.duration
        }, {
            onComplete,
            onUpdate: (value) => {
                this.opacity = value;
            }
        });
    }

    public toElementProps() {
        return [
            {
                style: {opacity: this.opacity},
            },
            {
                style: {opacity: 1 - this.opacity},
                src: this.src,
            }
        ];
    }

    copy(): ITransition<DissolveProps> {
        return new Dissolve(this.duration, this.src);
    }
}
```
