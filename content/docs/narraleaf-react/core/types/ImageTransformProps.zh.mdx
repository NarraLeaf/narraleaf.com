---
title: "ImageTransformProps"
description: 图像变换在透明度、缩放、旋转与位置之间进行的属性定义
---
```ts
type ImageTransformProps = {
    opacity: number;
    scale: number;
    rotation: number;
    display: boolean;
} & {
    position: RawPosition | IPosition;
};
```

## opacity

图片的不透明度，取值范围为 0 到 1

## scale

图片的缩放比例，取值应大于 0

## rotation

图片的旋转角度，以度为单位

## display

请勿使用此属性

## position

图片的位置，参见 [IPosition](/zh/docs/narraleaf-react/core/types/IPosition)

> **注意：** 可以直接使用原始位置对象作为快捷写法，不必新建 IPosition 实例
> ```ts
> image.transform(new Transform<TransformDefinitions.ImageTransformProps>([
>     {
>         props: {
>             position: {
>                 x: 100,
>                 y: 100
>             }
>         },
>         options: {}
>     }
> ], {}));
> ```
