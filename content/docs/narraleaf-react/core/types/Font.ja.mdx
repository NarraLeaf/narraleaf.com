---
title: "Font"
description: テキストに適用される斜体、太字、フォントファミリー、フォントサイズの各オプション
---
```ts
type Font = {
    italic?: boolean;
    bold?: boolean;
    fontFamily?: React.CSSProperties["fontFamily"];
    fontSize?: React.CSSProperties["fontSize"];
};
```

## italic

テキストが斜体かどうかを表します。

## bold

テキストが太字かどうかを表します。

## fontFamily

[fontFamily](https://developer.mozilla.org/en-US/docs/Web/CSS/font-family) を参照してください。

## fontSize

[fontSize](https://developer.mozilla.org/en-US/docs/Web/CSS/font-size) を参照してください。
