---
title: "KeyBindingType"
---
`KeyBindingType` 是 `KeyMap` 中预定义按键绑定的动作类型枚举。

```typescript
enum KeyBindingType {
    skipAction = "skipAction",
    nextAction = "nextAction",
}
```

## 枚举成员

### skipAction

<Steps>
<Step>

按下绑定键时，游戏前进到**下一句**。

- **默认绑定：** `[" "]`（空格键）

<Callout type="info">
    **自 `0.26.0` 起，点击舞台与按一下这个键做同一件事**：把正在打字的一行补完，并推进已经打完的一行。在此之前只有这个键能推进 ADV 对话 —— 点击会被识别并发出事件，却没有任何东西响应，因此靠点击阅读的玩家根本无法推进游戏。NVL 对话一直同时监听这两者。

    按住该键仍然会强制一路跑完场景；点击从不如此，因为点击的玩家要的是一行，而不是这一场景的其余部分。
</Callout>
</Step>
</Steps>

### nextAction

<Steps>
<Step>

按下绑定键时，游戏**跳过当前动作**。

- **默认绑定：** `["Control"]`
</Step>
</Steps>

## 示例

```typescript
// 将跳过动作的按键改为 F3
game.keyMap.setKeyBinding(KeyBindingType.skipAction, "F3");
// 同时绑定 Control 和 F3 到 skipAction
game.keyMap.setKeyBinding(KeyBindingType.skipAction, ["Control", "F3"]);
// 移除绑定
game.keyMap.setKeyBinding(KeyBindingType.skipAction, null);
```

参见：[KeyBindingValue](/zh/docs/narraleaf-react/core/types/KeyBindingValue)、[KeyMap](/zh/docs/narraleaf-react/core/game/key-map)。
