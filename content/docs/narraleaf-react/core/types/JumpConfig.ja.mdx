---
title: "JumpConfig"
description: Scene.jumpTo の遷移オプションと returnable オプション。ステージの遷移や、呼び出し元シーンを一時停止するかどうかを制御する
---
```ts
type JumpConfig = {
    transition: Transition;
    returnable: boolean;
};
```

## transition

[`Scene.jumpTo`](/ja/docs/narraleaf-react/core/elements/scene#jumpto) がシーンを切り替える際に再生される遷移です。

`0.27.0` 以降、これは背景だけでなく、ステージ全体を横断して再生されます。ジャンプの間、両方のシーンが画面上に存在します。離脱するシーンが遷移の離脱側半分を、進入するシーンが進入側半分を担うため、スプライト、テキスト、その他すべてのレイヤーがこれに参加します。

```typescript
scene.jumpTo(nextScene, new Reveal({duration: 800, pattern: Mask.iris()}));
```

遷移の一覧については [Transition](/ja/docs/narraleaf-react/core/animation/transition) を参照してください。

遷移がステージ全体を覆うことから、次の 2 点が導かれます。

- そのジオメトリは背景画像ではなくステージです。`Push` はステージの幅ぶん移動し、`Mask` はステージの矩形全体に重ねられます。意図的にステージより小さくした背景は、掃われる対象そのものではなく、他のすべてと一緒に掃われる側になります。
- ダイアログボックスはこれに参加しません。ステージの外にレンダリングされ、シーンが終わった時点ですでに消えています。

このフィールドの型は `ImageTransition` ではなく `Transition` です。組み込みのすべての遷移はどちらも満たすため、`0.27.0` より前に書かれた呼び出しは影響を受けません。

スキップキーでこの遷移をスキップできるかどうかは [`allowSkipSceneTransition`](/ja/docs/narraleaf-react/core/types/GameConfig) が決めます。

## returnable

対象のシーンのアクションが尽きたときに、完全に離れるのではなくここへ戻ってきます。`0.39.0` で追加され、既定値は `false` です。これは `jumpTo` がこれまで常に行ってきた、普通のジャンプにあたります。

```typescript
scene.jumpTo(storeroom, {returnable: true});
```

`true` の場合、呼び出し元のシーンはアンロードされるのではなく**一時停止**します。ステージ、スプライト、レイヤー、シーンローカル変数はそのまま保持され、背景音楽は一時停止し、対象のシーンが画面に表示されている間は描画を止めます。対象のシーンのアクションが尽きると呼び出しは戻ります。対象のシーンはアンロードされ、呼び出し元のシーンは再び描画を再開し、その音楽は一時停止した位置から再生を再開し、ジャンプの後ろにあったアクションが実行されます。

一時停止するのはそのシーン自身の背景音楽だけです。それ以外の音声はシーンではなくストーリーに属しており、普通のジャンプをまたぐときとまったく同じように、呼び出しをまたいでも再生され続けます。

すでに呼び出しスタックにあるシーンを呼び出すことはできません。1 つの `Scene` はステージ上の 1 つの位置と 1 組のシーンローカル変数しか持てないため、同時に 2 か所に存在することはできません。すでにスタックにあるシーンを呼び出すとエラーになります。呼び出しの連鎖が同時に一時停止しておけるシーンの数は [`maxSceneCallDepth`](/ja/docs/narraleaf-react/core/types/GameConfig) で決まり、既定値は `8` です。
