---
title: "RawPosition"
description: API 全体で受け付けられる位置の形状：共通プリセット、座標のペア、整列のペアのいずれかで、混在はしません
---
```typescript
type RawPosition = CommonPositionType
    | (Partial<Coord2DPosition> & { xalign?: never; yalign?: never })
    | (Partial<AlignPosition> & { x?: never; y?: never });
```

詳細については、以下を参照してください：
- [CommonPositionType](/ja/docs/narraleaf-react/core/types/CommonPositionType)
- [Coord2DPosition](/ja/docs/narraleaf-react/core/types/Coord2DPosition)
- [AlignPosition](/ja/docs/narraleaf-react/core/types/AlignPosition)


## 例

### 例 1

```typescript
const position: RawPosition = {
    xalign: 0.5, // x: 50%
    yalign: 0.3, // y: 30%
};
```

### 例 2

```typescript
const position = {
    x: 100, // x: 100px
    y: "50%", // y: 50%
};
```

### 例 3

```typescript
const position = CommonPosition.Positions.Left; // x: 33.3%, y: 50%
```

### 例 4

```typescript
const position = {
    xalign: 0.5, // x: 50% + 10px
    yalign: 0.3, // y: 30% + 20px
    xoffset: 10,
    yoffset: 20,
};
```
