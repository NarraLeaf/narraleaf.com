<Callout type="warning">
    已废弃的接口，请改用 [ITextUserConfig](/zh/docs/narraleaf-react/core/types/ITextUserConfig)
</Callout>

```typescript
type TextConfig = {
    alignX: "left" | "center" | "right";
    alignY: "top" | "center" | "bottom";
    className?: string;
    fontSize: number;
    fontColor: color;
    display: boolean;
    text: string;
} & CommonDisplayable;
```

关于 CommonDisplayable，参见 [CommonDisplayableConfig](/zh/docs/narraleaf-react/core/types/CommonDisplayableConfig)
关于 color，参见 [color](/zh/docs/narraleaf-react/core/types/color)

## alignX

- Type: `"left" | "center" | "right"`

文本的水平对齐方式

## alignY

- Type: `"top" | "center" | "bottom"`

文本的垂直对齐方式

## className

- Type: `string`

文本的类名

## fontSize

- Type: `number`

文本的字号

## fontColor

- Type: [color](/zh/docs/narraleaf-react/core/types/color)

文本的字体颜色

## display

请勿使用此字段

## text

- Type: `string`

初始文本内容
