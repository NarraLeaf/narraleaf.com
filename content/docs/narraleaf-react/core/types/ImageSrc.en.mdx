---
title: "ImageSrc"
description: The union of a URL string or a loader-generated `StaticImageData` object accepted as an image source.
---
```typescript
export type ImageSrc = string | StaticImageData;
```

StaticImageData is a src that is generated by image loader

```typescript
import img1 from 'path/to/image1.png';

const src: StaticImageData = img1;
```
