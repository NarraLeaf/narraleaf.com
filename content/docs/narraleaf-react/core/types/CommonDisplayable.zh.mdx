---
title: "CommonDisplayable"
---
```typescript
type CommonDisplayable = {
    scale?: number;
    rotation?: number;
    position?: RawPosition | IPosition;
    opacity?: number;
    alt?: string;
};
```

## scale

图片的缩放比例，范围为 0 到 1。

## rotation

图片的旋转角度，以度为单位。

## position

图片的位置，可以是 [IPosition](/zh/docs/narraleaf-react/core/types/IPosition) 或原始位置数据。

## opacity

图片的不透明度，范围为 0 到 1。

## alt

图片的替代文本（alt）。
