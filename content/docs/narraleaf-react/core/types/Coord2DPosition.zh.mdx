title: "Coord2DPosition"
description: 按绝对或百分比 x、y 坐标并叠加像素偏移的 IPosition 变体

```typescript
type Coord2DPosition = {
    x: number | `${"-" | ""}${number}%`;
    y: number | `${"-" | ""}${number}%`;
} & OffsetPosition;
```
