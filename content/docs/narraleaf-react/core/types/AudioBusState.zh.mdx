---
title: "AudioBusState"
---
```ts
type AudioBusState = {
    id: string;
    parentId: string | null;
    /**
     * The player's control, 0..1, default 1. This is the one to persist.
     */
    volume: number;
    /**
     * The author's mix position, from AudioBusDeclaration.volume.
     */
    declaredVolume: number;
    /**
     * `declaredVolume * volume` - what is actually on the gain node.
     */
    effectiveVolume: number;
};
```

一条总线连同它的两个数字，由 `game.audioBuses.list()` 返回。

这两个数字是刻意分开的。此前一个增益节点被要求同时扮演两个角色——作者混音中的位置和玩家的滑条——
后写入的那一个会悄悄抹掉另一个。把它们拆开之后，叠加关系就变得完整而没有歧义：
**声明值 × 玩家值 = 节点上的值**，谁也覆盖不了谁。

## volume

玩家的控制。**要持久化的就是这一半**——它是唯一属于玩家的那个数字，恢复它可以让作者重新混音一款已发行的游戏，
而不会被回访玩家保存的设置永远钉在旧混音上。`game.audioBuses.getVolumes()` 返回的正是这些值，以 id 为键。

## declaredVolume

作者混音中的位置，来自 [AudioBusDeclaration](/zh/docs/narraleaf-react/core/types/AudioBusDeclaration)。
它来自游戏而不是存储；持久化它等于持久化游戏自身的内容。

## effectiveVolume

两者的乘积——增益节点上真正的值。

- 完整模型参见[音频总线](/zh/docs/narraleaf-react/core/game/audio-buses)。
