---
title: "AlignPosition"
description: An `IPosition` variant that places an element by fractional alignment (`xalign`, `yalign`) plus a pixel offset.
---
```typescript
type AlignPosition = {
    xalign: number;
    yalign: number;
} & OffsetPosition;
```

For OffsetPosition, see [OffsetPosition](/docs/narraleaf-react/core/types/OffsetPosition).
