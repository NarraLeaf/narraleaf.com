---
title: "ChainedActions"
description: "キャラクターやシーンなどのゲーム要素にメソッドを連結呼び出しして得られる、1つのアクション列の配列型"
---
```ts
type ChainedAction = Proxied<GameElement, Chained<LogicAction.Actions>>;
type ChainedActions = (Proxied<LogicAction.GameElement, Chained<LogicAction.Actions>> | LogicAction.Actions)[];
```

例:

```ts
[
    character1
        .say("Hello")
        .say("World"),
    scene1
        .jumpTo(scene2),
    character2
        .say("World")
] satisfies ChainedActions;
```
