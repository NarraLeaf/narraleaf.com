---
title: "WrappedStorableData"
description: 存档中单个存储值的带标签包装形式，标记加载时需要还原为 `Date` 或 `undefined` 的路径
---
存档中的单个存储值

```typescript
export type WrappedStorableData<T extends StorableType = any> = {
    type: BaseStorableTypeName;
    data: T;
    dates?: StorablePath[];
    undefineds?: StorablePath[];
}
```

写入存档时，值会被打上其类型的标签，好让 JSON 无法表达的类型也能完整往返。目前这样的类型有两种：`Date`，以及嵌在里面的 `undefined`。

两者都**不是写在值里**的——没有插入任何可能与真实数据撞车的哨兵对象。`data` 仍然是纯 JSON，而那些位置被按路径记在 `dates` 和 `undefineds` 里，读档时由加载器沿着路径把真值放回去。没有可记的东西时两个字段都不出现，所以既不含 `Date` 也不含 `undefined` 的值，序列化结果与这套机制存在之前逐字相同，旧存档也照旧能读

```typescript
{type: "any", data: 42}
{type: "any", data: false}
{type: "date", data: "Wed Jul 15 2026 14:23:27 GMT+0000"}
```

这是存档格式的一部分：它正是 [SavedGame](/zh/docs/narraleaf-react/core/types/SavedGame) 的 `store` 携带的内容，并由 [SerializedNamespaceData](/zh/docs/narraleaf-react/core/types/SerializedNamespaceData) 按命名空间分组

<Callout type="warning">
    请通过 [Namespace](/zh/docs/narraleaf-react/core/game/storable/namespace) 读写存储的值，它会替你完成包装与解包。这个包装是一个对象，因此存入的 `false` 在解包前是 truthy 的
</Callout>

`data` 保存的是一个 `StorableType`，即命名空间接受的值类型之一，参见 [Persistent](/zh/docs/narraleaf-react/core/elements/persistent)
