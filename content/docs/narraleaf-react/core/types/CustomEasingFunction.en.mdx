title: "CustomEasingFunction"
description: The function signature for a hand-written easing curve, taking a 0-to-1 time value and returning its eased output.

Define a custom easing function.

```typescript
type CustomEasingFunction = (t: number) => number;
```

## t

The time value of the easing function. The value is between 0 and 1.
