---
title: "WrappedStorableData"
---
A single stored value as it appears in a saved game.

```typescript
export type WrappedStorableData<T extends StorableType = any> = {
    type: BaseStorableTypeName;
    data: T;
    dates?: StorablePath[];
    undefineds?: StorablePath[];
}
```

Values are tagged with their type on the way into a save so that types JSON cannot express survive the round-trip. Today those are `Date` and a nested `undefined`.

Neither is encoded in-band — no sentinel object is inserted that a stored value could collide with. `data` stays plain JSON, and the positions that held one of the two are named by path in `dates` and `undefineds`, which the loader walks to put the real values back. Both are absent when there is nothing to name, so a value holding neither serializes exactly as it did before this scheme existed, and a save written before it loads unchanged.

```typescript
{type: "any", data: 42}
{type: "any", data: false}
{type: "date", data: "Wed Jul 15 2026 14:23:27 GMT+0000"}
```

This is part of the save format: it is what [SavedGame](/docs/narraleaf-react/core/types/SavedGame)'s `store` contains, grouped per namespace by [SerializedNamespaceData](/docs/narraleaf-react/core/types/SerializedNamespaceData).

<Callout type="warning">
    Read and write stored values through [Namespace](/docs/narraleaf-react/core/game/storable/namespace), which wraps and unwraps them for you. The wrapper is an object, so a stored `false` is truthy until it is unwrapped.
</Callout>

`data` holds a `StorableType`: one value of the kinds a namespace accepts, see [Persistent](/docs/narraleaf-react/core/elements/persistent).
