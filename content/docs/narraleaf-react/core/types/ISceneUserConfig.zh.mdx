---
title: "ISceneUserConfig"
---
```typescript
interface ISceneUserConfig {
    /**
     * Background music
     */
    backgroundMusic: Sound | null;
    /**
     * Background music fade duration, in milliseconds
     */
    backgroundMusicFade: number;
    /**
     * Voice map or a function that returns the voice URL
     */
    voices?: VoiceIdMap | VoiceSrcGenerator;
    /**
     * Background src, can be a {@link Color} or an {@link Image}
     */
    background: ImageSrc | Color;
    /**
     * An array of {@link Layer}s
     */
    layers: Layer[];
}
```

- 关于 Sound，参见 [Sound](/zh/docs/narraleaf-react/core/elements/sound)
- 关于 VoiceIdMap 和 VoiceSrcGenerator，参见 [ISoundUserConfig](/zh/docs/narraleaf-react/core/types/ISoundUserConfig)。
- 关于 ImageSrc，参见 [ImageSrc](/zh/docs/narraleaf-react/core/types/ImageSrc)。
- 关于 Color，参见 [Color](/zh/docs/narraleaf-react/core/types/color)。
- 关于 Layer，参见 [Layer](/zh/docs/narraleaf-react/core/elements/layer)。
