---
title: "background"
---
```ts
type Background = {
    url: string;
} | color | null | undefined | StaticImageData;
```

场景的背景。可以是 URL 对象、[color](/zh/docs/narraleaf-react/core/types/color)、StaticImageData 或 null

> **注意：** StaticImageData 是由加载器生成的一种类型
> 如果使用 NextJS，可以直接导入图片
> 
> ```ts
> import image from "path/to/image.png";
> ```
