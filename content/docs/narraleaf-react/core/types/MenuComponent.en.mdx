---
title: "MenuComponent"
description: The slot type for `game.configure({ menu })`, the component contract a custom menu screen must satisfy.
---
```typescript
interface MenuElementProps {
    prompt: Sentence;
    choices: Choice[];
    afterChoose: (choice: Choice) => void;
    state: GameState;
}
type MenuComponent = Components<MenuElementProps>;
```

For Components, see [Components](/docs/narraleaf-react/core/types/Components)
