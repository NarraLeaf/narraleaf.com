---
title: "WordConfig"
---
```typescript
type WordConfig = {
    className: string;
    ruby: string;
    color: Color;
    cps?: number;
    emphasis?: WordEmphasis;
    fontScale?: number;
    render?: WordRenderer;
    data?: unknown;
} & Font;
```

For Color, see [Color](/docs/narraleaf-react/core/types/color).
For Font, see [Font](/docs/narraleaf-react/core/types/Font).

## ruby

The `ruby` property is used to display ruby text. This is useful for displaying phonetic guides for Chinese characters.

## className

The `className` property is used to set the class name of the word.

```typescript
new Word({
    className: 'bold',
});
```

## color

The `color` property is used to set the color of the word.

```typescript
new Word({
    color: 'red',
});
```

## cps

The `cps` property is used to set the speed of the word. Using this property, you can have different speeds for different words.

```typescript
new Word({
    cps: 10, // 10 characters per second
});
```

## emphasis

> Available since `0.37.0`

Emphasis marks drawn beside this word's characters: a small glyph beside every character, the typographic way East Asian text stresses a phrase where a Latin one would go italic (傍点 / 圏点 in Japanese, 着重号 in Chinese). The marks follow the characters as they are typed out, so a word that is half revealed carries half its marks.

```typescript
type WordEmphasis = {
    mark?: "dot" | "circle" | "sesame" | "triangle";  // default "dot"
    fill?: "filled" | "open";                          // default "filled"
    position?: "over" | "under";                       // default "over"
};
```

`position` is read against the writing direction: in horizontal writing `over` is above the line and `under` below it; in vertical writing both sit to the right of the column, where the convention places them.

```typescript
new Word("aether density", {emphasis: {mark: "sesame"}});
```

[`Word.emphasis`](/docs/narraleaf-react/core/elements/character/word) sets this field.

## fontScale

> Available since `0.37.0`

This word's size as a share of the line's — `1.25` for a quarter larger, `0.8` for a fifth smaller. Relative rather than absolute, so the word keeps its weight against the rest of the line whatever size the line is set at, including while [text scaling](/docs/narraleaf-react/player/dialog) brings the line down to fit its box.

Ignored when `fontSize` is set, which pins the word to an absolute size.

```typescript
new Word("QUIET", {fontScale: 0.8});
```

## render

> Available since `0.27.0`

The component that draws this word's revealed characters.

```typescript
type WordRenderer<T = any> = string | React.ComponentType<WordRenderProps<T>>;
```

Pass a component in code. Pass an id when the word comes from data and cannot carry a function; the id is resolved against the [renderer registry](/docs/narraleaf-react/core/elements/character/word#renderer-registry) when the word is drawn, and an id nothing answers to renders as plain text.

```tsx
new Word("aether density", {render: GlossaryTerm});
new Word("aether density", {render: "glossary"});
```

[`Word.custom`](/docs/narraleaf-react/core/elements/character/word#custom) sets this field. See [Custom rendering](/docs/narraleaf-react/core/elements/character/word#custom-rendering).

`render` propagates to the plain strings a dynamic word returns, the same way `className` does. It is not inherited by a nested `Word`, which keeps whatever renderer it declares for itself.

## data

> Available since `0.27.0`

The payload handed to `render` as `data`. It is never merged or cloned: the component receives the very value given here.

```tsx
new Word("aether density", {render: "glossary", data: {entry: "aether"}});
```
