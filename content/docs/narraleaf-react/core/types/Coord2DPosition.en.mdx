---
title: "Coord2DPosition"
description: An `IPosition` variant that places an element by absolute or percentage x and y coordinates plus a pixel offset.
---
```typescript
type Coord2DPosition = {
    x: number | `${"-" | ""}${number}%`;
    y: number | `${"-" | ""}${number}%`;
} & OffsetPosition;
```

For OffsetPosition, see [OffsetPosition](/docs/narraleaf-react/core/types/OffsetPosition).
