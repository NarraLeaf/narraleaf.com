---
title: "TransformDefinitions.CommonTransformProps"
description: The duration, easing, delay and sync options common to every transform definition.
---
```typescript
type CommonTransformProps = {
    duration: number;
    ease: EasingDefinition;
    delay: number;
} & {
    sync: boolean;
};
```

## duration

The duration of the transform in milliseconds.

## ease

The easing function of the transform. See [EasingDefinition](/docs/narraleaf-react/core/types/EasingDefinition).

## delay

The delay of the transform in milliseconds.

## sync

If true, the next step will be executed after the current step is completed.
