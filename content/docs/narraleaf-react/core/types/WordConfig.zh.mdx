---
title: "WordConfig"
---
```typescript
type WordConfig = {
    className: string;
    ruby: string;
    color: Color;
    cps?: number;
} & Font;
```

关于 Color，参见 [Color](/zh/docs/narraleaf-react/core/types/color)。  
关于 Font，参见 [Font](/zh/docs/narraleaf-react/core/types/Font)。

## ruby

`ruby` 属性用于显示注音（ruby）文本，可以为汉字标注读音。

## className

`className` 属性用于设置词的类名。

```typescript
new Word({
    className: 'bold',
});
```

## color

`color` 属性用于设置词的颜色。

```typescript
new Word({
    color: 'red',
});
```

## cps

`cps` 属性用于设置词的显示速度，可以让不同的词以不同的速度显示。

```typescript
new Word({
    cps: 10, // 10 characters per second
});
```
