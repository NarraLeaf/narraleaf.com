title: "WordConfig"
---
```typescript
type WordConfig = {
    className: string;
    ruby: string;
    color: Color;
    pause: boolean;
    cps?: number;
    emphasis?: WordEmphasis;
    fontScale?: number;
    render?: WordRenderer;
    data?: unknown;
} & Font;
```

关于 Color，参见 [Color](/zh/docs/narraleaf-react/core/types/color)
关于 Font，参见 [Font](/zh/docs/narraleaf-react/core/types/Font)

## ruby

`ruby` 属性用于显示注音（ruby）文本，可以为汉字标注读音

## className

`className` 属性用于设置词的类名

```typescript
new Word({
    className: 'bold',
});
```

## color

`color` 属性用于设置词的颜色

```typescript
new Word({
    color: 'red',
});
```

## cps

`cps` 属性用于设置词的显示速度，可以让不同的词以不同的速度显示

```typescript
new Word({
    cps: 10, // 10 characters per second
});
```

## pause

这个词是不是一段停顿而非文字。由 [`Word.pause`](/zh/docs/narraleaf-react/core/elements/character/word) 置位，手写的词不会设它。

## emphasis

> 自 `0.37.0` 起可用

画在这个词每个字旁边的**着重号**（日文叫傍点 / 圈点，中文叫着重号）——东亚排版里强调一段话的做法，对应拉丁文的斜体。标记跟着文字一起逐字出现，所以只显了一半的词也只带一半标记。

```typescript
type WordEmphasis = {
    mark?: "dot" | "circle" | "sesame" | "triangle";  // 默认 "dot"
    fill?: "filled" | "open";                          // 默认 "filled"
    position?: "over" | "under";                       // 默认 "over"
};
```

`position` 是相对书写方向读的：横排时 `over` 在行上、`under` 在行下；竖排时两者都在字列右侧，也就是惯例的位置。

```typescript
new Word("灵子密度", {emphasis: {mark: "sesame"}});
```

由 [`Word.emphasis`](/zh/docs/narraleaf-react/core/elements/character/word) 置位。

## fontScale

> 自 `0.37.0` 起可用

这个词相对整行的字号倍率 —— `1.25` 是大四分之一，`0.8` 是小五分之一。用相对值而不是绝对值，所以无论整行被排到多大，这个词在行里的轻重不变——包括[文本缩放](/zh/docs/narraleaf-react/player/dialog)为了塞进框里而把整行调小的时候。

设了 `fontSize` 时它被忽略，因为那是把词钉在一个绝对字号上。

```typescript
new Word("安静", {fontScale: 0.8});
```

## render

> 自 `0.27.0` 起可用

用来绘制这个词已显示字符的组件

```typescript
type WordRenderer<T = any> = string | React.ComponentType<WordRenderProps<T>>;
```

在代码里直接传组件。词来自数据、无法携带函数时传 id：绘制这个词时会在[渲染器注册表](/zh/docs/narraleaf-react/core/elements/character/word#渲染器注册表)中解析该 id，没有注册过的 id 渲染为纯文本

```tsx
new Word("以太浓度", {render: GlossaryTerm});
new Word("以太浓度", {render: "glossary"});
```

[`Word.custom`](/zh/docs/narraleaf-react/core/elements/character/word#custom) 设置的就是这个字段，参见[自定义渲染](/zh/docs/narraleaf-react/core/elements/character/word#自定义渲染)

`render` 会像 `className` 一样传递给动态词返回的纯字符串。嵌套的 `Word` 不会继承它，嵌套词保留自己声明的渲染器

## data

> 自 `0.27.0` 起可用

交给 `render` 作为 `data` 的负载。它既不合并也不克隆：组件拿到的就是这里给出的那个值

```tsx
new Word("以太浓度", {render: "glossary", data: {entry: "aether"}});
```
