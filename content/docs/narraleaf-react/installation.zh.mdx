## 环境要求

- [React](https://reactjs.org/) 19+
- [Motion](https://motion.dev/) 11+

## 安装依赖

<Steps>
<Step>

### 安装 NarraLeaf-React

<Tabs items={['npm', 'yarn', 'pnpm']}><Tab value="npm">
        ```bash
        npm install narraleaf-react motion@11
        ```
</Tab>
<Tab value="yarn">
        ```bash
        yarn add narraleaf-react motion@11
        ```
</Tab>
<Tab value="pnpm">
        ```bash
        pnpm add narraleaf-react motion@11
        ```
</Tab></Tabs>

</Step>
<Step>

### 配置 GameProviders

在应用入口处包裹 `GameProviders` 组件：

```tsx
"use client";

import { GameProviders } from 'narraleaf-react';

export default function App() {
    return (
        <GameProviders>
            {/* 你的应用内容 */}
        </GameProviders>
    );
}
```

</Step>
</Steps>

接下来编写剧本并传入 Player 组件即可。详见[基础](/zh/docs/narraleaf-react/basic)。
