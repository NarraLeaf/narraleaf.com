---
title: "快速开始"
---
本指南带你从零创建一个 NarraLeaf-React 视觉小说项目。

## 创建项目

<Steps>
<Step>

### 初始化项目

在终端中执行以下命令，使用官方模板创建新项目：

```bash
npx nlr-skeleton@latest my-project
```

</Step>
<Step>

### 启动开发服务器

<Tabs items={['npm', 'yarn', 'pnpm']}><Tab value="npm">
        ```bash
        npm run dev
        ```
</Tab>
<Tab value="yarn">
        ```bash
        yarn dev
        ```
</Tab>
<Tab value="pnpm">
        ```bash
        pnpm dev
        ```
</Tab></Tabs>

打开 `http://localhost:3000` 即可预览。

</Step>
</Steps>

项目创建完成后，编辑 `src/story.ts` 即可编写你的剧本。
