## 依存関係

NarraLeaf-React は以下の依存関係を使用しています。

- [React](https://github.com/facebook/react) - [MIT License](https://github.com/facebook/react/blob/main/LICENSE)
- [Howler.js](https://github.com/goldfire/howler.js) - [MIT License](https://github.com/goldfire/howler.js/blob/master/LICENSE.md)
- [Framer Motion](https://github.com/framer/motion) - [MIT License](https://github.com/framer/motion/blob/main/LICENSE.md)
- [clsx](https://github.com/lukeed/clsx) - [MIT License](https://github.com/lukeed/clsx/blob/master/license)
