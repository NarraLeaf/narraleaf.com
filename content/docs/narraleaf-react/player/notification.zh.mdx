---
title: "通知"
---
`Notifications` 组件用于渲染通知框，提供自定义接口。

## 数据结构

```typescript
type Notification = {
    message: string;
    id: string;
}
```

## 示例

1. 导入组件

```tsx
import { useState } from "react";
import { INotificationsProps, useGame } from "narraleaf-react";
```

2. 实现通知组件

```tsx
function GameNotification({ notifications }: { notifications: Notification[] }) {
    return (
        <Notifications
            className="absolute top-0 left-0 w-full h-full"
        >
            {notifications.map(({id, message}) =>
                <div
                    key={id}
                    className="absolute top-0 left-0 w-[100px] h-[80px]"
                >
                    <span className="text-white text-2xl font-bold">
                        {message}
                    </span>
                </div>
            )}
        </Notifications>
    );
}
```

3. 注册到游戏

```tsx
function App() {
    const game = useGame();

    useEffect(() => {
        game.configure({
            notification: GameNotification,
        });
    }, []);

    return /* ... */
}
```

## 组件

### Notifications

通知框容器。

- `children: React.ReactNode` - 子元素
- `...props: React.HTMLAttributes<HTMLDivElement>` - 其他属性
