---
title: "useRouter"
description: LayoutRouter のツリーをナビゲートするための Router インスタンスを作成または取得する useRouter フック
---
router インスタンスを作成します。

```tsx
import { useRouter } from "narraleaf-react";
```

```tsx
const router = useRouter();
```

## 定義

```typescript
function useRouter(defaultId?: string): Router;
```

router インスタンスの詳細については、[Router](/ja/docs/narraleaf-react/player/page-router/router) を参照してください。
