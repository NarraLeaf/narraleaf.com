---
title: "useGame"
---
通过这个钩子可以访问游戏对象

> **注意：** 此钩子只能在 [GameProvider](/zh/docs/narraleaf-react/player/game-providers) 的后代组件中使用

```typescript
function useGame(): GameContextType;
```

- 类型定义参见 [GameContextType](/zh/docs/narraleaf-react/core/types/GameContextType)

## 用法

```typescript
import {useGame} from "narraleaf-react";
```

```typescript
function myComponent() {
    const game = useGame();

    useEffect(() => {
        // ...
    }, [game]);
}
```
