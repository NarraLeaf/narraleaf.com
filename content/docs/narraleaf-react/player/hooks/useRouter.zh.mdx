创建一个路由器实例

```tsx
import { useRouter } from "narraleaf-react";
```

```tsx
const router = useRouter();
```

## 定义

```typescript
function useRouter(defaultId?: string): Router;
```

有关路由器实例的更多信息，请查看 [Router](/zh/docs/narraleaf-react/player/page-router/router)
