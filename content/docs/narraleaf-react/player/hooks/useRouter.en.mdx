---
title: "useRouter"
description: The useRouter hook, which creates or retrieves a Router instance for navigating the LayoutRouter tree.
---
Create a router instance.

```tsx
import { useRouter } from "narraleaf-react";
```

```tsx
const router = useRouter();
```

## Definition

```typescript
function useRouter(defaultId?: string): Router;
```

For more information about the router instance, please check [Router](/docs/narraleaf-react/player/page-router/router).
