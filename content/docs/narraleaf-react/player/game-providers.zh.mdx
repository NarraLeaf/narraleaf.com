---
title: "GameProviders"
---
`GameProviders` 组件用于向子组件提供游戏实例。

必须将 `Player` 包裹在 `GameProviders` 中。

## 用法

```tsx
import { GameProviders } from "narraleaf-react";
```

```tsx
<GameProviders>
    <Player ... />
</GameProviders>
```

### 使用已定义的游戏实例

传入 `game` 属性可使用自定义的 [Game](/zh/docs/narraleaf-react/core/game/game) 实例：

```tsx
"use client";

import { Game, GameProviders, Player } from "narraleaf-react";
import { useState } from "react";

export default function Page() {
    const [game] = useState(new Game({}));

    return (
        <GameProviders game={game}>
            <Player ... />
        </GameProviders>
    );
}
```

## Props

### game

[Game](/zh/docs/narraleaf-react/core/game/game) 实例。

### children

子组件。
