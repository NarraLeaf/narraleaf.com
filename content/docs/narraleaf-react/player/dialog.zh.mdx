---
title: "对话框"
---
`Dialog` 组件用于渲染 ADV 对话框，包含角色名牌、对话文本和可选的小头像。

可通过 `game.configure({ dialog })` 传入自定义组件。你可以组合 `Avatar`、`Nametag`、`Texts`，或使用 [`useAvatar`](/zh/docs/narraleaf-react/player/hooks/useAvatar)、[`useDialog`](/zh/docs/narraleaf-react/player/hooks/useDialog) 处理布局逻辑。

<Callout type="info">
    默认头像槽位直接使用 `Avatar`。若布局需根据头像是否存在而变化，请使用 `useAvatar()`。
</Callout>

## 快速示例

1. 导入组件

```tsx
import { Dialog, Texts, Nametag, useGame } from "narraleaf-react";
```

2. 组合默认 ADV 布局

```tsx
import { Avatar, Dialog, Nametag, Texts } from "narraleaf-react";

function GameDialog() {
    return (
        <Dialog className="bg-white">
            <div className="dialog-content flex items-start gap-4 w-full h-full">
                <Avatar />
                <div className="dialog-text-content min-w-0 flex-1">
                    <Nametag className="font-bold" />
                    <Texts className="text-lg" />
                </div>
            </div>
        </Dialog>
    );
}
```

3. 注册到游戏

```tsx
function App() {
    const game = useGame();

    useEffect(() => {
        game.configure({
            dialog: GameDialog,
        });
    }, []);

    return /* ... */
}
```

## 组件

### Dialog

对话框容器。子节点通常为 `Avatar`、`Nametag`、`Texts`。

- `children?: React.ReactNode` — 对话框内容
- `...props: HTMLMotionProps<"div">` — 传给内部 `motion.div` 的属性，支持 `initial`、`animate`、`exit`、`transition`、`layout` 及 Motion 事件处理器

外层 wrapper 负责宽高比缩放和点击/按键处理。视觉 transform 应写在 `Dialog` 上，播放器会应用到内部 motion 元素。

已导出的 props 类型：`NametagProps`、`TextAppearanceProps`、`TextsProps`、`RawTextsProps`、`EntryTextsProps`。

### Nametag

渲染说话人名字。需放在 `Dialog` 内。

通过 props 控制内容与展示。未传自定义内容时回退到当前说话人名称；未传 `color` 时回退到角色颜色。

- `character?: Character | null` — 指定角色来源
- `entry?: NvlDialogEntry` — NVL 条目来源
- `name?: React.ReactNode` — 覆盖显示名称
- `color?: Color` — 名牌文字颜色
- `children?: React.ReactNode` — 完全自定义名牌内容
- `...props: Omit<React.HTMLAttributes<HTMLDivElement>, "children" | "color">`

### Texts

渲染逐字显示的对话正文。需放在 `Dialog` 内。

文本外观来自组件 props 或继承的 CSS。`Sentence` 与 `Word` 的局部样式会覆盖默认值。

- `children?: never`
- `defaultColor?: Color` — 回退文本颜色
- `fontSize?: React.CSSProperties["fontSize"]`
- `fontWeight?: React.CSSProperties["fontWeight"]`
- `fontWeightBold?: React.CSSProperties["fontWeight"]` — 粗体字重
- `fontFamily?: React.CSSProperties["fontFamily"]`
- `...props: React.HTMLAttributes<HTMLDivElement>`

### Avatar

根据当前台词解析并渲染对话框头像。若当前行无头像则不渲染。

- `...props: React.ImgHTMLAttributes<HTMLImageElement>` — 与默认样式合并（参见 [useAvatar](/zh/docs/narraleaf-react/player/hooks/useAvatar)）

默认样式：`width/height: 96`、`objectFit: "cover"`、`borderRadius: 6`、`flex: "0 0 auto"`。

## Dialog Motion Props

自定义对话框可直接向 `Dialog` 传入 Motion props。内置 `DefaultDialog` 默认无进入/退出动画。

```tsx
import { Dialog, Nametag, Texts } from "narraleaf-react";

function GameDialog() {
    return (
        <Dialog
            initial={{ opacity: 0, y: 20 }}
            animate={{ opacity: 1, y: 0 }}
            exit={{ opacity: 0, y: -20 }}
            transition={{ duration: 0.25, ease: "easeOut" }}
            layout
        >
            <Nametag />
            <Texts />
        </Dialog>
    );
}
```

presence 时序由播放器处理：

- 对话到对话的直接替换保留同一 dialog slot，不会播放 exit/进入动画
- 对话后接非对话内容时，当前对话移除，可播放 exit
- 旧退出动画未结束时出现新对话，两者可重叠播放
- 菜单 prompt 使用相同的 presence 行为
- 退出中的对话框处于 inactive 状态，点击、skip、auto-forward 均被忽略

`GameConfig.animationPropagate` 传给 dialog 的 `AnimatePresence`。除非自定义对话框内部嵌套了需要传播退出动画的 `AnimatePresence`，否则保持 `false`。

## 对话框头像

用于在 ADV 文本框旁显示小头像，适用于说话人在台上、画外音等不需要逐句配置头像的场景。

### 设计模型

- **`Character` 承载头像意图** — 默认/画外音头像及立绘绑定
- **舞台上的 `Image` 可细化头像** — 仅当该立绘为当前绑定的可见肖像时生效
- **`Sentence` 只覆盖例外** — 隐藏头像或单行特殊资源

解析顺序：

1. 旁白或无名角色 → 无头像
2. `sentence.config.avatar === false` → 无头像
3. 句子级头像覆盖
4. 该角色当前最近可见的绑定立绘头像
5. 角色级默认头像
6. 否则无头像

引擎**不会**自动从全身立绘裁切头像。

### 角色级头像

当同一张头像同时用于台上台词与画外音时使用：

```ts
import { Character } from "narraleaf-react";

const alice = new Character("Alice", {
    avatar: "/assets/alice/avatar-default.png",
});

alice.say("画外音时也可以使用角色级头像。");
```

链式写法：

```ts
const alice = new Character("Alice")
    .setAvatar("/assets/alice/avatar-default.png");

alice.say("本句使用 Alice 的默认头像。");
```

### 绑定舞台立绘

当可见立绘决定对话框头像时，将舞台 `Image` 绑定到角色：

```ts
import { Character, Image } from "narraleaf-react";

const aliceBody = new Image({
    name: "alice-body",
    src: "/assets/alice/body-normal.png",
    opacity: 1,
});

const alice = new Character("Alice", {
    avatar: "/assets/alice/avatar-default.png",
    portraits: [
        {
            image: aliceBody,
            avatar: "/assets/alice/avatar-normal.png",
        },
    ],
});
```

当 `aliceBody` 可见时使用立绘头像，否则回退到角色级头像。

```ts
const alice = new Character("Alice")
    .setAvatar("/assets/alice/avatar-default.png")
    .addPortrait(aliceBody, {
        avatar: "/assets/alice/avatar-normal.png",
    });
```

### 基于标签表情的头像

立绘头像可以是解析函数，入参包含当前立绘、`currentSrc`、`tags`、`character`、`sentence`、`gameState`。返回值：

- 图片 URL 或 `StaticImageData`
- `null` — 强制不显示头像
- `undefined` — 交由下一层回退

```ts
const aliceBody = new Image({
    name: "alice-body",
    src: {
        groups: [
            ["normal", "happy", "angry"],
            ["school", "casual"],
        ],
        defaults: ["normal", "school"],
        resolve: (emotion, outfit) => `/assets/alice/body-${emotion}-${outfit}.png`,
    },
    opacity: 1,
});

const alice = new Character("Alice", {
    avatar: "/assets/alice/avatar-default.png",
    portraits: [
        {
            image: aliceBody,
            avatar: ({ tags }) => {
                const emotion = tags?.[0] ?? "normal";
                return `/assets/alice/avatar-${emotion}.png`;
            },
        },
    ],
});
```

### 单行覆盖

```ts
alice.say("仅本行隐藏头像。", {
    avatar: false,
});

alice.say("本行使用特殊切图。", {
    avatar: "/assets/alice/avatar-special.png",
});

alice.say("本行使用解析器。", {
    avatar: ({ tags, currentSrc }) => {
        if (tags?.includes("angry")) {
            return "/assets/alice/avatar-angry-close.png";
        }
        return undefined;
    },
});
```

除 `avatar: false` 外，句子级覆盖优先于立绘与角色默认。

### 多个可见立绘

若同一角色多个绑定立绘同时可见，引擎按展示顺序选取最近且可见的一个。`opacity` 为 0 的显示对象会被忽略。

## 自定义对话框与 `useAvatar`

简单布局直接使用 `<Avatar />`。若需根据头像是否存在调整布局，请使用 [`useAvatar()`](/zh/docs/narraleaf-react/player/hooks/useAvatar)（返回 `visible`、`src`、`character`、`portrait` 等）。

详见 [useAvatar](/zh/docs/narraleaf-react/player/hooks/useAvatar)。

## TypeScript 参考

类型与类由 `narraleaf-react` 导出（详见 [Character](/zh/docs/narraleaf-react/core/elements/character)、[SentenceConfig](/zh/docs/narraleaf-react/core/types/SentenceConfig)、[CharacterConfig](/zh/docs/narraleaf-react/core/types/CharacterConfig)）：

- `DialogAvatarSource`、`DialogAvatarResolverContext`、`DialogAvatarResolver`、`DialogAvatar`
- `CharacterPortraitConfig`、`DialogAvatarResolution`
- `Character` 方法：`setAvatar`、`addPortrait`、`setPortraits`
- `Sentence` / `say` 的 `avatar`：参见 [SentenceUserConfig](/zh/docs/narraleaf-react/core/types/SentenceUserConfig)
- React：`Avatar`、`useAvatar`，类型 `DialogAvatarContext`

默认 UI 的头像解析在播放器内部完成，通常只需配置角色与句子，再渲染 `<Avatar />` 或调用 `useAvatar()`。

## 自定义对话框外观

### 容器样式

```tsx
function GameDialog() {
    return (
        <Dialog
            style={{
                backgroundColor: "rgba(0, 0, 0, 0.5)",
                borderRadius: "10px",
                padding: "20px",
            }}
        >
            {/* ... */}
        </Dialog>
    );
}
```

### 名牌装饰

```tsx
function GameDialog() {
    return (
        <Dialog>
            <Nametag
                style={{
                    backgroundImage: "url('/path/to/image.png')",
                    backgroundSize: "cover",
                    width: "100%",
                    height: "100%",
                }}
            />
        </Dialog>
    );
}
```
