**NarraLeaf-React** ライブラリのドキュメントへようこそ。

NarraLeaf-React は、軽量でカスタマイズ性が高く、扱いやすい React 向けのビジュアルノベルフレームワークです。React でビジュアルノベルを制作するために設計されています。

## NarraLeaf-React を選ぶ理由

- **軽量**：レンダリングライブラリや不要な依存関係がありません
- **カスタマイズ性**：新しい言語を学ぶ必要はなく、アプリに合わせてあらゆる部分を調整できます
- **開発者向けの設計**：オブジェクト指向の原則に基づいており、拡張や保守が容易です

NarraLeaf-React は、専用のスクリプト言語を必要とする従来のエンジンに代わる、より柔軟な選択肢です。**React** と **TypeScript** を使うことで、ビジュアルノベルの UI を完全にカスタマイズでき、複雑なスクリプトを書かずに独自の見た目を実現できます。
