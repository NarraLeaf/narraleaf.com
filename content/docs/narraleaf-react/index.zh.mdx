欢迎来到 **NarraLeaf-React** 库的文档！

NarraLeaf-React 是一个轻量、可定制且易用的 React 视觉小说框架，可以直接用 React 构建自己的视觉小说

## 为什么选择 NarraLeaf-React？

- **轻量**：不依赖渲染库，没有多余的依赖
- **可定制**：一切都可以按你的应用定制，无需学习新语言
- **为开发者设计**：基于面向对象设计，易于扩展和维护

相比需要专用脚本语言的传统引擎，NarraLeaf-React 的集成方式更灵活。使用 **React** 和 **TypeScript**，你可以完全定制视觉小说的 UI，全程无需再学习复杂的脚本
