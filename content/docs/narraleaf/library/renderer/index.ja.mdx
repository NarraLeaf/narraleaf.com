**Renderer** モジュールは、NarraLeaf デスクトップアプリの React 側です。生成されたアプリのエントリをマウントし、アプリケーションシェルを提供し、NarraLeaf-React の `Player` を埋め込み、セーブ、再生状態、renderer から main への通信のための hooks を公開します。

```ts
import {
    render,
    useApp,
    useGamePlayback,
    useSaveAction,
    invokeMainEvent,
} from "narraleaf/renderer";
```

## 公開エクスポート

- `render`
- `useApp`
- `useAppState`
- `useGamePlayback`
- `useCurrentSaved`
- `useCurrentSavedRef`
- `useSaveAction`
- `useSavedGames`
- `readGame`
- `requestMain`
- `invokeMainEvent`
- `SaveType`

renderer のエントリは、`RendererApp`、`RendererAppRootProps`、`GameMetadata`、ルートモジュールの型、セーブ結果の型、`MainProcessEventMap`、`MainProcessEventEntry` といった公開の型もエクスポートします。

## NarraLeaf-React との関係

NarraLeaf は、ストーリーの再生に NarraLeaf-React を使用します。ストーリー、シーン、キャラクター、メニュー、displayable は [NarraLeaf-React](/ja/docs/narraleaf-react) で作成し、そのストーリーを NarraLeaf の renderer アプリの `metadata.story` を通じてエクスポートします。
