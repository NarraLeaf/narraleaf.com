**NarraLeaf Desktop** のドキュメントへようこそ。

NarraLeaf Desktop は、Electron、React、NarraLeaf-React の上に構築されたデスクトップ版ビジュアルノベルアプリのツールチェーンです。主プロセスのランタイム、renderer のシェル、セーブブリッジ、ページルーティング、プロジェクト設定、そして完全なパッケージアプリを作成するための CLI ワークフローを提供します。

## NarraLeaf Desktop を選ぶ理由

- **完全なデスクトップアプリ**：既存の Web ページにプレイヤーを埋め込むだけでなく、独立した Electron アプリケーションを構築できます。
- **型付けされたランタイム**：主プロセス、renderer ブリッジ、セーブシステム、ビルドターゲットを TypeScript フレンドリーな API で設定できます。
- **内蔵の NarraLeaf-React**：NarraLeaf-React でストーリーを作成し、アプリの起動、ルーティング、永続化、パッケージ化は NarraLeaf Desktop に任せられます。

React のプレイヤーフレームワークだけが必要な場合は [NarraLeaf-React](/ja/docs/narraleaf-react) を選んでください。デスクトップアプリのシェル、CLI、配布ワークフローも必要な場合は NarraLeaf Desktop を選んでください。

## 推奨する読み進め方

1. [Installation](/ja/docs/narraleaf/library/installation) を読みます。
2. [Quick Start](/ja/docs/narraleaf/library/quick-start) を進めます。
3. [Project Config](/ja/docs/narraleaf/library/project-config) を学びます。
4. API の詳細が必要になったら [Main](/ja/docs/narraleaf/library/main) と [Renderer](/ja/docs/narraleaf/library/renderer) を参照します。
5. ローカル開発とパッケージ化を自動化する準備ができたら [CLI](/ja/docs/narraleaf/library/cli) を使います。

> **Note:** NarraLeaf Desktop は初期開発段階にあります。文書化するに足るほど安定した API もありますが、プロジェクトでは NarraLeaf Desktop、NarraLeaf-React、Electron、React のバージョンを揃えておいてください。
