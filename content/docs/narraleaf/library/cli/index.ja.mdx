**CLI** パッケージは、NarraLeaf デスクトッププロジェクトが使用する `narraleaf` コマンドを提供します。

```bash
narraleaf init my-visual-novel
cd my-visual-novel
narraleaf dev
```

## CLI が読み取るもの

各プロジェクトコマンドはカレントディレクトリから実行され、次のものが存在することを前提とします。

- `package.json`
- `narraleaf.config.js`
- 設定された main のエントリ
- 設定された renderer ディレクトリ
- `renderer/App.tsx` または `renderer/App.jsx`
- `renderer/pages`
- `renderer/public`

設定の全体像は [プロジェクト設定](/ja/docs/narraleaf/library/project-config) を参照してください。
