---
title: "Init"
description: skeleton パッケージで NarraLeaf プロジェクトを作成する
---

`narraleaf init [path]` は、最新の skeleton パッケージに処理を委譲してプロジェクトを作成します。

```bash
narraleaf init my-visual-novel
```

内部では次のコマンドが実行されます。

```bash
npx narraleaf-skeleton@latest my-visual-novel
```

`[path]` を省略した場合、デフォルトのパスはカレントディレクトリになります。

```bash
narraleaf init
```

## Init のあと

プロジェクトディレクトリに移動し、開発を開始します。

```bash
cd my-visual-novel
narraleaf dev
```

## 想定されるプロジェクト構成

生成されたプロジェクトには、NarraLeaf に必要なプロジェクトファイルが含まれているはずです。

        <Folder name="assets" />
