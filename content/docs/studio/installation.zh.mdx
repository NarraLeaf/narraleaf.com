## 系统需求

| 平台 | 最低系统版本 | 架构 |
| --- | --- | --- |
| Windows | Windows 10 | x64 |
| macOS | macOS 11 | Apple Silicon |

Studio 不支持 Intel Mac。Intel Mac 仍可作为构建目标，参见[运行与打包](/zh/docs/studio/getting-started/run-and-package)

## 安装

**Windows** —— 运行 `.exe` 安装程序。默认为当前用户安装，不会出现管理员授权提示；向导中也可以修改安装目录，或改为所有用户安装，该方式需要管理员授权

**macOS** —— 打开 `.dmg`，将 NarraLeaf Studio 拖入「应用程序」

<Callout type="warn">
Studio 未经过代码签名，首次启动需要手动放行。Windows 上选择**更多信息 → 仍要运行**；macOS 上在**系统设置 → 隐私与安全性**中选择**仍要打开**，或移除隔离属性：

```bash
xattr -dr com.apple.quarantine "/Applications/NarraLeaf Studio.app"
```
</Callout>

首次启动进入启动器，项目和插件都在这里管理

## 更新

Studio 在启动后不久以及运行期间每隔数小时检查是否有新版本，结果显示在**设置 → 常规 → 更新**中。关闭检查请取消勾选**自动检查更新**。**更新下载源**决定从哪里下载新版本：选择**自动**时会比较 GitHub 与 GitCode 的速度，使用较快的一个

**Windows** —— Studio 在后台下载并准备新版本，工作区标题栏的更新按钮显示进度，重启 Studio 即应用更新。如果想在**更新**面板中自己下载每个版本，请取消勾选**自动下载更新**

**macOS** —— Studio 只提示新版本。请下载新的 `.dmg`，替换「应用程序」中的应用

### 升级到 1.4.0 [#upgrading-to-1-4-0]

Studio 1.4.0 以第 14 版格式保存项目的界面，新增了[页面参数](/zh/docs/studio/workspace/ui-editor#page-params)。它第一次打开早期版本建立的项目时，会升级 `editor/ui/uidoc.json`，此后 Studio 1.3.x 及更早的版本会拒绝打开该项目，因此打开它的每台电脑都需要 1.4.0 或更高版本。这次升级不改动页面本身，只在文件里记下新的版本号

### 升级到 1.3.0 [#upgrading-to-1-3-0]

Studio 1.3.0 以新的格式（第 13 版）保存项目的界面。它第一次打开早期版本建立的项目时，会升级 `editor/ui/uidoc.json`，此后 Studio 1.2.x 及更早的版本会拒绝打开该项目，因此打开它的每台电脑都需要 1.3.0 或更高版本。升级带来的变化见[界面文本](/zh/docs/studio/workspace/localization#projects-from-earlier-versions)
