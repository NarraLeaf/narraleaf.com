## 系统需求

| 平台 | 最低系统版本 | 架构 |
| --- | --- | --- |
| Windows | Windows 10 | x64 |
| macOS | macOS 11 | Apple Silicon |

Studio 不支持 Intel Mac。Intel Mac 仍可作为构建目标，参见[运行与打包](/zh/docs/studio/getting-started/run-and-package)。

## 安装

**Windows** —— 运行 `.exe` 安装程序。默认为当前用户安装，不会出现管理员授权提示；向导中也可以修改安装目录，或改为所有用户安装，该方式需要管理员授权。

**macOS** —— 打开 `.dmg`，将 NarraLeaf Studio 拖入「应用程序」。

<Callout type="warn">
Studio 未经过代码签名，首次启动需要手动放行。Windows 上选择**更多信息 → 仍要运行**；macOS 上在**系统设置 → 隐私与安全性**中选择**仍要打开**，或移除隔离属性：

```bash
xattr -dr com.apple.quarantine "/Applications/NarraLeaf Studio.app"
```
</Callout>

首次启动进入启动器，项目和插件都在这里管理。

## 更新

Studio 在启动后不久检查是否有新版本，结果显示在**设置 → 常规 → 更新**中。下载不会自行开始。关闭该检查请取消勾选**启动时检查更新**。

**Windows** —— 在该面板中下载更新，Studio 会在下次重启时安装。

**macOS** —— Studio 只提示新版本。请下载新的 `.dmg`，替换「应用程序」中的应用。
