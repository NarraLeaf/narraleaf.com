## 系统需求

**Windows** —— Windows 10 或更高版本，x64。

**macOS** —— macOS 11 或更高版本，且必须是 **Apple Silicon**，Studio 不支持 Intel Mac。

<Callout type="warn">
在 Intel Mac 上无法运行 Studio。macOS 版本提供的是 Apple Silicon 原生二进制，而 Rosetta 2 仅支持将 Intel 二进制转译至 Apple Silicon 架构，不具备反向转译能力。因此，这并非功能受限或可绕过的问题——应用完全无法启动。

需要注意的是，此处受限的是 Studio 本身的运行环境，而非输出的目标平台。Intel Mac 仍可作为构建目标：在 Apple Silicon 设备上制作的游戏，可像对待其他平台一样，正常打包分发给使用 Intel Mac 的玩家。详见“运行与打包”文档。
</Callout>

## 安装

**Windows** —— 运行 `.exe`。它按当前用户安装，不会索要管理员权限。

**macOS** —— 打开 `.dmg`，把 NarraLeaf Studio 拖进「应用程序」。

<Callout type="warn">
构建没有代码签名，所以第一次启动会被拦下。

Windows 上点**更多信息 → 仍要运行**。macOS 上走**系统设置 → 隐私与安全性 → 仍要打开**，或者：

```bash
xattr -dr com.apple.quarantine "/Applications/NarraLeaf Studio.app"
```
</Callout>

Studio 不会自我更新——更新的做法是下载新的安装包，直接覆盖现有安装。
