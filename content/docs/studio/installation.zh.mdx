## 系统需求

| 平台 | 最低系统版本 | 架构 |
| --- | --- | --- |
| Windows | Windows 10 | x64 |
| macOS | macOS 11 | Apple Silicon |

Studio 不提供 Intel 版本，也无法在 Intel Mac 上运行。该限制仅涉及 Studio 自身的运行环境：Intel Mac 仍是可用的构建目标，在 Apple Silicon 上制作的项目可以照常打包给使用 Intel Mac 的玩家。参见[运行与打包](/zh/docs/studio/getting-started/run-and-package)。

## 安装

**Windows** —— 运行 `.exe` 安装程序。Studio 安装到当前用户，不需要管理员权限。

**macOS** —— 打开 `.dmg`，将 NarraLeaf Studio 拖入「应用程序」。

<Callout type="warn">
桌面产物尚未完成代码签名，首次启动会被系统拦截。Windows 上选择**更多信息 → 仍要运行**；macOS 上在**系统设置 → 隐私与安全性**中选择**仍要打开**，或移除隔离属性：

```bash
xattr -dr com.apple.quarantine "/Applications/NarraLeaf Studio.app"
```
</Callout>

## 更新

Studio 不会自动更新。更新时下载新版本安装程序，覆盖现有安装即可。
