ワークスペースは、アクティビティバー、サイドバー、エディタ領域、Properties パネル、ボトムバーで構成されます。アクティビティバーは、左側のサイドバーに表示するツールを切り替えます。ページ、ストーリーのシーン、アセット、ブループリントは、中央にタブとして開きます。

## 主な領域

| 領域 | 役割 |
| --- | --- |
| 左側のアクティビティバー | Dashboard、Project、Story、Search、UI、Characters、Assets、Localization、Voice、Story Variables、Dictionary、Plugins を切り替える |
| 左サイドバー | 現在のツールのコンテンツを閲覧・作成する |
| 中央のエディタ領域 | ページ、シーン、アセットのプレビュー、ブループリントをタブで開く |
| 右側の Properties パネル | 選択したページ、ウィジェット、アセット、ストーリーアクションを編集する |
| ボトムバー | コンソール、ビルド出力、モーションツール、アセットパネルを表示する |
| トップバー | ファイル操作、バージョン管理、実行・ビルドの操作 |

## 左側のレール

レールには 12 個のパネルが登録されています。そのうち見落としやすい 3 つを紹介します。

- **Dashboard**（ダッシュボード）はレールの先頭にあり（他のすべてより前に並びます）、サイドバーではなくタブとして開きます。プロジェクトの規模、各キャラクターの台詞数、最近の執筆活動が表示されます。
- **Search**（検索）は、1 つのエディタ内ではなくプロジェクト全体を対象に検索します。
- **Voice**（ボイス）はボイスラインのライブラリです。各台詞について、吹き替え言語ごとに収録したテイクを扱います。Story Variables、Dictionary、Plugins と同様、オンにするまでは表示されません。

レールにどのパネルを表示するかは自由に設定できます。プラグインも [`app.services.ui.panels`](/ja/docs/studio/plugin/studio/ui) を通じて独自のパネルを追加できます。

## 選択と Properties

Properties パネルは、現在の選択に応じて内容が変わります。

- UI キャンバス上でテキストを選択すると、その内容、レイアウト、外観を編集できます。
- Assets で画像を選択すると、そのアセットの情報を表示します。
- ストーリーのシーンでアクションを選択すると、そのアクションのパラメータを編集できます。

パネルが「何も選択されていません」と表示している場合は、現在のエディタまたはサイドバーで項目を選択してください。

## エディタのタブ

コンテンツを開くと、中央のエディタ領域にタブが作成されます。タブは閉じたり再度開いたりでき、`Ctrl+Tab` で最近使用したタブを順に切り替えられます。ワークスペースを再度開くと、Studio は対応するタブを復元します。

タブのタイトル横に表示される変更マークは、その内容がまだプロジェクトファイルに書き込まれていないことを示します。Studio はほとんどの編集を自動的に保存します。Dev Mode の開始やビルドの前には、通知と診断結果を確認してください。

## ワークスペースを調整する

<Gif
    brief="左サイドバーの端をドラッグして幅を広げ、ボトムバーを上にドラッグし、続いてトップバーから右サイドバーを非表示にする様子"
    duration="6s"
/>

- 領域の端をドラッグすると、サイドバーやボトムバーのサイズを変更できます。
- 非表示にした領域は、**Window → Show Sidebar**（ウィンドウ → サイドバーを表示）、**Show Right Bar**（右バーを表示）、**Show Bottom Bar**（下部バーを表示）から復元できます。
- パネルを閉じても、プロジェクトの内容が削除されることはありません。
- コンソールはボトムバーにあり、Dev Mode とビルドの詳細な出力を表示します。

<Callout type="info">
キャンバスはレイアウトのためのツールです。ブループリントの実行、ノードのトレース、実行中のゲームの状態は Dev Mode に表示されます。
</Callout>
