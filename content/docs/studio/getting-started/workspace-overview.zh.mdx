---
title: 工作区概览
description: 活动栏、编辑器、属性面板和底部面板的分工
---

工作区由活动栏、侧边栏、编辑区、属性面板和底部面板组成。活动栏决定左侧边栏显示哪个工具；页面、故事场景、素材和蓝图以标签页的形式在中央打开。

## 主要区域

| 区域 | 作用 |
| --- | --- |
| 左侧活动栏 | 在项目、故事、UI、角色、素材和本地化之间切换 |
| 左侧边栏 | 浏览和创建当前工具中的内容 |
| 中央编辑区 | 以标签页打开页面、场景、素材预览和蓝图 |
| 右侧属性面板 | 编辑所选页面、控件、素材或故事动作 |
| 底部面板 | 显示控制台、构建输出、动画工具和素材面板 |
| 顶部操作栏 | 文件操作、版本控制，以及运行与构建控件 |

## 选择与属性

属性面板跟随当前选择：

- 在 UI 画布中选择文本，显示其文字、布局和外观属性。
- 在素材面板中选择图片，显示该素材的信息。
- 在故事场景中选择动作，显示该动作的参数。

若面板提示未选择任何内容，先在当前编辑器或侧边栏中选中对象。

## 编辑器标签页

打开内容会在中央编辑区创建标签页。标签页可以关闭和重新打开，`Ctrl+Tab` 在最近使用的标签页之间切换。再次打开工作区时，Studio 会恢复支持恢复的标签页。

标签页标题旁的修改标记表示内容尚未写入项目文件。Studio 会自动保存多数编辑；启动开发模式或构建前，仍应查看通知与检查结果。

## 调整工作区

- 拖动区域边缘可调整侧边栏和底部面板的尺寸。
- 使用**窗口 → 显示侧边栏**、**显示右边栏**或**显示底边栏**恢复被隐藏的区域。
- 关闭面板不会删除项目内容。
- 控制台位于底部面板，显示开发模式和构建的详细输出。

<Callout type="info">
画布是排版工具。蓝图执行、节点跟踪和实际游戏状态在开发模式中查看。
</Callout>
