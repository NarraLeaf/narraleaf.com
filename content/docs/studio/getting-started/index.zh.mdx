本指南从启动器创建一个空白项目。完成后，Studio 打开工作区，UI 编辑器中已准备好 `Main Page`

/>

## 创建项目

<Steps>
<Step>

### 打开向导

在启动器的**项目**页选择**添加项目**

向导分为**来源**、**工程**、**舞台**和**确认**四步
</Step>
<Step>

### 选择来源

选择**新建工程**，再选择**空白**模板

同一步骤也可以导入已导出的 `.nlspkg` 文件，或从版本控制服务器克隆项目

<Figure
    src="/static/img/docs/studio/zh/project-wizard.webp"
    alt="向导的来源一步：新建工程、导入 .nlspkg、从服务器克隆，右侧是可选模板"
/>
</Step>
<Step>

### 填写项目信息

需要填写：

- **项目名称**，同时作为产物的默认名称
- **应用 ID**，只能使用小写字母、数字和连字符，创建后不可更改
- **位置**，一个空目录或尚不存在的路径。Studio 不会在非空目录中创建项目

启用**版本控制**会在项目目录内建立版本历史。作者、许可证和项目描述可以稍后补充
</Step>
<Step>

### 设置舞台

选择**舞台尺寸**，即游戏 UI 和运行画面的基准尺寸；并选择**剧本语言**，即故事的写作语言。其他语言稍后在本地化面板中添加
</Step>
<Step>

### 确认并创建

在**确认**页核对填写的内容，然后选择**创建项目**。创建完成后 Studio 直接打开工作区
</Step>
</Steps>

## 首次打开

UI 编辑器会打开 `Main Page`，它是项目的默认主页面。可以将它用作标题界面，也可以另建页面

<Figure
    src="/static/img/docs/studio/zh/ui-editor.webp"
    alt="在 UI 编辑器中打开的页面：UI 大纲、画布、插入栏和属性面板"
/>

左侧活动栏是主要的功能入口：

- **项目** —— 元数据、图标、依赖和项目设置
- **故事** —— 故事、章节和场景
- **UI** —— 页面、游戏 UI 和组件库
- **角色** —— 角色形态与差分
- **素材** —— 项目素材及分组
- **本地化** —— 语言、翻译和审校

## 打开已有项目

在启动器中选择**打开项目**或**打开文件夹**，然后选择包含 `.nlproj` 文件的目录。若要打开导出的 `.nlspkg` 项目包，选择**添加项目**，在**来源**一步中导入
