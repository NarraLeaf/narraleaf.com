Studio 有两条输出路径：开发模式用于制作期间检查，正式构建用于生成可分发文件。**导出项目**传递的是可编辑的 Studio 项目，不是玩家使用的构建产物

## 在开发模式中运行

以下任一入口都可以启动开发模式：

- UI 编辑器中画布右上角的播放按钮，从当前页面或游戏 UI 开始
- 顶部操作栏中的运行按钮，运行模式选择**开发模式**
- **开发**菜单

开发模式在独立窗口中打开。修改 UI 文档或蓝图后，重新加载运行中的内容。运行日志和节点跟踪显示在调试工具和控制台中

## 构建发行版本

<Steps>
<Step>

### 打开构建窗口

在顶部操作栏的运行下拉菜单或**开发**菜单中选择**正式构建…**，打开**构建发行版本**窗口

<Figure
    src="/static/img/docs/studio/zh/build-dialog.webp"
    alt="构建发行版本窗口的目标一步，列出各平台及其格式"
/>
</Step>
<Step>

### 选择目标

选择平台、格式和架构。可用目标取决于当前系统：

- Windows 产物可在任意受支持的桌面系统上构建
- macOS 产物必须在 macOS 上构建。两种架构都可选：Studio 自身只在 Apple Silicon 上运行，为 Intel Mac 玩家打包同样可行
- Linux 产物可在 macOS 或 Linux 上构建
- Web、Android 和 iOS 产物可在任意受支持的桌面系统上构建

Android 可产出用于直接安装的 APK、用于 Play 商店上传的 AAB，或两者同时产出；iOS 产出 IPA
</Step>
<Step>

### 检查标识与内容

确认版本号、产品名、应用 ID、版权和图标。版本号使用语义化版本格式，例如 `1.0.0`

窗口中还会列出随包插件、语言、网络策略和资源保护。Web 构建产出可部署的静态站点，资源保护对其不生效
</Step>
<Step>

### 选择输出目录

选择一个可写目录和压缩级别。目录中的同名产物会被覆盖。产物列表在构建前给出预计生成的文件名
</Step>
<Step>

### 开始构建

处理所有阻断项后选择**开始构建**。构建在后台进行，进度和详细输出显示在控制台中
</Step>
</Steps>

要改动已经发布出去的游戏，参见[补丁](/zh/docs/studio/patches)

## 构建前检查

窗口会区分阻断项和警告：

- 无目标、版本号无效或输出目录不可写会阻止构建
- 缺少图标不会阻止构建，但会使用默认的 Electron 图标
- 未配置签名时，桌面产物不会被签名，玩家首次打开时可能看到系统安全提示
- 首次构建某个平台时会下载该平台所需的文件，耗时长于之后的构建

## 导出 Studio 项目

需要移交或归档可编辑项目时，选择**文件 → 导出项目**。Studio 会生成 `.nlspkg` 项目包，接收方在启动器中将其添加到一个空目录

`.nlspkg` 包含项目内容，不是发行构建，也不交给玩家
