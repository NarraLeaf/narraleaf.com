## Requirements

**Windows** — Windows 10 or later, on x64.

**macOS** — macOS 11 or later, on **Apple Silicon**. There is no Intel build of Studio.

<Callout type="warn">
Studio does not run on an Intel Mac. The macOS download is an Apple Silicon binary, and Rosetta only translates in the other direction — it lets Apple Silicon run Intel code, not the reverse. So this is not a reduced-feature mode you can work around: the application will not open at all.

That limits where Studio runs, not who you can ship to. **Intel Mac is still a build target** — a game authored on Apple Silicon can be packaged for players on Intel Macs, alongside every other target. See [Run and Package](/docs/studio/getting-started/run-and-package).
</Callout>

## Install

**Windows** — run the `.exe`. It installs for the current user, so it never asks for administrator rights.

**macOS** — open the `.dmg` and drag NarraLeaf Studio into Applications.

<Callout type="warn">
Builds are not code-signed, so the first launch is blocked.

On Windows, **More info → Run anyway**. On macOS, **System Settings → Privacy & Security → Open Anyway**, or:

```bash
xattr -dr com.apple.quarantine "/Applications/NarraLeaf Studio.app"
```
</Callout>

Studio does not update itself — to update, download the new installer and run it over the existing installation.
