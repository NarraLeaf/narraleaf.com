## Requirements

| Platform | Minimum version | Architecture |
| --- | --- | --- |
| Windows | Windows 10 | x64 |
| macOS | macOS 11 | Apple Silicon |

There is no Intel build of Studio, and it does not run on an Intel Mac. This limits where Studio runs, not what it produces: Intel Mac remains an available build target, and a project authored on Apple Silicon can be packaged for players on Intel Macs. See [Run and Package](/docs/studio/getting-started/run-and-package).

## Install

**Windows** — run the `.exe` installer. Studio installs for the current user and does not require administrator rights.

**macOS** — open the `.dmg` and drag NarraLeaf Studio into Applications.

<Callout type="warn">
Desktop builds are not code-signed, so the first launch is blocked. On Windows, select **More info → Run anyway**. On macOS, select **Open Anyway** under **System Settings → Privacy & Security**, or remove the quarantine attribute:

```bash
xattr -dr com.apple.quarantine "/Applications/NarraLeaf Studio.app"
```
</Callout>

## Updating

Studio does not update itself. To update, download the current installer and run it over the existing installation.
