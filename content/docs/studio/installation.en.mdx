## Requirements

| Platform | Minimum version | Architecture |
| --- | --- | --- |
| Windows | Windows 10 | x64 |
| macOS | macOS 11 | Apple Silicon |

Studio does not run on an Intel Mac. Intel Mac remains available as a build target — see [Run and Package](/docs/studio/getting-started/run-and-package).

## Install

**Windows** — run the `.exe` installer. It installs for the current user by default, without an administrator prompt. The wizard can also change the install directory, or install for all users, which requires administrator approval.

**macOS** — open the `.dmg` and drag NarraLeaf Studio into Applications.

<Callout type="warn">
Studio is not code-signed, and the first launch has to be allowed manually. On Windows, select **More info → Run anyway**. On macOS, select **Open Anyway** under **System Settings → Privacy & Security**, or remove the quarantine attribute:

```bash
xattr -dr com.apple.quarantine "/Applications/NarraLeaf Studio.app"
```
</Callout>

The first launch opens the launcher, which is where projects and plugins are managed.

## Updating

Studio checks for a newer release shortly after launch and reports the result under **Settings → General → Updates**. Downloads do not start on their own. To stop the check, turn off **Check for updates at launch**.

**Windows** — download the update in that panel. Studio installs it on the next restart.

**macOS** — Studio reports the new version only. Download the current `.dmg` and replace the app in Applications.

### Upgrading from 1.3.0 [#upgrading-from-1-3-0]

The Studio release after 1.3.0 keeps a project's interface in version 14 of the format, which adds [page params](/docs/studio/workspace/ui-editor#page-params). Once it has saved a project, Studio 1.3.0 and earlier refuse to open that project, so every computer that opens it needs the same release or later.

### Upgrading to 1.3.0 [#upgrading-to-1-3-0]

Studio 1.3.0 keeps a project's interface in a newer format, version 13. The first time it opens a project made by an earlier version, it upgrades `editor/ui/uidoc.json`, and Studio 1.2.x and earlier refuse to open the project from then on, so every computer that opens it needs 1.3.0 or later. What the upgrade changes is described under [Interface text](/docs/studio/workspace/localization#projects-from-earlier-versions).
