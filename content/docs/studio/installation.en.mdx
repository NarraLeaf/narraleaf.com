## Requirements

**Windows** — Windows 10 or later, on x64.

**macOS** — macOS 11 or later, on **Apple Silicon**. Studio does not support Intel Mac.

<Callout type="warn">
On an Intel Mac, Studio cannot run. The macOS version ships as an Apple Silicon native binary, while Rosetta 2 only supports translating Intel binaries to Apple Silicon architecture and does not provide reverse translation. Therefore, this is not a case of missing features or a workaround that can be bypassed — the application cannot start at all.

It is important to note that the limitation here is Studio's own runtime environment, not the output target platform. Intel Mac remains a valid build target: games authored on Apple Silicon devices can be packaged and distributed to Intel Mac players in the same way as for other platforms. See the “Run and Package” document.
</Callout>

## Install

**Windows** — run the `.exe`. It installs for the current user, so it never asks for administrator rights.

**macOS** — open the `.dmg` and drag NarraLeaf Studio into Applications.

<Callout type="warn">
Builds are not code-signed, so the first launch is blocked.

On Windows, **More info → Run anyway**. On macOS, **System Settings → Privacy & Security → Open Anyway**, or:

```bash
xattr -dr com.apple.quarantine "/Applications/NarraLeaf Studio.app"
```
</Callout>

Studio does not update itself — to update, download the new installer and run it over the existing installation.
