`app.services.story.actions` は、シーンエディターの挿入パレットに、**Tools**（道具）の下でアクションを登録します。各アクションはストーリーブロックを組み立てて挿入します。そのブロックは、プラグインがなくなってもドキュメントに残る標準のストーリーブロックか、ストーリーがその行に来たときに runtime エントリーが実行する、プラグイン独自の行のどちらかです。

## プロジェクトのストーリーを読み取る

`app.services.story` は、作者にストーリー上のある位置を指し示させる必要のあるプラグインパネル――どのシーンを再生するかを名指しする回想エントリーや、どこで解除されるかを名指しする実績――のために、読み取り専用のカタログも備えています。

| メソッド | シグネチャ |
| --- | --- |
| `listStories` | `() => PluginStoryEntry[]` ――`{ id, name }`。ストーリー一覧はすでにメモリ上にあるため、これは同期的です。 |
| `listScenes` | `(storyId: string) => Promise<PluginSceneEntry[]>` ――`{ id, name, storyId }`。作者自身のドキュメントの順序どおりです。ストーリードキュメントが必要になるため、読み込みを待ちます。 |

読み取り専用であるのは意図的なものです。ストーリーの作成と編集は、あくまで Studio が担います。

## `actions` 上のメソッド

| メソッド | シグネチャ |
| --- | --- |
| `register` | `(registration: StoryPluginActionRegistration) => PluginCleanup` |
| `registerMany` | `(registrations: StoryPluginActionRegistration[]) => PluginCleanup` |

## StoryPluginActionRegistration

```ts
type StoryPluginActionRegistration = {
    id: string;                 // あなたのプラグイン id を前置する
    label: string;
    detail?: string;            // パレット内の副次的な行
    group?: string;
    createBlock: (input: { generateId: () => string; initialText?: string }) => StoryBlock;
    describe?: (params: Record<string, unknown>) => string | null | undefined;
    keywords?: readonly string[];                    // コマンド語。どの表示言語でも有効
    params?: readonly StoryPluginActionParamDef[];  // Properties パネルのフィールド
};
```

`createBlock` は `generateId()` を受け取ります――ブロックが必要とする任意の id にはこれを使ってください――また、作者がコマンドの後に入力したテキストを `initialText` として受け取ります。`StoryBlock` を返してください。

作者がこのアクションに届く方法は 2 つあります。コマンドメニューから選ぶか、コマンド語を入力して Enter を押すかです。コマンド語は、`keywords` のいずれかの語かその先頭部分、またはラベルや id の先頭の語です。`/rock rpsResult` は **Rock, Paper, Scissors** というラベルのアクションを、`initialText` を `rpsResult` として挿入します。翻訳されたラベルは作者の表示言語に合わせて変わり、`keywords` は変わりません。どの言語でも使えるコマンド語は `keywords` に書きます。組み込みコマンドの名前である語は、常に組み込みコマンドを指します。1 語でないキーワードは登録時に拒否されます。

`keywords` と `params` を読み取るのは Studio 1.6.0 以降です。それより前のバージョンはこの 2 つを無視します。

```ts
app.services.story.actions.register({
    id: `${PLUGIN_ID}.insertNote`,
    label: "Insert Note",
    createBlock: ({ generateId }) => ({
        id: generateId(),
        // ... 標準のストーリーブロック
    }),
});
```

`StoryBlock`、`StoryBlockId`、`StoryBlockKind` は `narraleaf-studio/plugin` からエクスポートされています。

## プラグイン独自の行

`kind: "action"` で、payload が `action: "plugin"` のブロックは、あなたのプラグイン独自の行です。

```ts
createBlock: ({ generateId, initialText }) => ({
    id: generateId(),
    kind: "action",
    parentId: null,
    childrenIds: [],
    payload: {
        action: "plugin",
        pluginId: PLUGIN_ID,
        actionId: `${PLUGIN_ID}.play`,
        params: { variable: (initialText ?? "").trim() },
    },
}),
```

- `params` には、その行が必要とするものを JSON で入れます。Studio はそれを保存し、アクションが宣言した [Properties パネルのフィールド](#properties-パネルのフィールド)を通してだけ変更します。
- この行はエディターでは何もしません。ゲームの中では、runtime エントリーが同じ `actionId` で [`app.game.storyActions`](/ja/docs/studio/plugin/api-reference#gamestoryactions) に登録した処理がそれを実行し、ストーリーはその終了を待ちます。
- シーンにこの行がある間、プロジェクトはあなたのプラグインに依存し、すべての実行とビルドにプラグインが含まれます。プラグインがないとき、この行は何もせず、プロジェクトはプラグインが足りないことを報告します。

`describe` は、その行が自身の `params` からシーンエディターに表示するテキストです。指定しない場合、何も返さない場合、または例外を投げた場合、行には `label` が表示されます。パラメーターが行の動作を変える場合に指定し、作者がそれを読めるようにします。

```ts
describe: params => `Rock, Paper, Scissors → ${String(params.variable ?? "")}`,
```

## Properties パネルのフィールド

登録の `params` は、そのアクションの行を選択したときに Properties パネルに表示するフィールドの一覧です。各フィールドは行の `params` のキーを 1 つ編集し、その編集はほかの行の編集と同じくシーンの元に戻す履歴に入ります。フィールドを空にすると、そのキーは削除されます。

```ts
type StoryPluginActionParamDef = {
    key: string;                                   // フィールドが編集する params のキー
    label: string;
    kind: "select" | "string" | "number";
    options?: { value: string; label: string }[];  // select の固定の選択肢
    dynamicOptionsSource?: string;                 // または登録済みのソースから select の選択肢を取る
    emptyOptionLabel?: string;                     // 空の選択肢の表示。既定は "-"
};
```

これはブループリントノードの `inspectorParams` の 1 項目を、この 3 種類の kind に限ったものです。同じ一覧から選ぶノードと行は、1 つのオブジェクトを共有できます。`dynamicOptionsSource` を持つ `select` は、[`registerDynamicSelectOptionsSource`](/ja/docs/studio/plugin/studio/blueprint-nodes) で登録したソースが返す選択肢を、ノードカードでも Properties パネルでも同じように表示します。

```ts
const achievementParam = {
    key: "achievementId",
    label: "Achievement",
    kind: "select",
    dynamicOptionsSource: `${PLUGIN_ID}.achievements`,
} as const;

app.services.story.actions.register({
    id: `${PLUGIN_ID}.story.unlock`,
    label: "Unlock Achievement",
    keywords: ["unlock"],
    params: [achievementParam],
    createBlock: ({ generateId, initialText }) => ({
        id: generateId(),
        kind: "action",
        parentId: null,
        childrenIds: [],
        payload: {
            action: "plugin",
            pluginId: PLUGIN_ID,
            actionId: `${PLUGIN_ID}.story.unlock`,
            params: initialText?.trim() ? { achievementId: initialText.trim() } : {},
        },
    }),
    describe: params => `Unlock achievement ${String(params.achievementId ?? "")}`,
});
```

- `/unlock ACH_WIN` は `ACH_WIN` を選択した状態で行を挿入します。コマンドメニューから選んだ行は何も選択されていない状態で入り、作者が Properties パネルで選びます。
- 一覧にもう含まれない値が行に保存されている場合、その値は行に残り、作者が別の値を選ぶまでフィールドは見つからない値として表示します。
- 実行中の Studio が対応していない kind のフィールドは、パネルに表示されません。`params` が配列でない場合、`key` や `label` のない項目がある場合、同じキーを 2 回宣言した場合は、登録時に拒否されます。

アクションから、それが実行するゲームまでの一式は、[例：じゃんけん](/ja/docs/studio/plugin/rock-paper-scissors)にあります。
