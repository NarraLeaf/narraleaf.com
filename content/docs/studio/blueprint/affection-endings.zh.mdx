title: 示例：好感度与多结局
description: 用存档变量记录好感度，选项改变它，对话框用蓝图值显示它，结局由条件和图条件判定，标题页显示已达成的结局
---

本页在**骨架**模板创建的项目上做一个好感度系统。玩家的选择增加 Narra 的好感度，对话框右侧用心形显示当前好感度。好感度够高时，Narra 会多问一句；故事最后按好感度和之前的选择走向三个结局之一。标题页显示已经达成了几个结局

| 部分 | 位置 | 在这里做什么 |
| --- | --- | --- |
| 存档变量`好感度` | **变量**面板 | 保存好感度，随存档保存和读取 |
| `/inc`、`/if`、`/ending` | 场景 | 增加好感度，按好感度分支，标记结局 |
| 蓝图值 | 游戏 UI **对话**中的文本 | 读取好感度，显示为心形 |
| 图条件 | 结局分支 | 用蓝图同时检查好感度和`真心` |
| `Get Endings`（获取结局列表） | 页面**标题**中的文本 | 显示已达成的结局数 |

三个结局：

| 结局 | 条件 |
| --- | --- |
| 一起的文化祭 | 好感度至少 35，并且在社团活动室选了「做点真心的东西。」 |
| 明天老时间 | 好感度至少 20 |
| 空着的座位 | 其他情况 |

## 准备

用**骨架**模板新建项目，步骤见[入门](/zh/docs/studio/getting-started)。骨架的三个场景依次是**走廊**、**社团活动室**和**最后的光**。**社团活动室**的菜单把选择写进存档变量`真心`，**最后的光**按`真心`显示不同的台词，以结局**明天老时间**结束

下文先声明变量，再依次修改三个场景，最后修改游戏 UI **对话**和页面**标题**

## 1. 声明变量

在右侧栏打开**变量**，在**存档变量**一栏点**添加**。把新变量命名为`好感度`，类型设为**数字**，默认值保持`0`

存档变量属于整个项目，每个场景和每个蓝图都能读写它。它的值写进存档，读档时恢复，开始新游戏时回到默认值。其他作用域见[变量](/zh/docs/studio/blueprint/variables)

## 2. 让选择改变好感度

<Steps>
<Step>

### 走廊

在 Narra 的台词「一个半。天还没黑你就走了。」之后新建一行，输入`/menu`并按两次 Enter。Studio 插入一个菜单和它的第一个选项。在菜单行上点**添加选项**再加一个选项，双击选项写上文字，再在选项上点**在内部添加动作**，写入选中它之后的行：

| 选项 | 选项内的行 |
| --- | --- |
| 今天我待到最后。 | Narra：「……这可是你说的。」<br />`/inc 好感度 10` |
| 社团又不会跑。 | Narra：「社团不会跑，人会。」 |

</Step>
<Step>

### 社团活动室

菜单**我们做什么？**的两个选项内各有一行`/set 真心 …`。在这两行之后分别加入：

| 选项 | 加入的行 |
| --- | --- |
| 做点真心的东西。 | `/inc 好感度 20` |
| 做点真的会有人来的东西。 | `/inc 好感度 10` |

</Step>
</Steps>

输入`/inc 好感度 20`并按 Enter 后，这一行显示为**增加 好感度 20**。`/inc`省略数值时加 1，`/dec`减少；`/set 好感度 好感度 + 20`效果相同

/>

## 3. 在对话框上显示好感度

对话框右侧显示 5 颗心，好感度每 10 点填满一颗

<Steps>
<Step>

### 添加文本

在左侧活动栏选择 **UI**，把**界面类型**设为**游戏 UI**，打开**对话**。从画布下方的工具栏把**文本**拖到对话底带右侧，命名为`好感度`，文字右对齐。骨架的名牌右侧有空位：位置 X 1420、Y 754，尺寸 320 × 46

</Step>
<Step>

### 把文字交给蓝图值

选中这个文本，在属性面板的**内容**中，把**文本**从**直接写**切换为**蓝图值**。Studio 为它创建一个蓝图值，原来的文字成为**示例文字**，只在编辑器中显示。点**打开蓝图值**

<Figure
    src="/static/img/docs/studio/zh/affection-meter-text.webp"
    alt="UI 编辑器中打开的游戏 UI 对话，选中的文本好感度在属性面板中以蓝图值提供文字，示例文字是两颗实心心和三颗空心心"
/>

</Step>
<Step>

### 搭建图

蓝图值中已有`Init`（初始化）连到`Return Value`（返回值），由一个`String`（字符串）提供原来的文字。删除`String`，按下表加入节点并连线：

| 节点 | 设置 | 连到 |
| --- | --- | --- |
| `Init`（初始化） | | 执行连到`Get Saved Var` |
| `Get Saved Var`（获取存档变量） | **存档变量**选`好感度` | 执行连到`Return Value`；**值**连到`÷`的 **A** |
| `÷` | **B** 填`10` | **结果**连到`Floor`的**数字** |
| `Floor`（向下取整） | | **结果**连到`Repeat`的**数量** |
| `Repeat`（重复） | **值**填`♥` | **结果**连到`Pad End`的**值** |
| `Pad End`（尾部填充） | **长度**填`5`，**填充字符**填`♡` | **结果**连到`Return Value`的**值** |

<Figure
    src="/static/img/docs/studio/zh/affection-meter-graph.webp"
    alt="好感度的蓝图值：初始化接获取存档变量再接返回值，值依次经过除以 10、向下取整、重复和尾部填充"
/>

</Step>
</Steps>

蓝图值读取的存档变量每次被写入，文本都重新求值：故事执行`/inc`的那一刻、读档时和开始新游戏时，对话框上的心形随之变化

    src="/static/img/docs/studio/zh/affection-stage.webp"
    alt="开发模式中 Narra 询问之后的两个选项，对话框右侧显示三颗实心心和两颗空心心"
/>

## 4. 按好感度分支

在**最后的光**中，`真心`的条件之后、Narra 的台词「明天老时间。别再迟到了。」之前新建一行，输入`/if 好感度 >= 20`并按 Enter。在**如果**下面加入：

- Narra：「回去的路上……要不要一起走到车站？」
- 一个菜单。选项「好啊。」内写 Narra：「那就说定了。」和`/inc 好感度 15`；选项「今天就算了。」内写 Narra：「……嗯。也是。」

好感度低于 20 时，故事跳过整个分支。这个条件没有**否则**，不满足时直接执行下一行

`/if`的条件是表达式，可以使用比较、`&&`、`||`和`!`。在属性面板中也可以把条件切换为**变量**，用下拉框选择变量和比较方式

## 5. 三个结局

删除**最后的光**末尾的两行旁白和结局**明天老时间**。在场景末尾输入`/if 好感度 >= 35 && 真心`并按 Enter，然后在**条件**行上点**否则如果**和**否则**，加入另外两个分支：

| 分支 | 条件 | 分支内的行 |
| --- | --- | --- |
| 如果 | `好感度 >= 35 && 真心` | 旁白「文化祭那天，第一个推开活动室门的是 Narra。」<br />`/ending 一起的文化祭` |
| 否则如果 | `好感度 >= 20` | `/ending 明天老时间` |
| 否则 | | 旁白「第二天，我没有去社团。」<br />`/ending 空着的座位` |

`/ending`在这一行结束故事，并记录玩家到达了哪个结局

### 用蓝图计算条件

条件也可以交给蓝图计算。下面把第一个分支改为图条件，判定结果与表达式`好感度 >= 35 && 真心`相同

<Steps>
<Step>

### 切换为图

选中第一个分支的**如果**行，在属性面板中把条件从**表达式**切换为**图**，再点下面的预览卡片。Studio 创建条件蓝图，并在**条件**标签页中打开它。这一行的条件显示为**图条件**

<Figure
    src="/static/img/docs/studio/zh/affection-endings.webp"
    alt="最后的光末尾的三个分支，每个分支以结局行结束，第一个分支的条件显示为图条件，属性面板中条件类型为图"
/>

</Step>
<Step>

### 搭建图

图中已有`On Call`（被调用时）连到`Return Value`（返回值），由一个`Boolean`（布尔值）提供值。删除`Boolean`，按下表加入节点：

| 节点 | 设置 | 连到 |
| --- | --- | --- |
| `On Call`（被调用时） | | 执行连到第一个`Get Saved Var` |
| `Get Saved Var`（获取存档变量） | **存档变量**选`好感度` | 执行连到第二个`Get Saved Var`；**值**连到`Greater Than Or Equal`的 **A** |
| `Get Saved Var`（获取存档变量） | **存档变量**选`真心` | 执行连到`Return Value`；**值**连到`And`的 **A** |
| `Greater Than Or Equal`（大于或等于） | **B** 填`35` | **结果**连到`And`的 **B** |
| `And`（与） | | **结果**连到`Return Value`的**值** |

<Figure
    src="/static/img/docs/studio/zh/affection-condition.webp"
    alt="条件蓝图：被调用时接两个获取存档变量再接返回值，好感度经大于或等于 35 与真心一起进入与节点"
/>

</Step>
</Steps>

故事每次走到这个分支都运行一次图，`Return Value`交出的值为真时进入分支。图条件中不能使用需要等待的节点，例如`Get Persistent`（获取持久变量）；表达式写不出的计算，例如`Random Integer`（随机整数），可以放进图条件

实时预览把图条件当作不成立。结局分支在开发模式中检查

## 6. 结局之后回到标题

打开**项目** → **应用**，在**变体**中展开 **main**，把**剧本结束后显示的页面**设为**标题**。结局行在故事结束后显示这个页面。单个结局行可以在属性面板的**结束后显示的页面**中另选页面

## 7. 在标题页显示已达成的结局

玩家到达过的结局记录在存档之外：读档、开始新游戏或重新启动游戏都不会清除它

打开页面**标题**，在标题分隔线下方放一个**文本**，命名为`结局进度`。把**文本**切换为**蓝图值**并打开，按下表搭建：

| 节点 | 设置 | 连到 |
| --- | --- | --- |
| `Init`（初始化） | | 执行连到`Return Value` |
| `Get Endings`（获取结局列表） | **故事**选`骨架` | **结局列表**连到`Array Filter By Key`的**数组** |
| `Boolean`（布尔值） | 真 | 连到`Array Filter By Key`的**值** |
| `Array Filter By Key`（数组按键筛选） | **键**填`isReached` | **数组**连到`Array Length` |
| `Array Length`（数组长度） | | **长度**连到`Make Array`的**项 1** |
| `Get Endings`（获取结局列表） | **故事**选`骨架` | **结局列表**连到第二个`Array Length` |
| `Array Length`（数组长度） | | **长度**连到`Make Array`的**项 2** |
| `Make Array`（创建数组） | 两项 | **数组**连到`Format`的**值列表** |
| `Format`（格式化） | **模板**填`已达成结局 {0} / {1}` | **结果**连到`Return Value`的**值** |

`Get Endings`列出故事中的每一行结局，每一项的`isReached`表示玩家是否到达过。第一个`Get Endings`筛出到达过的结局，第二个计算全部结局

<Figure
    src="/static/img/docs/studio/zh/affection-endings-graph.webp"
    alt="结局进度的蓝图值：两个获取结局列表，一个经数组按键筛选和数组长度，一个只经数组长度，两个数进入创建数组再由格式化写成一句话"
/>

模板是写在图中的文字，不随游戏语言切换。项目有多种语言时，用`Translation Key Text`（翻译键文本）提供模板

## 试玩与检查

- 按 **F5** 在开发模式中运行项目。在一行上点**从这一行开始播放**，从那一行开始运行
- 开发模式左下角的调试按钮 → **故事** → **变量**列出存档变量的当前值，并可以直接修改。把`好感度`改成 40、打开`真心`，再走到结局，检查**一起的文化祭**
- 开发模式按钮旁的箭头 → **重置玩家数据** → **开发模式**，清除开发模式的所有存档和结局记录。标题页回到`已达成结局 0 / 3`
- 在**故事**面板中点**打开场景流程**，在变量列表中选`好感度`。每个场景显示到达时好感度的范围；**展开分支**显示每个选项的增减，以及以结局结束的分支
- 条件的门槛高于任何路线能达到的值时，**问题**面板报告**没有路径能满足的条件**，并给出该处好感度的范围
