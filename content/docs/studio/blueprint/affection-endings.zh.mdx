title: 示例：好感度与多结局
description: 用存档变量记录好感度，在选项中修改它，用蓝图值在对话框中显示它，按它进入不同结局，并在标题页显示已达成的结局数
---

本示例在**骨架**模板创建的项目中实现一个好感度系统：

- 选项增加存档变量`好感度`
- 对话框右侧显示`好感度`的当前值
- `好感度`不低于 20 时出现一段额外分支
- 故事结尾根据`好感度`和`真心`进入三个结局之一
- 标题页显示已达成的结局数

| 部分 | 位置 | 作用 |
| --- | --- | --- |
| 存档变量`好感度` | **变量**面板 | 保存好感度，随存档保存和读取 |
| `/inc`、`/if`、`/ending` | 场景 | 增加好感度，按好感度分支，标记结局 |
| 蓝图值 | 游戏 UI **对话**中的文本 | 读取`好感度`并显示 |
| `Get Endings`（获取结局列表） | 页面**标题**中的文本 | 显示已达成的结局数 |

| 结局 | 条件 |
| --- | --- |
| 一起参加文化祭 | `好感度`不低于 35，且在社团活动室选择了「做点真心的东西。」 |
| 明天老时间 | `好感度`不低于 20 |
| 离开社团 | 其他情况 |

## 准备

使用**骨架**模板新建项目，步骤见[入门](/zh/docs/studio/getting-started)。骨架包含**走廊**、**社团活动室**和**最后的光**三个场景。**社团活动室**的菜单将选择写入存档变量`真心`；**最后的光**根据`真心`显示不同的台词，并以结局**明天老时间**结束

以下步骤依次声明变量、修改三个场景，最后修改游戏 UI **对话**和页面**标题**

## 1. 声明变量

在右侧栏打开**变量**，在**存档变量**中点击**添加**。将新变量命名为`好感度`，类型设为**数字**，默认值保留`0`

存档变量属于整个项目，所有场景和蓝图都可以读写。其值写入存档，读档时恢复，开始新游戏时重置为默认值。其他作用域见[变量](/zh/docs/studio/blueprint/variables)

## 2. 在选项中修改好感度

<Steps>
<Step>

### 走廊

在 Narra 的台词「一个半。天还没黑你就走了。」之后新建一行，输入`/menu`并按两次 Enter，Studio 插入一个菜单及其第一个选项。在菜单行上点击**添加选项**添加第二个选项，双击选项输入文字，然后在选项上点击**在内部添加动作**，输入选择该选项后执行的行：

| 选项 | 选项内的行 |
| --- | --- |
| 今天我待到最后。 | Narra：「那今天一起锁门。」<br />`/inc 好感度 10` |
| 今天有别的事。 | Narra：「知道了。」 |

</Step>
<Step>

### 社团活动室

菜单**我们做什么？**的两个选项中各有一行`/set 真心 …`，在其后分别加入：

| 选项 | 加入的行 |
| --- | --- |
| 做点真心的东西。 | `/inc 好感度 20` |
| 做点真的会有人来的东西。 | `/inc 好感度 10` |

</Step>
</Steps>

输入`/inc 好感度 20`并按 Enter 后，该行显示为**增加 好感度 20**。`/inc`省略数值时加 1，`/dec`用于减少，`/set 好感度 好感度 + 20`与`/inc 好感度 20`效果相同

/>

## 3. 在对话框中显示好感度

<Steps>
<Step>

### 添加文本

在左侧活动栏选择 **UI**，在**界面**中选择**游戏 UI**，打开**对话**。从画布下方的工具栏将**文本**拖到对话底带右侧，命名为`好感度`，文字设为右对齐。该位置在名牌右侧：位置 X 1420、Y 754，尺寸 320 × 46

</Step>
<Step>

### 将文本设为蓝图值

选中该文本，在属性面板的**内容**中将**文本**从**直接输入**切换为**蓝图值**。Studio 为其创建蓝图值，原有文字成为**示例文字**，仅在编辑器中显示。点击**打开蓝图值**

<Figure
    src="/static/img/docs/studio/zh/affection-meter-text.webp"
    alt="UI 编辑器中打开的游戏 UI 对话，选中的文本好感度在属性面板中使用蓝图值，示例文字为好感度：30"
/>

</Step>
<Step>

### 搭建图

蓝图值中已有`Init`（初始化）连接到`Return Value`（返回值），并由一个`String`（字符串）提供原有文字。删除`String`，按下表加入节点并连线：

| 节点 | 设置 | 连接到 |
| --- | --- | --- |
| `Init`（初始化） | | 执行连接到`Get Saved Var` |
| `Get Saved Var`（获取存档变量） | **存档变量**选择`好感度` | 执行连接到`Return Value`；**值**连接到`Concat`的 **B** |
| `Concat`（拼接） | **A** 填写`好感度：` | **结果**连接到`Return Value`的**值** |

<Figure
    src="/static/img/docs/studio/zh/affection-meter-graph.webp"
    alt="好感度的蓝图值：初始化连接到获取存档变量和返回值，存档变量的值经拼接加上前缀后连接到返回值"
/>

</Step>
</Steps>

蓝图值读取的存档变量每次写入后，文本都会重新求值。执行`/inc`、读档和开始新游戏时，对话框中的数值都会更新

<Figure
    src="/static/img/docs/studio/zh/affection-stage.webp"
    alt="开发模式中 Narra 提问后的两个选项，对话框右侧显示好感度：30"
/>

## 4. 按好感度分支

在**最后的光**中，于`真心`的条件之后、Narra 的台词「明天老时间。别再迟到了。」之前新建一行，输入`/if 好感度 >= 20`并按 Enter，在**如果**下加入：

- Narra：「回去的时候，要一起走到车站吗？」
- 一个菜单：选项「一起走吧。」内为 Narra：「好。」和`/inc 好感度 15`；选项「今天不行。」内为 Narra：「那下次吧。」

`好感度`低于 20 时跳过整个分支。该条件没有**否则**分支，不满足时继续执行下一行

`/if`的条件是表达式，支持比较运算以及`&&`、`||`和`!`。也可以在属性面板中将条件切换为**变量**，从下拉框选择变量和比较方式

## 5. 三个结局

删除**最后的光**末尾的两行旁白和结局**明天老时间**。在场景末尾输入`/if 好感度 >= 35 && 真心`并按 Enter，然后在**条件**行上点击**否则如果**和**否则**，加入另外两个分支：

| 分支 | 条件 | 分支内的行 |
| --- | --- | --- |
| 如果 | `好感度 >= 35 && 真心` | 旁白「文化祭当天，我和 Narra 一起布置了社团活动室。」<br />`/ending 一起参加文化祭` |
| 否则如果 | `好感度 >= 20` | `/ending 明天老时间` |
| 否则 | | 旁白「之后，我没有再去社团。」<br />`/ending 离开社团` |

`/ending`在该行结束故事，并记录玩家到达的结局

<Figure
    src="/static/img/docs/studio/zh/affection-endings.webp"
    alt="最后的光末尾的三个分支，每个分支以结局行结束，选中的第一个分支在属性面板中显示条件表达式"
/>

## 6. 结局后返回标题页

打开**项目** → **应用**，在**变体**中展开 **main**，将**剧本结束后显示的页面**设为**标题**。故事在结局行结束后显示该页面。单个结局行可以在属性面板的**结束后显示的页面**中指定其他页面

## 7. 在标题页显示已达成的结局

玩家到达的结局记录在存档之外，读档、开始新游戏和重新启动游戏都不会清除该记录

打开页面**标题**，在标题分隔线下方添加一个**文本**，命名为`结局进度`。将**文本**切换为**蓝图值**并打开，按下表搭建：

| 节点 | 设置 | 连接到 |
| --- | --- | --- |
| `Init`（初始化） | | 执行连接到`Return Value` |
| `Get Endings`（获取结局列表） | **故事**选择`骨架` | **结局列表**连接到`Array Filter By Key`的**数组** |
| `Boolean`（布尔值） | 真 | 连接到`Array Filter By Key`的**值** |
| `Array Filter By Key`（数组按键筛选） | **键**填写`isReached` | **数组**连接到`Array Length` |
| `Array Length`（数组长度） | | **长度**连接到`Make Array`的**项 1** |
| `Get Endings`（获取结局列表） | **故事**选择`骨架` | **结局列表**连接到第二个`Array Length` |
| `Array Length`（数组长度） | | **长度**连接到`Make Array`的**项 2** |
| `Make Array`（创建数组） | 两项 | **数组**连接到`Format`的**值列表** |
| `Format`（格式化） | **模板**填写`已达成结局 {0} / {1}` | **结果**连接到`Return Value`的**值** |

`Get Endings`列出故事中的所有结局行，每一项的`isReached`表示玩家是否到达过该结局。第一个`Get Endings`筛选出已到达的结局，第二个统计全部结局

<Figure
    src="/static/img/docs/studio/zh/affection-endings-graph.webp"
    alt="结局进度的蓝图值：两个获取结局列表，一个经数组按键筛选和数组长度，另一个只经数组长度，两个数值进入创建数组，再由格式化生成文字"
/>

模板是写在图中的文字，不随游戏语言切换。项目包含多种语言时，使用`Translation Key Text`（翻译键文本）提供模板

## 测试与检查

- 按 **F5** 在开发模式中运行项目。在某一行上点击**从这一行开始播放**，从该行开始运行
- 开发模式左下角的调试按钮 → **故事** → **变量**列出存档变量的当前值，并可直接修改。将`好感度`改为 40、打开`真心`后运行到结尾，检查结局**一起参加文化祭**
- 开发模式按钮旁的箭头 → **重置玩家数据** → **开发模式**，清除开发模式的全部存档和结局记录，标题页恢复为`已达成结局 0 / 3`
- 在**故事**面板中点击**打开场景流程**，在变量列表中选择`好感度`。每个场景显示到达时`好感度`的范围；**展开分支**显示每个选项的增减量，以及以结局结束的分支
- 条件的阈值高于任何路线可达到的值时，**问题**面板报告**没有路径能满足的条件**，并给出该处`好感度`的范围
