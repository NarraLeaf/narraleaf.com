このページでは、**Skeleton**（スケルトン）テンプレートで作ったプロジェクトに好感度の仕組みを組み込みます。プレイヤーの選択で Narra の好感度が上がり、会話ボックスの右側にハートで現在の好感度が表示されます。好感度が十分に高いと Narra がもう一言たずね、ストーリーは好感度と以前の選択によって 3 つのエンディングのどれかで終わります。タイトルページには、到達したエンディングの数が表示されます。

| 部品 | 場所 | ここでの役割 |
| --- | --- | --- |
| セーブ変数 `好感度` | **Variables**（変数）パネル | 好感度を保持し、セーブとロードで保存・復元されます。 |
| `/inc`、`/if`、`/ending` | シーン | 好感度を増やし、好感度で分岐し、エンディングを記録します。 |
| ブループリント値 | ゲーム UI「会話」のテキスト | 好感度を読み、ハートで表示します。 |
| グラフの条件 | エンディングの分岐 | 好感度と `正直` をブループリントでまとめて確かめます。 |
| `Get Endings`（エンディング一覧を取得） | ページ「タイトル」のテキスト | 到達したエンディングの数を表示します。 |

3 つのエンディング：

| エンディング | 条件 |
| --- | --- |
| 二人の文化祭 | 好感度が 35 以上で、部室で「正直なものを。」を選んだ |
| 明日も同じ時間 | 好感度が 20 以上 |
| 空いた席 | それ以外 |

## 準備

**Skeleton**（スケルトン）テンプレートで新しいプロジェクトを作ります。手順は[はじめに](/ja/docs/studio/getting-started)を参照してください。スケルトンのシーンは順に「廊下」「部室」「最後の光」です。「部室」のメニューは選択をセーブ変数 `正直` に書き込み、「最後の光」は `正直` によって異なる台詞を表示し、エンディング「明日も同じ時間」で終わります。

以下では、まず変数を宣言し、3 つのシーンを順に変更し、最後にゲーム UI「会話」とページ「タイトル」を変更します。

## 1. 変数を宣言する

右サイドバーで **Variables**（変数）を開き、**Saved variables**（セーブ変数）の **Add**（追加）をクリックします。新しい変数の名前を `好感度` にし、型を **Number**（数値）にして、既定値は `0` のままにします。

セーブ変数はプロジェクト全体に属し、どのシーンとどのブループリントからも読み書きできます。値はセーブに書き込まれ、ロードで戻り、新しいゲームを始めると既定値に戻ります。ほかのスコープについては[変数](/ja/docs/studio/blueprint/variables)を参照してください。

## 2. 選択で好感度を変える

<Steps>
<Step>

### 廊下

Narra の台詞「一人半ね。暗くなる前に帰っちゃうんだから。」のあとに行を追加し、`/menu` と入力して Enter を 2 回押します。Studio がメニューと最初の選択肢を挿入します。メニューの行で **Add option**（選択肢を追加）をクリックして選択肢をもう 1 つ追加し、選択肢をダブルクリックして文を書き、選択肢の **Add action inside**（中にアクションを追加）をクリックして、選んだあとに続く行を書きます：

| 選択肢 | 選択肢の中の行 |
| --- | --- |
| 今日は最後までいる。 | Narra：「……言ったからね。」<br />`/inc 好感度 10` |
| 部活は逃げないよ。 | Narra：「部活は逃げない。人は逃げる。」 |

</Step>
<Step>

### 部室

メニュー「何を作る？」の 2 つの選択肢には、それぞれ `/set 正直 …` の行があります。それぞれの行のあとに次の行を追加します：

| 選択肢 | 追加する行 |
| --- | --- |
| 正直なものを。 | `/inc 好感度 20` |
| ちゃんと人が来るものを。 | `/inc 好感度 10` |

</Step>
</Steps>

`/inc 好感度 20` と入力して Enter を押すと、行は **inc 好感度 20** と表示されます（日本語のインターフェースでは **増加 好感度 20**）。数を省くと `/inc` は 1 を足し、`/dec` は減らします。`/set 好感度 好感度 + 20` も同じ結果になります。

<Figure
    src="/static/img/docs/studio/en/affection-story.webp"
    alt="部室の 2 つの選択肢の最後にそれぞれ inc の行があり、右側の Variables パネルのセーブ変数に好感度（数値、既定値 0）と正直がある"
/>

## 3. 会話ボックスに好感度を表示する

会話ボックスの右側に 5 つのハートを表示し、好感度 10 ごとに 1 つ塗りつぶします。

<Steps>
<Step>

### テキストを追加する

左のアクティビティバーで **UI** を選び、**Interface Type**（インターフェースの種類）を **Game UI**（ゲーム UI）にして「会話」を開きます。キャンバスの下のツールバーから **Text**（テキスト）を会話帯の右側にドラッグし、名前を `好感度` にして文字を右揃えにします。スケルトンのネームタグの右側が空いています：位置 X 1420、Y 754、サイズ 320 × 46。

</Step>
<Step>

### 文字をブループリント値に任せる

テキストを選択し、プロパティパネルの **Content**（内容）で **Text**（テキスト）を **Direct**（直接入力）から **Blueprint Value**（ブループリント値）に切り替えます。Studio がブループリント値を作り、元の文字はエディターだけに表示される **Sample text**（サンプルテキスト）になります。**Open Blueprint Value**（ブループリント値を開く）をクリックします。

<Figure
    src="/static/img/docs/studio/en/affection-meter-text.webp"
    alt="UI エディターで開いたゲーム UI の会話。選択したテキストはプロパティパネルでブループリント値から文字を受け取り、サンプルテキストは塗りつぶしたハート 2 つと空のハート 3 つ"
/>

</Step>
<Step>

### グラフを組む

ブループリント値には、`Init`（初期化）から `Return Value`（値を返す）への接続と、元の文字を渡す `String`（文字列）がすでにあります。`String` を削除し、次のノードを追加して接続します：

| ノード | 設定 | 接続先 |
| --- | --- | --- |
| `Init`（初期化） | | 実行を `Get Saved Var` へ |
| `Get Saved Var`（セーブ変数を取得） | **Saved variable**（セーブ変数）：`好感度` | 実行を `Return Value` へ。**Value**（値）を `÷` の **A** へ |
| `÷` | **B**：`10` | **Result**（結果）を `Floor` の **Number**（数値）へ |
| `Floor`（切り捨て） | | **Result** を `Repeat` の **Count**（個数）へ |
| `Repeat`（繰り返す） | **Value**：`♥` | **Result** を `Pad End` の **Value** へ |
| `Pad End`（末尾を埋める） | **Length**（長さ）：`5`、**Pad**（埋める）：`♡` | **Result** を `Return Value` の **Value** へ |

<Figure
    src="/static/img/docs/studio/en/affection-meter-graph.webp"
    alt="好感度のブループリント値：Init から Get Saved Var、Return Value へ進み、値は 10 での割り算、Floor、Repeat、Pad End を順に通る"
/>

</Step>
</Steps>

ブループリント値が読むセーブ変数に書き込みがあるたびに、テキストは計算し直されます。ストーリーが `/inc` を実行した瞬間、ロードしたとき、新しいゲームを始めたときに、会話ボックスのハートも変わります。

<Figure
    src="/static/img/docs/studio/en/affection-stage.webp"
    alt="開発モードで Narra の問いかけのあとに 2 つの選択肢が表示され、会話ボックスの右側に塗りつぶしたハート 3 つと空のハート 2 つがある"
/>

## 4. 好感度で分岐する

「最後の光」で、`正直` の条件のあと、Narra の台詞「明日も同じ時間。遅れないで。」の前に行を追加し、`/if 好感度 >= 20` と入力して Enter を押します。**If** の下に次を追加します：

- Narra：「帰り道……駅まで一緒に歩く？」
- メニュー。選択肢「うん。」の中に Narra：「じゃあ、決まり。」と `/inc 好感度 15`、選択肢「今日はやめとく。」の中に Narra：「……そう。だよね。」

好感度が 20 未満のとき、ストーリーは分岐全体を飛ばします。この条件には **Else**（それ以外）がないため、成り立たないときは次の行に進みます。

`/if` の条件は式で、比較、`&&`、`||`、`!` を使えます。プロパティパネルで条件を **Variable**（変数）に切り替え、ドロップダウンで変数と比較を選ぶこともできます。

## 5. 3 つのエンディング

「最後の光」の末尾にある 2 行のナレーションとエンディング「明日も同じ時間」を削除します。シーンの末尾で `/if 好感度 >= 35 && 正直` と入力して Enter を押し、条件の行で **Else if**（そうでなくもし）と **Else**（それ以外）をクリックして、残り 2 つの分岐を追加します：

| 分岐 | 条件 | 分岐の中の行 |
| --- | --- | --- |
| If | `好感度 >= 35 && 正直` | ナレーション「文化祭の日、最初に部室の扉を開けたのは Narra だった。」<br />`/ending 二人の文化祭` |
| Else if | `好感度 >= 20` | `/ending 明日も同じ時間` |
| Else | | ナレーション「次の日、わたしは部活に行かなかった。」<br />`/ending 空いた席` |

`/ending` はその行でストーリーを終え、プレイヤーがどのエンディングに到達したかを記録します。

### ブループリントで条件を計算する

条件はブループリントに計算させることもできます。以下では最初の分岐をグラフの条件に変えます。判定の結果は式 `好感度 >= 35 && 正直` と同じです。

<Steps>
<Step>

### グラフに切り替える

最初の分岐の **If** の行を選択し、プロパティパネルで条件を **Expression**（式）から **Graph**（グラフ）に切り替えて、その下のプレビューカードをクリックします。Studio が条件のブループリントを作り、**Condition**（条件）タブで開きます。行の条件は **Graph condition**（グラフの条件）と表示されます。

<Figure
    src="/static/img/docs/studio/en/affection-endings.webp"
    alt="最後の光の末尾にある 3 つの分岐。どれもエンディングの行で終わり、最初の分岐の条件は Graph condition と表示され、プロパティパネルの条件の種類は Graph"
/>

</Step>
<Step>

### グラフを組む

グラフには、`On Call`（呼ばれたとき）から `Return Value`（値を返す）への接続と、値を渡す `Boolean`（真偽値）がすでにあります。`Boolean` を削除し、次のノードを追加します：

| ノード | 設定 | 接続先 |
| --- | --- | --- |
| `On Call`（呼ばれたとき） | | 実行を 1 つ目の `Get Saved Var` へ |
| `Get Saved Var`（セーブ変数を取得） | **Saved variable**：`好感度` | 実行を 2 つ目の `Get Saved Var` へ。**Value** を `Greater Than Or Equal` の **A** へ |
| `Get Saved Var`（セーブ変数を取得） | **Saved variable**：`正直` | 実行を `Return Value` へ。**Value** を `And` の **A** へ |
| `Greater Than Or Equal`（以上） | **B**：`35` | **Result** を `And` の **B** へ |
| `And`（かつ） | | **Result** を `Return Value` の **Value** へ |

<Figure
    src="/static/img/docs/studio/en/affection-condition.webp"
    alt="条件のブループリント：On Call から 2 つの Get Saved Var、Return Value へ進み、好感度は Greater Than Or Equal 35 を通って正直と一緒に And に入る"
/>

</Step>
</Steps>

ストーリーがこの分岐に来るたびにグラフが実行され、`Return Value` に渡された値が真なら分岐に入ります。グラフの条件では、`Get Persistent` のように待機するノードは使えません。`Random Integer` のように式では書けない計算は、グラフの条件に置けます。

ライブプレビューはグラフの条件を偽として扱います。エンディングの分岐は開発モードで確かめます。

## 6. エンディングのあとタイトルに戻る

**Project**（プロジェクト）→ **App**（アプリ）を開き、**Build variants**（ビルドバリアント）で **main** を展開して、**Page shown when the story ends**（ストーリーが終わったときに出すページ）を「タイトル」にします。エンディングの行は、ストーリーが終わったあとにこのページを表示します。1 つのエンディングの行だけ別のページにするには、プロパティパネルの **Page shown afterwards**（終了後に表示するページ）で選びます。

## 7. タイトルページに到達したエンディングを表示する

プレイヤーが到達したエンディングはセーブの外に記録されます。ロード、新しいゲームの開始、ゲームの再起動では消えません。

ページ「タイトル」を開き、タイトル区切り線の下に **Text**（テキスト）を置いて名前を `エンディング` にします。**Text** を **Blueprint Value**（ブループリント値）に切り替えて開き、次のように組みます：

| ノード | 設定 | 接続先 |
| --- | --- | --- |
| `Init`（初期化） | | 実行を `Return Value` へ |
| `Get Endings`（エンディング一覧を取得） | **Story**（ストーリー）：`スケルトン` | **Endings**（エンディング一覧）を `Array Filter By Key` の **Array**（配列）へ |
| `Boolean`（真偽値） | True | `Array Filter By Key` の **Value** へ |
| `Array Filter By Key`（配列をキーで絞り込み） | **Key**（キー）：`isReached` | **Array** を `Array Length` へ |
| `Array Length`（配列の長さ） | | **Length**（長さ）を `Make Array` の **Item 1**（項目 1）へ |
| `Get Endings`（エンディング一覧を取得） | **Story**：`スケルトン` | **Endings** を 2 つ目の `Array Length` へ |
| `Array Length`（配列の長さ） | | **Length** を `Make Array` の **Item 2**（項目 2）へ |
| `Make Array`（配列を作る） | 項目 2 つ | **Array** を `Format` の **Values**（値の一覧）へ |
| `Format`（整形） | **Template**（テンプレート）：`到達したエンディング {0} / {1}` | **Result** を `Return Value` の **Value** へ |

`Get Endings` はストーリーにあるすべてのエンディングの行を列挙し、各項目の `isReached` はプレイヤーがそこに到達したかどうかを表します。1 つ目の `Get Endings` は到達したエンディングを絞り込み、2 つ目はすべてのエンディングを数えます。

<Figure
    src="/static/img/docs/studio/en/affection-endings-graph.webp"
    alt="エンディングのブループリント値：2 つの Get Endings のうち 1 つは Array Filter By Key と Array Length を、もう 1 つは Array Length だけを通り、2 つの数が Make Array に入って Format で 1 行の文になる"
/>

テンプレートはグラフの中に書いた文字で、ゲームの言語では切り替わりません。プロジェクトに複数の言語があるときは、`Translation Key Text` でテンプレートを渡します。

    alt="開発モードのタイトルページ。ゲームタイトルの下に到達したエンディングが 1 / 3 と表示されている"

## 試して確かめる

- **F5** を押すと、プロジェクトが開発モードで実行されます。行の **Play from this row**（この行から再生）をクリックすると、その行から実行されます。
- 開発モード左下のデバッグボタン → **Story**（ストーリー）→ **Variables**（変数）に、セーブ変数の現在の値が並び、その場で変更できます。`好感度` を 40 にし、`正直` をオンにしてから最後まで進めると、「二人の文化祭」を確かめられます。
- 開発モードボタンの横の矢印 → **Reset player data**（プレイヤーデータをリセット）→ **Dev Mode**（開発モード）で、開発モードのすべてのセーブとエンディングの記録が消えます。タイトルページは `到達したエンディング 0 / 3` に戻ります。
- **Story**（ストーリー）パネルで **Open Scene Flow**（シーンフローを開く）をクリックし、変数の一覧で `好感度` を選びます。各シーンに到達時の好感度の範囲が表示され、**Show branches**（枝を表示）で選択肢ごとの増減と、エンディングで終わる分岐が表示されます。
- 条件の基準がどのルートでも届かない値のとき、**Problems**（問題）パネルが **Condition no path can satisfy**（成立し得ない条件）を報告し、その位置での好感度の範囲を示します。

<Figure
