Gallery プラグインは、ゲームの鑑賞画面のためのものです。CG ギャラリー、シーン回想、音楽鑑賞、ボイス鑑賞を扱います。鑑賞画面に載せるものを Studio のギャラリーエディターで一覧にしておくと、このページのノードがその一覧とプレイヤーが解除した内容を合わせて、List ウィジェットがそのまま描ける行として返します。このプラグインは出荷時に無効です。[組み込みプラグイン](/ja/docs/studio/blueprint/nodes/built-in-plugins#switching-a-plugin-on)を参照してください。

**Skeleton**（スケルトン）テンプレートから作成したプロジェクトの鑑賞画面は、これらのノードで組み立てられています。列ごとに `Get Gallery` が 1 つ、進捗の行に `Get Gallery Progress`、CG ビューアーに `Get Gallery Variants` と `Get Gallery Variant At` を使っています。

## カタログ [#the-catalog]

- **エントリー（entry）。** 鑑賞画面の 1 項目です。1 枚の CG、1 つの回想、1 枚のアルバム、1 組のボイスのいずれかです。どのエントリーにも**種類**があり、`cg`、`scene`、`music`、`voice` のいずれかで、Studio では **CG**、**Recollection**（回想）、**Music**（音楽）、**Voice**（ボイス）と表示されます。種類はエントリーが属する列を決めます。ノードのカードとピンはエントリーを artwork と呼びます。カードの `Artwork` フィールドと `artworkId` ピンがそれです。
- **バリアント（variant）。** エントリーの 1 メンバーです。CG の差分、回想の画像、アルバムの曲、ボイスの組の 1 行がこれにあたります。プレイヤーが解除するのはバリアントです。エントリーは、いずれかのバリアントが解除された時点で解除済みとみなされます。
- **カバー。** エントリーを代表するバリアントです。星を付けたもの、なければ最初のものです。
- **グループ。** すべての種類にまたがる任意の分類で、タブバーに使います。エントリーはグループに 1 つ属するか、どれにも属しません。
- **ロック中の見た目。** エントリーがロックされている間、その行は元の画像の代わりにプレースホルダー画像を、名前の代わりにロック中のタイトルを持ち、説明、音声、ボイス、シーンのフィールドは空になります。プレースホルダーはエントリー自身のもの、なければカタログの既定のものです。ロック中のタイトルは変更するまで `???` で、空にすると本当の名前が表示されます。
- **非表示のエントリー。** 非表示に設定したエントリーは、プレイヤーが解除するまで `Get Gallery` の行にも進捗の合計にも含まれません。そのため、秘密のエントリーが空の枠として見えることはありません。

プラグインを有効にすると、アクティビティバーに **Gallery**（ギャラリー）ツールが現れ、エントリーを一覧表示します。エントリーを選ぶか、ツールのヘッダーにある展開ボタンを押すと、ギャラリーエディターがタブとして開きます。

エディターは種類ごとに列を持ちます。追加ボタンは列によって変わります。**Import CGs**（CG を読み込む）は選んだ画像 1 枚ごとにエントリーを 1 つ作り、**Import Tracks**（トラックを読み込む）は選んだ曲で 1 枚のアルバムを作り、**Add Recollection**（回想を追加）と **Add Voice Lines**（ボイスの行を追加）は空のエントリーを作ります。そのシーンや行はインスペクターで選びます。グループは列の下に並ぶチップで、**New group**（新規グループ）で追加します。インスペクターでは、エントリーの名前、説明、グループ、バリアント、**Shown as a locked slot**（ロックされた枠として表示）か **Hidden until unlocked**（解除まで非表示）か、そしてエントリー自身のロック中のプレースホルダーを編集します。ヘッダーの **How locked entries look in game**（ゲーム内でのロック中の見た目）ボタンで、カタログの **Default placeholder**（既定のプレースホルダー）と **Locked title**（ロック中のタイトル）を設定します。

カタログはプロジェクトとともに保存され、ゲームに同梱されます。

## 解除 [#unlocking]

バリアントを解除するものは種類によって異なります。何も選択していないとき、エディターのインスペクターも列ごとに同じことを示します。

| 種類 | 解除するもの |
| --- | --- |
| CG | `Unlock Gallery` または `Unlock Whole Gallery` だけです。 |
| Recollection | プレイヤーがエントリーのシーンに到達したとき。エントリーのすべてのバリアントが一度に解除されます。 |
| Music | ストーリーがその曲を再生したとき。`/bgm` 行や `/sound` 行、またはシーンの開始時に流れるそのシーン自身の BGM です。Page が `Play Sound` で再生するクリップは数えないため、音楽鑑賞画面自身のプレイヤーでは曲を解除できません。 |
| Voice | プレイヤーが、そのバリアントの元になったストーリーの行を読み終えたとき。 |

解除記録はプレイヤーの持続データに、[永続変数](/ja/docs/studio/blueprint/variables#永続変数)と並んで保存され、どのセーブファイルにも入りません。新しいゲームを始めてもリセットされず、セーブをロードしても変わりません。`Lock Whole Gallery` で消去されます。Studio では、**Reset player data**（プレイヤーデータをリセット）が Dev Mode または Preview の解除記録を、それぞれのセーブとともに消去します。

解除記録が保持するのはバリアントの id で、id はエディターが割り当てます。まだバリアントのないエントリーは、エントリー自身の id で記録されます。バリアントの名前を変えたり並べ替えたりしても解除状態は保たれます。バリアントを削除して同じ画像を追加し直すと、新しいバリアントになり、ロックされた状態から始まります。

まだバリアントのないエントリーは、全体として解除・ロックされます。回想のシーンへの到達、`Unlock Gallery`、`Lock Gallery`、`Unlock Whole Gallery` のいずれもそのエントリーに作用します。回想は作成時に画像を持ちませんが、画像がなくてもシーンに到達すれば解除され、後から加えた画像もそのプレイヤーにとっては解除済みになります。

## 規約 [#conventions]

- **どのノードにも exec ピンがあります。** `Pure` なものはなく、Blueprint Value ではどれも提供されません。イベントグラフから実行し、返された値を List や変数に渡してください。`Get Gallery Groups` 以外はすべて `Latent` です。
- **接続したピンがカードより優先されます。** `artworkId`、`variantId`、`groupId` に空でない文字列が来ると、カードの `Artwork`、`Variant`、`Group` を上書きします。作成時にはカードで名前から選び、ピンには行が持つ id を渡します。プレイヤーがクリックした行がビューアーを動かすのはこの仕組みです。
- **行はすでにロック状態を反映しています。** ロック状態は各行の中で適用済みなので、項目テンプレートは受け取ったものをそのまま描けばよく、ロック中のエントリーの画像を誤って見せることはありません。
- **行は List に渡します。** `entries` を [`Set List Content`](/ja/docs/studio/blueprint/nodes/list#set-list-content) に接続します。項目テンプレートでは、[`Get List Item Props`](/ja/docs/studio/blueprint/nodes/list#get-list-item-props) と [`Get JSON Field`](/ja/docs/studio/blueprint/nodes/data#get-json-field) でフィールドを読みます。
- **エントリーが見つからないとノードは失敗します。** カードでエントリーを選んでおらず `artworkId` にも何もないと、ノードは `Pick a gallery artwork` で失敗します。カタログにない id では `Gallery artwork not found: <id>` で失敗します。
- **実行される場所。** エディターのキャンバスでは、ノードは編集中のカタログを読み、何も解除されていない状態として扱い、解除やロックは何も変えません。Dev Mode、Preview、ビルドしたゲームでは、ゲームに同梱されたカタログを読みます。
- **カタログのないゲーム。** ゲームがギャラリーのカタログを持たない場合（プロジェクトがカタログを一度も保存していない場合）、プラグインは `No gallery catalog was published with this game.` を一度だけ記録します。`Get Gallery` と `Get Gallery Groups` は空の配列を返し、`Get Gallery Progress` はすべて 0 を返し、エントリーを指定するノードはすべて失敗します。

## Get Gallery

`narraleaf.gallery.getEntries` · Latent

カタログのエントリーを、エディターでの順序のまま、種類とグループで絞り込んだ行として返します。プレイヤーがまだ解除していない非表示のエントリーは含まれません。

| ピン | 方向 | 型 | 備考 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `groupId` | in · data | `string` | 省略可能です。接続されている場合はカードの `Group` より優先されます。 |
| `onlyUnlocked` | in · data | `boolean` | 省略可能です。カード上にリテラル値を入力できます。`true` ではロック中のエントリーをすべて除きます。 |
| `next` | out · exec | — | |
| `entries` | out · data | `array` | オブジェクトの配列です。フィールドは下記のとおりです。 |
| `count` | out · data | `integer` | `entries` の行数です。 |
| `unlockedCount` | out · data | `integer` | `entries` のうち解除済みの行数です。 |

**カード上のフィールド**

| フィールド | 内容 |
| --- | --- |
| `Kind` | `CG`、`Recollection`、`Music`、`Voice` のいずれか。空（**All kinds**（すべての種類））ではすべての種類を読みます。 |
| `Group` | カタログのグループの 1 つ。空（**All groups**（すべてのグループ））ではすべてのグループを読みます。 |

**エントリーフィールド**

| フィールド | 内容 |
| --- | --- |
| `index` | `entries` の中での位置。絞り込みの後に数えます。 |
| `id` | エントリーの id。`artworkId` ピンに渡します。 |
| `name` | エントリーの名前。ロック中はロック中のタイトル。 |
| `description` | ロック中は空。 |
| `kind` | `"cg"`、`"scene"`、`"music"`、`"voice"` のいずれか。 |
| `groupId`、`groupName` | どのグループにも属さないエントリーでは空。 |
| `unlocked`、`locked` | いずれかのバリアントが解除済みかどうか（まだバリアントのないエントリーではエントリー自身が解除済みかどうか）と、その反転。`Not` を使わずにロック中の見た目を束縛できます。 |
| `variantCount`、`unlockedCount` | エントリーのバリアント数と、そのうち解除済みの数。 |
| `image`、`assetId` | 描く画像を、`ImageAsset` と素のアセット id で。解除済みなら、プレイヤーがカバーを持っていればカバー、なければプレイヤーが持つ最初のバリアント。ロック中はロック中のプレースホルダー。画像がなければ `null` と `""`。 |
| `thumbnail`、`thumbnailAssetId` | 同じ画像。ギャラリーエディターは別のサムネイルを設定しません。 |
| `coverVariantId` | 解除済みのとき `image` の元になっているバリアント。ビューアーはこれから開けます。ロック中はカバー。 |
| `audioAssetId` | `music`：表示している曲のクリップ。[`Play Sound`](/ja/docs/studio/blueprint/nodes/sound#play-sound) に渡します。ロック中は空。 |
| `durationSec` | 長さが分かっていれば秒数、分からなければ `0`。プロジェクトのボイスのテイクから選んだ行は長さを持ち、読み込んだ曲は持ちません。 |
| `voiceUnitId` | `voice`：表示している行の voice id。[`Play Voice`](/ja/docs/studio/blueprint/nodes/voice#play-voice) に渡します。ロック中は空。 |
| `lineText` | `voice`：表示している行の、選んだ時点でのテキスト。字幕に使います。ロック中は空。 |
| `storyId`、`sceneId`、`startBlockId` | `scene`：[`Start Game`](/ja/docs/studio/blueprint/nodes/game#start-game) が再生を始める場所。ロック中は空。ギャラリーエディターはストーリーとシーンしか設定しないため、`startBlockId` は空です。 |

## Get Gallery Progress

`narraleaf.gallery.getStats` · Latent

画面のヘッダーに使う達成度の数字を返します。種類とグループによる絞り込みは `Get Gallery` と同じです。非表示のエントリーは解除されてはじめて数えられるため、秘密のエントリーが合計に現れることはありません。

| ピン | 方向 | 型 | 備考 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `groupId` | in · data | `string` | 省略可能です。接続されている場合はカードの `Group` より優先されます。 |
| `next` | out · exec | — | |
| `total` | out · data | `integer` | 数えたエントリーの数です。 |
| `unlocked` | out · data | `integer` | 解除済みのバリアントを 1 つ以上持つエントリーの数です。 |
| `percent` | out · data | `integer` | `total` に対する `unlocked` の割合を、`0` から `100` の整数に丸めたものです。`total` が `0` のときは `0` です。 |
| `variantTotal` | out · data | `integer` | 数えたエントリーのバリアント数です。 |
| `variantUnlocked` | out · data | `integer` | そのうち解除済みの数です。 |

**カード上のフィールド**

| フィールド | 内容 |
| --- | --- |
| `Kind` | `Get Gallery` と同じ。空（**All kinds**（すべての種類））ではすべての種類を数えます。 |
| `Group` | `Get Gallery` と同じ。空（**All groups**（すべてのグループ））ではすべてのグループを数えます。 |
