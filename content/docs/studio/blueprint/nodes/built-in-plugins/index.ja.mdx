---
title: 組み込みプラグイン
description: Studio に同梱されるプラグイン、そのうちブループリントノードを追加する 2 つ、有効にする方法、そしてそれらのノードを使うプロジェクトが何に依存するか
---

Studio には Gallery、Quick Save、Menu Bar の 3 つのプラグインが同梱されています。これらは Studio と一緒にインストールされ、プラグインの一覧ではどれにも **Built-in**（組み込み）の印が付きます。組み込みプラグインはアンインストールできず、その権限はプラグインとともに付与されるため、有効にしても権限の確認は表示されません。

そのうち 2 つがブループリントノードを追加します。これらのノードは、プラグインが有効な間しかプロジェクトに存在しないため、コアのカテゴリとは分けてここに記載しています。

| プラグイン | ノード | 出荷時 | 内容 |
| --- | --- | --- | --- |
| [Gallery](/ja/docs/studio/blueprint/nodes/built-in-plugins/gallery) | 10 | 無効 | 鑑賞画面（CG ギャラリー、シーン回想、音楽鑑賞、ボイス）と、プレイヤーの解除記録。 |
| [Quick Save](/ja/docs/studio/blueprint/nodes/built-in-plugins/quick-save) | 3 | 有効 | クイックセーブとクイックロードに使う 1 つのセーブスロット。 |

Gallery の数はパレットが提供するものです。ほかに古い Gallery ノードが 4 つあり、パレットからは非表示で、そのページの末尾に記載しています。これらは数に含めていません。

3 つ目の組み込みプラグインである Menu Bar はノードを追加しません。デスクトップ版ゲームのメニューバーを作るためのもので、メニューバーの各行は組み込みのアクションか、グローバルブループリントの関数を実行します。

## プラグインを有効にする [#switching-a-plugin-on]

Quick Save は出荷時に有効、Gallery と Menu Bar は出荷時に無効です。このスイッチはこのマシンの Studio に属し、すべてのプロジェクトに適用されます。

プラグインはランチャーの **Plugins**（プラグイン）ページで有効にします。**Installed**（インストール済み）の一覧でそのプラグインを探し、**Enable**（有効にする）を選びます。変更がいつ反映されるかは[プラグインをインストールする](/ja/docs/studio/plugin/install-plugin)を参照してください。

**Skeleton**（スケルトン）テンプレートからプロジェクトを作成すると、Gallery が有効になります。このテンプレートの鑑賞画面が Gallery ノードで組み立てられているためです。

Gallery を有効にすると、アクティビティバーに **Gallery**（ギャラリー）ツールが加わり、パレットに **Gallery** カテゴリが加わります。Quick Save の 3 つのノードはパレットの **Game**（ゲーム）カテゴリに現れます。

## プロジェクトが依存するもの [#what-a-project-depends-on]

これらのノードを 1 つでも含むプロジェクトは、そのノードを提供するプラグインに依存します。プロジェクトはそのプラグインを、自身の[依存関係の表](/ja/docs/studio/plugin/project-dependencies)にハード依存として記録します。Studio は実行とエクスポートのたびにその前にこの表を再スキャンするため、ノードを置くだけで十分です。**Skeleton**（スケルトン）テンプレートから作成したプロジェクトは、最初に開いたときから Gallery を宣言しています。

Dev Mode、Preview、ビルドしたゲームは、表がハード依存として挙げるプラグインだけを実行します。有効になっていてもプロジェクトが宣言していない組み込みプラグインは、そこでは実行されず、ゲームにも同梱されません。Dev Mode の **Issues**（問題）パネルは、そうしたプラグインを 1 つずつ、インストールされているがこのプロジェクトのプラグイン依存に入っていないものとして示します。

## プラグインが無効なとき [#when-the-plugin-is-off]

無効になっている組み込みプラグインに依存するプロジェクトを開くと、このプロジェクトが必要とするプラグインが利用できないという警告が、そのプラグインの名前とともに表示されます。警告の **Open dependencies**（依存関係を開く）はプロジェクトの依存関係の一覧を開き、そこではそのプラグインの行が **Disabled**（無効）と表示され、**Enable**（有効にする）が用意されています。

プラグインが再び有効になるまで、そのノードはグラフに残ったまま **Unknown node**（不明なノード）カードとして描かれます。プロジェクトチェックはそれぞれを **Unknown node type**（不明なノード型）として報告し、これはビルドを止めるエラーです。Preview とエクスポートは、プラグインとノードの型を名指しするメッセージとともに停止します。[プラグインがないとき](/ja/docs/studio/plugin/studio/blueprint-nodes#when-the-plugin-is-missing)を参照してください。プラグインを有効に戻すと、ノードは接続ごと元に戻ります。
