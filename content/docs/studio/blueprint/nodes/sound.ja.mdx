ブループリントで決める**インターフェース**の音のための9つのノードです。条件によって鳴るかどうかが変わる音（CG が解放されているときだけ鳴るクリック音など）、ホバーやクリックに結び付かない音（Page が開いている間鳴らすアンビエンスなど）、ページが開いている間に変わるページの音楽（音楽鑑賞で押された曲など）が該当します。いつも鳴るホバー音やクリック音にはブループリントは要りません。Properties の [Sound](/ja/docs/studio/workspace/ui-editor#sound)（効果音）で要素に設定します。ページ自身の音楽も Properties の [Music](/ja/docs/studio/workspace/ui-editor#page-music)（音楽）で設定します。ストーリーが再生する音楽や効果音はストーリーに属し、そちらでは `/bgm` 行や `/sound` 行として記述します。

## 規約

- **9つすべてが latent です。** そのため Blueprint Value のバックエンドにすることはできません。Story Action ブループリントにはゲームのホストがないため、そこでも提供されません。
- **`Play Sound` がハンドルを返し、`Stop Sound`、`Pause Sound`、`Resume Sound`、`Seek Sound`、`Set Sound Volume`、`Is Sound Playing` がそれを受け取ります。** ハンドルが指すのは**この一回の再生**であり、アセットそのものではありません。同じクリップを2回再生すれば、それぞれ独立に停止・シーク・フェードできる2つのハンドルになります。
- **クリップはカード上で選びます。** `Play Sound` と `Play Page Music` では、`Audio Clip` がアセットを、`Track` がその再生先の音声トラックを選び、これによりプレイヤーがそのトラックに設定した音量が適用されます。`Asset Id` ピンは、再生するクリップを実行時に決める場合のためのものです。受け取る名前は、アセットピッカーで選んだもの、またはそれを保持している変数やリスト行から読み取ったものなど、プロジェクトにすでにあるものでなければなりません。`Concat` などで実行時に組み立てた名前は [`blueprint/assembled-asset-name`](/ja/docs/studio/blueprint/asset-names) プロジェクトチェックで報告され、プロダクションビルドでも拒否されます。ゲームパッケージにそのクリップが含まれないためです。
- **ページの音楽のノードは、自身のページの音楽を設定します。** `Play Page Music`（ページの音楽を流す）と `Stop Page Music`（ページの音楽を止める）はハンドルを受け取りません。実行したブループリントがあるページまたはレイヤーの音楽を、それが開いている間だけ、ページの [Music](/ja/docs/studio/workspace/ui-editor#page-music)（音楽）の設定の代わりに変えます。その設定と同じ規則に従い、下のページに戻るとそのページの音楽に戻ります。`Replace Page` でそのページを置き換えた、今の音楽のままのページは、その音楽を流し続けます。ゲーム中は音楽をストーリーが決めるため、これらは何も変えません。Dev Mode では、そのことを伝える警告が**コンソール**パネルに出ます。

## Play Sound

`blueprint.sound.play` · Latent

クリップを再生開始し、以後それにアクセスするためのハンドルを返します。

| ピン | 方向 | 型 | 備考 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `assetId` | in · data | `string` | 省略可能。カードの `Audio Clip` を上書きします。実行時に決めるクリップに使います。 |
| `loop` | in · data | `boolean` | 省略可能、リテラル。 |
| `volume` | in · data | `float` | 省略可能、リテラル。 |
| `fadeIn` | in · data | `float` | 省略可能、リテラル。単位は秒です。 |
| `next` | out · exec | — | |
| `handle` | out · data | `SoundHandle` | この分類の他のすべてのノードが受け取るものです。 |

**カード上のフィールド**

| フィールド | 内容 |
| --- | --- |
| `Audio Clip` | 再生するオーディオアセットです。 |
| `Track` | 再生先のプロジェクトの音声トラックです。これにより、プレイヤーがそのトラックに設定した音量が適用されます。 |

## Play Page Music

`blueprint.sound.playPageMusic` · Latent

このブループリントがあるページが開いている間、クリップをそのページの音楽にします。同じ音楽が同じトラックですでに流れていれば、途切れずに続き、音量がこのノードの音量になります。そうでなければ、流れている音楽がそれ自身のフェードで消え、このクリップが `fade` でフェードインします。同じページでこのノードをもう一度実行すると、前に設定した音楽を置き換えます。ゲーム中は何も変えません。

音楽鑑賞では、このノードで行を流します。押した行は前に押した行の曲を引き継ぎ、ページを離れると下のページの音楽に戻ります。**スケルトン**テンプレート（テンプレート 1.20.7 以降）の鑑賞ページの楽曲リストはこの作りです。

| ピン | 方向 | 型 | 備考 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `assetId` | in · data | `string` | 省略可能。カードの `Audio Clip` を上書きします。押された行のクリップを渡すときなどに使います。 |
| `volume` | in · data | `float` | 省略可能、リテラル。0 から 1 です。値がなければ 1 です。 |
| `loop` | in · data | `boolean` | 省略可能、リテラル。値がなければトラック自身の設定に従います。音楽トラックはループします。 |
| `fade` | in · data | `float` | 省略可能、リテラル。単位は秒です（カード上の表示は**フェード（秒）**）。クリップはこの時間でフェードインし、ほかの音楽に引き継ぐときもこの時間でフェードアウトします。値がなければ 0 です。 |
| `next` | out · exec | — | |

**カード上のフィールド**

| フィールド | 内容 |
| --- | --- |
| `Audio Clip` | 再生するオーディオアセットです。 |
| `Track` | 再生先のプロジェクトの音声トラックです。これにより、プレイヤーがそのトラックに設定した音量が適用されます。空なら音楽トラックです。 |

## Stop Page Music

`blueprint.sound.stopPageMusic` · Latent

このブループリントがあるページが開いている間、音楽を流しません。ページの **Music** を **No music**（音楽なし）にしたときと同じです。流れている音楽は `fade` でフェードアウトします。ゲーム中は何も変えません。

| ピン | 方向 | 型 | 備考 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `fade` | in · data | `float` | 省略可能、リテラル。単位は秒です（カード上の表示は**フェード（秒）**）。値がなければ、流れている音楽はそれ自身のフェードで消えます。 |
| `next` | out · exec | — | |
