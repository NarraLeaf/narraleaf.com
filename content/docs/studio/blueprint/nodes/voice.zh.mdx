---

五个节点，管游戏的语音轨：播放某一条的录音、播放选项自带的录音，以及读取或设置当前生效的配音语言。

## 约定

- **五个都是 latent。** 所以都不能给蓝图值当后端。Story Action 蓝图没有游戏宿主，也不提供它们
- **一条录音按 voice id 寻址**，也就是那一行的单元 ID，即它在翻译表中那一行的 ID
- **设置语言从下一句语音起生效。** 游戏不会重启，文本语言也不受影响；文本语言用 [Localization](/zh/docs/studio/blueprint/nodes/localization) 里的节点设置

## Play Voice

`blueprint.voice.play` · Latent

按当前生效的配音语言，播放某一行录好的那一条。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `next` | out · exec | — | |
| `voiceId` | in · data | `string` | 那一行的 voice id |
| `value` | out · data | `boolean` | 是否找到并播放了录音 |

## Play Choice Voice

`blueprint.voice.playChoice` · Latent

播放**当前这张图所属的那个选项**自带的录音。用在选项行里——只有那一行知道自己是哪个选项。在其他地方运行是执行错误。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `next` | out · exec | — | |
| `interruptOthers` | in · data | `boolean` | 可选，字面量。打断另一个选项正在说的那一条，于是沿着列表快速划过时语音不会叠起来 |
| `value` | out · data | `boolean` | 是否找到并播放了录音 |

## Set Voice Language

`blueprint.voice.setLanguage` · Latent

| 引脚 | 方向 | 类型 |
| --- | --- | --- |
| `in` | in · exec | — |
| `next` | out · exec | — |
| `language` | in · data | `string` |

未知或为空的 code 是执行错误，在没有配置任何配音语言的项目里运行这个节点同样是执行错误

`blueprint.voice.getAvailableLanguages` · Latent

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
