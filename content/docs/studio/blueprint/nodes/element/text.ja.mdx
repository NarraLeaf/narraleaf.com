`nl.text` と `nl.textInput` は別々のウィジェットですが、3つのノード名を共有しています。この衝突が一目でわかるように、両方のファミリーをこのページにまとめています。すべての Element ノードに共通する規則は [Element](/ja/docs/studio/blueprint/nodes/element) にあります。

## Text

Text ノードは `element:nl.text` ピンを持つため、グラフが `nl.text` 要素をバインドしたときにのみパレットに提供されます。Self 形態は [Text](/ja/docs/studio/blueprint/nodes/text) にあります。

## Text Input

これらは `nl.text` ではなく `nl.textInput` を対象とし、パレット名は上の Text ノードと真正面から衝突します——`Get Text` が2つ、`Set Text` が2つ、`Clear Text` が2つ。両者を見分けるのはピンです——Text Input ノードは `element:nl.textInput` 型の `textInput` を取り、Text ノードは `element:nl.text` 型の `element` を取ります——実際には、パレットはグラフがすでに持つバインディングに一致する方だけを提供するため、各ペアのうち一方しか目にすることはありません。Self 形態は [Text Input](/ja/docs/studio/blueprint/nodes/text-input) にあります。
