三种自己持有状态的控件——List 的条目、Slider 的值、Image 的资源——在这里通过连入的引用操作，而不是从控件内部操作。所有 Element 节点共通的规则见 [Element](/zh/docs/studio/blueprint/nodes/element)。

## List

List 节点带 `list` 引脚，类型是 `element:nl.list`。它们操作的是 List 实例的运行时 items，而这些 items 只存在于该实例中：完全卸载后就没了，也不会自动恢复，需要作者自己从变量或其它数据源重新写入。`itemsBinding` 只在没有运行时 items 时作为读取 fallback。

条目上下文读取节点——index、count、key、props——根本不是 Element 节点；它们读的是自己所在条目的模板作用域，和 Self 形态一起放在 [List](/zh/docs/studio/blueprint/nodes/list)。

## Slider

Slider 节点带 `slider` 引脚，类型是 `element:nl.slider`。滑块报告值的每一处——`props.value`、它的 Blueprint Value、事件 payload、`Get Slider Value`——给的都是映射后的值，已经按 `min`、`max`、`step` clamp 和 snap 过。`0..1` 的 normalized 值只能通过 `Get Slider Normalized Value` 取得。Self 形态见 [Slider](/zh/docs/studio/blueprint/nodes/slider)。

### Get Slider Value

`blueprint.element.slider.getValue` · Pure

读取运行时映射值——已经 clamp 和 snap 过。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `slider` | in · data | `element:nl.slider` |  |
| `value` | out · data | `float` |  |

### Set Slider Value

`blueprint.element.slider.setValue` · Latent

写入映射值，并按当前范围和步进规范化。它只更新运行时状态：不会派发 `valueChanged`、`dragStart` 或 `dragEnd` 事件，也不写回 UIDocument。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `in` | in · exec | — |  |
| `next` | out · exec | — |  |
| `slider` | in · data | `element:nl.slider` |  |
| `value` | in · data | `float` | 可在卡片上直接填字面量。 |

## Image

Image 节点带 `element:nl.image` 引脚。它们只处理界面上的图片控件——不表示舞台表演图片、角色立绘或剧情演出资源。产出 `ImageAsset` 的字面量卡片没有派生形态，和 Self 形态一起留在 [Image](/zh/docs/studio/blueprint/nodes/image)。

### Get Image Asset

`blueprint.element.image.getImageAsset` · Pure

控件没有图片时输出 `null`。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `element` | in · data | `element:nl.image` |  |
| `asset` | out · data | `ImageAsset\|null` |  |

### Set Image Asset

`blueprint.element.image.setImageAsset` · Latent

`asset` 不接线时，卡片会展开成图片选择器；接线后以连线值为准。传 `null` 清除图片。旧图里直接传字符串 `assetId` 的连线仍可运行，但新图应该传 `ImageAsset`。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `in` | in · exec | — |  |
| `next` | out · exec | — |  |
| `element` | in · data | `element:nl.image` |  |
| `asset` | in · data | `ImageAsset\|null` | 可在卡片上直接填字面量。 |

### Clear Image Asset
