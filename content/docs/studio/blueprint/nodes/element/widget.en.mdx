A Button's label and cursor, a Container's clipping, a Switch's checked state, the Page a Frame shows, and a Video's playback. The rules common to every Element node are in [Element](/docs/studio/blueprint/nodes/element).

## Button

Button nodes take an `element:nl.button` pin. `Get Button Label` reads the label on screen. The label `Set Button Label` writes shows as written in every language, ahead of a **Translation key** and a Blueprint Value, until the page is opened again. The Self forms are in [Button](/docs/studio/blueprint/nodes/button).

### Get Button Label

`blueprint.element.button.getLabel` · Pure

Reads the label on screen, in the player's current language.

| Pin | Direction | Type | Notes |
| --- | --- | --- | --- |
| `element` | in · data | `element:nl.button` |  |
| `label` | out · data | `string` |  |

## Switch

Switch nodes take an `element:nl.switch` pin. The Self forms are in [Switch](/docs/studio/blueprint/nodes/switch); the Switch's `visible` and `enabled` pair is with the rest of that family on [Displayable](/docs/studio/blueprint/nodes/element/displayable).

None of these dispatch the Switch's `Changed`, `Turned On` or `Turned Off` heads — those are for the player toggling it. A graph that writes the Switch it also listens to does not trigger itself.

## Frame

Frame nodes take an `element:nl.frame` pin and act on the Frame's own target Page and params. Moving the player to a different Page is a different job, done by `Go Page` in [App](/docs/studio/blueprint/nodes/app). The Self forms are in [Frame](/docs/studio/blueprint/nodes/frame).

### Get Frame Target Page

`blueprint.element.frame.getTargetPage` · Pure

Reads the target Page's surface id, or an empty string when the Frame shows nothing.

| Pin | Direction | Type | Notes |
| --- | --- | --- | --- |
| `element` | in · data | `element:nl.frame` |  |
| `targetSurfaceId` | out · data | `string` |  |

### Set Frame Page

`blueprint.element.frame.setTargetPage` · Latent

Switches the Frame to another Page. The dropdown filters out the Page the Frame itself sits on and any Page that leads back to it, directly or through a component. This Element form finds the Frame through the wired `Element` node, so until the reference is connected the dropdown lists every Page. The Frame then plays its normal enter and exit animation.

| Pin | Direction | Type | Notes |
| --- | --- | --- | --- |
| `in` | in · exec | — |  |
| `next` | out · exec | — |  |
| `element` | in · data | `element:nl.frame` |  |
| `props` | in · data | `json` | Written into the Frame's `params` and handed to the embedded Page as its props. Unwired, the current `params` are kept — this is not a clear. Optional. |

**On-card fields**

| Field | What |
| --- | --- |
| `targetSurfaceId` | Dynamic options: the Pages this Frame may legally show. The empty option is labelled None and clears the target. |

When the picked Page declares params, the card grows one input per param in front of `props`, as on the Self form in [Frame](/docs/studio/blueprint/nodes/frame#set-frame-page).

## Video

Video nodes take an `element:nl.video` pin named `video`, so they work from any graph on the page that holds a binding for a video, such as the blueprint of a skip button beside it. Each one does to the wired video what the node of the same name in [Video](/docs/studio/blueprint/nodes/video) does to its own video. The video's `Playback Ended` head is on the video's own blueprint.

### Play Video

`blueprint.element.video.play` · Latent
