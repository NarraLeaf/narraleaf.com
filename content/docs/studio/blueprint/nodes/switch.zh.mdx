title: Switch
description: Switch 控件的选中状态，以及每个控件都有的启用与可见两个开关
---

九个节点，对应一个 `nl.switch` 元素：界面需要的各种形态的选中状态，加上启用与可见这一对。

## 约定

- **只能用于控件蓝图，且只在 Switch 上。** 它们的 scope 就是 `nl.switch`，所以只在那个控件自己的蓝图里出现，别处没有。要从别的图里够到一个 Switch，用 [Element](/zh/docs/studio/blueprint/nodes/element) 分类下的对应版本
- **三个读取节点是 pure**，所以能出现在 `function` 图里、也能给蓝图值当后端。六个写入节点是 latent

## Get Checked

`blueprint.switch.getChecked` · Pure

| 引脚 | 方向 | 类型 |
| --- | --- | --- |
| `checked` | out · data | `boolean` |

## Set Checked

`blueprint.switch.setChecked` · Latent

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `checked` | in · data | `boolean` | 字面量 |
| `next` | out · exec | — | |

## Turn On

`blueprint.switch.turnOn` · Latent

就是传 `true` 的 `Set Checked`，单独做成一张卡，好让最常见的那件事读起来只有一个词。

| 引脚 | 方向 | 类型 |
| --- | --- | --- |
| `in` | in · exec | — |
| `next` | out · exec | — |
