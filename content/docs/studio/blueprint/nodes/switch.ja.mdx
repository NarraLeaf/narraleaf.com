`nl.switch` 要素のための9つのノードです。インターフェースが必要とするあらゆる形でのチェック状態に加え、有効・可視のペアが含まれます。

## 規約

- **ウィジェットのブループリント専用で、しかも Switch 上でのみ使用できます。** これらは `nl.switch` にスコープされているため、そのウィジェット自身のブループリントにのみ提供され、他では提供されません。別のグラフから Switch にアクセスするには、[Element](/ja/docs/studio/blueprint/nodes/element) の対応バージョンを使用してください。
- **3つの読み取りノードは pure です**。そのため `function` グラフに置くことも、Blueprint Value のバックエンドにすることもできます。6つの書き込みノードは latent です。

## Get Checked

`blueprint.switch.getChecked` · Pure

| ピン | 方向 | 型 |
| --- | --- | --- |
| `checked` | out · data | `boolean` |

## Set Checked

`blueprint.switch.setChecked` · Latent

| ピン | 方向 | 型 | 備考 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `checked` | in · data | `boolean` | リテラル。 |
| `next` | out · exec | — | |

## Turn On

`blueprint.switch.turnOn` · Latent

`true` を渡す `Set Checked` を、よくある使い方が一語で読み取れるように独立したカードにしたものです。

| `in` | in · exec | — |
