`nl.switch` 要素のための9つのノードです。インターフェースが必要とするあらゆる形でのチェック状態に加え、有効・可視のペアが含まれます。

## 規約

- **ウィジェットのブループリント専用で、しかも Switch 上でのみ使用できます。** これらは `nl.switch` にスコープされているため、そのウィジェット自身のブループリントにのみ提供され、他では提供されません。別のグラフから Switch にアクセスするには、[Element](/ja/docs/studio/blueprint/nodes/element) の対応バージョンを使用してください。
- **3つの読み取りノードは pure です。** Blueprint Value のオーナーは `widgetValue` であり、これらのノードは提供されません。Blueprint Value から Switch を読み取るには、Element のバージョンを `Element` リテラルとともに使用してください。6つの書き込みノードは latent です。
- **表示と有効状態のノードは、それぞれ同じ種類のノードとしてまとめられます。** パレットを一覧するとき、`Get Visible` と `Get Enabled` は **Get Visible or Enabled**（表示・有効状態を取得）、`Set Visible` と `Set Enabled` は **Set Visible or Enabled**（表示・有効状態を設定）として、それぞれ 1 行で表示されます。検索すると各ノードが自分の名前で表示されます。配置したカードは、タイトルの横の ▾ で 2 つのノードを切り替えられます。[同じ種類のノード](/ja/docs/studio/blueprint/nodes#node-families)を参照してください。
