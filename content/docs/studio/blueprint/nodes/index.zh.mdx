内置目录共 492 个节点，分布在 20 个分类中。分类就是你在创建浮窗里导航时看到的分组，因此这些页面的组织方式与编辑器一致。

## 如何阅读一个节点

每个节点写成这样：

> **Delay**
>
> `blueprint.flow.delay` · Latent

标题下第一行是节点的 **type id**——存进文档的值，也是你从插件注册时要用的值。其后是该节点为真的标记：

| 标记 | 含义 |
| --- | --- |
| `Pure` | 无副作用。可用于 `function` 图。 |
| `Latent` | 会挂起执行直到完成。在 `function` 图中永远不可用。 |

`Pure` 本身**并不**意味着该节点能在 [Blueprint Value](/zh/docs/studio/blueprint) 里使用。那是另一条更窄的规则：节点必须同时是纯节点、非 latent，且属于允许的分类——Data、List、Math、Text、Slider、Displayable、Element、Game——外加一小串特例（`Init` 与 `On Flush` 事件头、非 latent 的 Flow、本地变量读写、`Call Fn`、注释、`Return Value`，以及四个 Page 状态读取节点）。scope 限定为 `widgetMain` 的 Self 节点无论标记如何都被排除；在 Blueprint Value 里要触及某个控件，走 `Element` 字面量加 Element 分类的读取节点。

然后是引脚表：

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `duration` | in · data | `float` | 秒。可在节点卡上直接填字面量。 |
| `completed` | out · exec | — | 等待结束后触发。 |
| `token` | out · data | `Timer` | 接给 `Skip Delay` 可提前结束等待。 |

执行引脚传递执行，数据引脚传递值。*可在节点卡上直接填字面量*意味着你可以在卡片上输入该值，而不必拉一条连线。部分节点带**动态引脚**——由所选变量、所选函数签名或你追加的分支推导出来——这类引脚以文字说明，因为没有固定的表可列。

## 可用性

节点出现在本目录里，不代表它会出现在你的创建浮窗中。有三层过滤：

- **图类型。** `function` 图拒绝副作用节点和 latent 节点。
- **宿主与控件能力。** Self 节点只在具备该能力的控件蓝图里出现；Text 控件的蓝图里不会提供 `Set Slider Value`。
- **已存在的绑定。** Element 节点只有在图中已有可兼容的 `Element`、`Element Flush` 或 `Element Click` 节点可供连接时才会出现。

<Callout type="info">
存在多个兼容来源时，创建浮窗只列出该节点一次。若来源恰好唯一，添加时会自动连上；若有多个，则保留目标输入由你选择。
</Callout>
