ノードは1つだけであり、それはコンポーネントブループリントが存在する理由そのものです。コンポーネントは一度だけ作成され、何度も配置されるため、定義側のグラフには自分がどの配置のために実行されているかを尋ねる手段が必要になります。

## Get Component Param

`blueprint.component.getParam` · Pure

その配置がコンポーネントの宣言済みパラメータの1つに対して与えた値。配置が値を与えていない場合は、パラメータの初期値です。配置が翻訳キーから取る **Text**（テキスト）パラメータでは、値はキー名になります。キーの文字は [`Translation Key Text`](/ja/docs/studio/blueprint/nodes/localization#translation-key-text) で得られます。コンポーネント内のテキストやボタンは、ブループリントなしでも Text パラメータを表示できます。[コンポーネント](/ja/docs/studio/workspace/ui-editor#components) を参照してください。

コンポーネント自身のブループリント（`componentWidgetMain`）でのみ利用可能です——コンポーネントの外には尋ねるべき配置が存在しません。

| ピン | 方向 | 型 | 備考 |
| --- | --- | --- | --- |
| `value` | out · data | `string` | |

**カード上のフィールド**

| フィールド | 内容 |
| --- | --- |
| `Param` | このコンポーネントが宣言するパラメータの1つ。 |

12個のセーブスロットは、`slot` パラメータを持つ1つのコンポーネントを12回配置したものであり、同じ要素ツリーを12個複製したものではありません。定義側のグラフはここで `slot` を読み取り、その配置が指定したスロットへ書き込みます、またはそこから読み込みます。コンポーネントから呼び出された関数内のグラフも同じ配置を参照するため、補助的な `Fn` もパラメータを読み取れます。
