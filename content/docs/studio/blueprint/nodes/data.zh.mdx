Data 承载蓝图参与运算的值。需要一个常量、值的类型不对，或者要拆解字符串、数组、JSON 文档时，都用它。这里几乎没有节点带执行引脚——Data 节点由连到它输出端的一方读取。`Memo` 是唯一的例外，它在本页末尾自己解释

## 值类型

下面的引脚上出现以下`valueType`

| `valueType` | 内容 | 产出方 |
| --- | --- | --- |
| `string` | 文本| `String`，以及所有字符串节点|
| `integer` | 整数| `Integer`，以及各类长度、下标、计数|
| `float` | 数字| `Float`、`To Float`、`Parse Float`|
| `boolean` | 真或假| `Boolean`，以及所有类型判断和字符串判断|
| `json` | 任意 JSON 值：object、array、string、number、boolean 或`null`| `JSON`、`Parse JSON`、`Get JSON Field`、`Make Object`|
| `array` | JSON 数组，但作为独立类型存在| `Make Array`、返回数组的那些`Array …`节点、`Object Values`|
| `array<T>` | 各项类型都为`T`的数组。卡片上显示为该类型的列表，例如**结局列表**、**string列表**| `Get Endings`、`Get History`、`Split`、`Object Keys`、`Array Range`|
| `struct:<id>` | 字段已声明的对象，例如结局、存档条目。卡片上显示结构的名称，例如**结局**。见[结构](#structs)| 作用于结局的`Array First`、List 的`Item Click`、遍历结局的`For Each`|
| `any` | 任意值| `Memo`，以及类型随卡片上所选内容而定的引脚，例如`Get Field`、`Get Var`，在选定之前|
| `RGBAColor` | `{ r, g, b, a }`| `Color`|
| `Vector2D` | `{ x, y }`| `Vector2D`、`Make Vector2D`、`Rect Center`、`Get Center`|
| `Rect` | `{ x, y, width, height }`| `Rect`、`Make Rect`、`Get Bounds`、`Get Measured Rect`|

两个数据引脚之间的连线，在类型完全相同时成立；此外还有以下几种：

| 来源 | 目标 | 原因 |
| --- | --- | --- |
| `integer` | `float` | 整数一定是浮点数|
| `integer`、`float` | `string` | 读取该输入时数字会被转成文本。这是唯一会改写值的隐式转换——其余允许的连线都原样传递|
| `array` | `json` | 数组本身就是一个 JSON 值|
| `array<T>` | `array`、`json` | 各项类型已知的数组仍是数组|
| `array<T>` | `array<U>` | `T`能接到`U`时|
| `struct:<id>` | `json` | 结构就是一个 JSON 对象|
| `struct:<id>` | 另一个结构 | 两者字段相同、顺序相同、类型相同时|
| `Rect` | `json` | 一条为旧图留的兼容口子，而不是关于结构化类型的规则——见下|
| `any` | 任意类型 | `any`在两个方向上都匹配|
| 任意类型 | `any` | |

其它分类的类型也只在同样的地方放宽：`element`能接到任意`element:nl.…`引脚上、也能反过来，`element`类引脚与`any`则在两个方向上都接不上；`ImageAsset`与`string`都能接进`ImageAsset|null`输入

其余一律拒绝，包括那些作者以为能反过来用的：

- **`json` → `array`、`json` → `Rect`。** 每一条放宽规则都只单向成立。一个任意对象并不是一个矩形
- **`json` → 结构。** 字段未声明的对象（例如`Parse JSON`的结果）不能接到`Get Field`上，请用`Get JSON Field`读取
- **`float` → `integer`。** 插一个`To Integer`，它向零截断
- **`string` → `integer`或`float`。** 插`Parse Int`、`Parse Float`、`To Integer`或`To Float`
- **`boolean` → `string`、`json` → `string`。** 只有数字会隐式转成文本。插`To String`或`Stringify JSON`
- **`string`、`integer`、`float`、`boolean` → `json`。** 只有`array`和`Rect`能隐式接进`json`输入。插`To JSON`
- **`RGBAColor` → `json`、`Vector2D` → `json`。** 它们是各自独立的结构化类型，不是 JSON 文档。要拆开就用`Break Vector2D`，要造文档就用`Make Object`

<Callout type="info">
`Rect` → `json` 是给 `Rect` 成为独立类型之前写下的图留的。那时 `Rect` 常量和 `Get Bounds` 发布的都是 `json`，所以当年写下的矩形至今仍能接进 `Get JSON Field` 并继续工作。`Vector2D` 从来就不是 `json` 引脚，因此保持窄口
</Callout>

<Callout type="info">
`array`能接进`json`输入，反过来永远不行。一个恰好装着数组的`json`值（`Parse JSON`、`Get JSON Field`）不能接到`Array Length`或 List 的`Set List Content`这类`array`输入上。[Flow](/zh/docs/studio/blueprint/nodes/flow)里的`For Each`收`json`，所以遍历仍然可行；`Array …`节点则不行
</Callout>

<Callout type="info">
`array<T>`和结构类型决定哪些引脚能相连、卡片上提供哪些选项，不改变值本身：游戏运行时，结局仍是同一个对象。早期版本的图中原本成立的连线仍然成立
</Callout>

## 约定

- **这里除一个之外都是纯节点。** 没有执行引脚可连，所以 Data 节点不可能落在执行线路上。它的输出在下游读取时才计算，下一次读取时重新计算。`Memo` 是例外：它是执行节点，因为把一个值按住不动恰恰是纯节点做不到的事
- **Blueprint Value 图接受它们全部**，`Memo` 也在内
- **不存在原地修改。** 写入类节点在输出引脚上给出一个新值，输入原封不动
- **只有`string`、`integer`、`float`、`boolean`引脚支持卡片内联输入。** `json`和`array`输入没有卡片编辑器，请接一个`JSON`常量或`Make Object` / `Make Array`节点
- **输入未连线不算错误。** 它读取该引脚的卡片内联值，没有内联值时读到空；各节点自行归一：缺失的数组读作空数组，缺失的字符串读作`""`，缺失的数字读作`0`
- **一条纯节点链最多解析 32 层。** 超过之后读取静默地什么都取不到

<Callout type="warn">
`Array Push`、`Set JSON Field`、`Remove JSON Field`，以及本页所有写入类节点，交给你的都是一个**新**值，输入保持不动。只把`Get Var → Array Push`连起来什么也不会发生——你必须把结果再连回`Set Var`。参见 [变量](/zh/docs/studio/blueprint/variables)
</Callout>

## 转换

连接规则会把你引向这几个节点。它们都不会失败：读不出来的输入产出该类型的零值，而不是报错

### To String

`blueprint.string.toString` · Pure

To String（转为字符串）：`null`和未连线的输入都读作`""`。object 和 array 会被序列化为 JSON 文本

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `string` | |

### To Integer

`blueprint.data.toInteger` · Pure

To Integer（转为整数）向零截断——`-2.7`得到`-2`而不是`-3`。`true`读作`1`，`false`读作`0`，数字字符串可以接受，其余一律得到`0`

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `integer` | |

### To Float

`blueprint.data.toFloat` · Pure

接受范围与`To Integer`相同，只是不截断。非有限数字得到`0`

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `float` | |

### To Boolean

`blueprint.data.toBoolean` · Pure

字符串在去除首尾空白并转小写后匹配：`""`、`"false"`、`"0"`、`"no"`为假；`"true"`、`"1"`、`"yes"`为真；其他非空字符串一律为真。`0`和非有限数字为假

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `boolean` | |

### To JSON

`blueprint.data.toJson` · Pure

字符串会尝试按 JSON 解析，解析不了就保留原字符串——所以这个节点绝不会毁掉文本。其他值会被转成 JSON-safe 值：非有限数字和循环引用变成`null`，函数和 symbol 变成它们的文本形式

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `json` | |

### Format

`blueprint.string.format` · Pure

`Format` 是创建浮窗中唯一的格式化节点，可用于 Blueprint Value 与函数。要使用玩家语言中的模板，把 [`Translation Key Text`](/zh/docs/studio/blueprint/nodes/localization#translation-key-text) 接到 `template`

| `values` | in · data | `json` | 接一个`JSON`常量、`Make Object`，或为 `{0}`、`{1}`……接`Make Array`|

## 结构 [#structs]

结构是字段已声明的对象：结局、历史记录条目、存档条目、画廊条目，或 List 的一行。携带结构的引脚在卡片上显示结构的名称，例如**结局**；携带结构数组的引脚显示**结局列表**。`Get Field`（获取字段）读取其中一个字段，字段从下拉列表中选择

| 结构 | 字段 | 给出该结构的节点 |
| --- | --- | --- |

各字段的含义写在给出该结构的节点下。插件可以声明自己的节点给出的结构，例如画廊插件的**画廊条目**，见[清单](/zh/docs/studio/plugin/manifest#structs)。List 的行采用**编辑内容**中设置的结构，可以是上表中的结构，也可以是为该 List 填写的字段，见[列表](/zh/docs/studio/workspace/ui-editor#lists)

- **类型沿连线传递。** 数组节点把项的类型传下去，见[数组](#数组)。[Flow](/zh/docs/studio/blueprint/nodes/flow#for-each) 中的`For Each`给出所遍历数组的一项。List 节点和条目事件头给出、接收该 List 结构的行，见 [List](/zh/docs/studio/blueprint/nodes/list#约定)
- **字段的类型就是引脚的类型。** 字符串字段为`string`，数字为`float`，布尔值为`boolean`，图片为`ImageAsset|null`，颜色为`RGBAColor`，JSON 为`json`
- **从结构上拖出连线。** 从携带结构的引脚拖出连线并在画布空白处松开，添加节点菜单会打开在**字段**分组，列出**获取**每个字段的条目，例如**获取 isReached**、**获取 name**。从携带结构数组的引脚拖出时，列出按每个字段**筛选**、**排序**、**查找**的条目，例如**按 isReached 筛选**。每个条目添加的节点已选好该字段，并与该引脚相连。对布尔字段**筛选**或**查找**时，比较的值为真
- **结构中没有的字段会被报告。** `Get Field`选择了结构中没有的字段，或`Array Filter By Key`、`Array Sort By Key`、`Array Find By Key`的`key`不是各项的字段时，画布上显示警告，项目检查报告**字段不存在**（`blueprint/field-missing`）。这样的节点读不到值：`Get Field`得到空值，筛选不保留任何项，排序不改变顺序。删除 List 的字段或手动填写键之后会出现这种情况。只检查结构已知的节点

### Get Field

`blueprint.list.getItemField` · Pure

读取结构中的一个字段。把结构连到**对象**，在**字段**中选择字段。输出取该字段的类型，因此结局的`isReached`可以直接连到`Branch`

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `object` | in · data | `struct:*` | 任意结构，显示为**结构**。在 List 的行中可以不连接 |
| `value` | out · data | `any` | 取所选字段的类型。值中没有该字段时为`null` |

**卡片字段**

| 字段 | 说明 |
| --- | --- |
| `Field` | 要读取的字段，从连到**对象**的结构的字段中选择。结构中已不存在的字段仍留在列表中，显示为**字段“…”已缺失** |

- **保留第一次连入的结构。** 此后**对象**只接受该结构，连线断开后也一样。要读取其他结构，请另加一个`Get Field`
- **在 List 的行中，对象可以不连接。** 此时节点读取正在绘制的那一行，卡片显示**对象 · 当前行**。可以读到行的位置与 [List](/zh/docs/studio/blueprint/nodes/list#约定) 中所列相同：List 项模板中元素的蓝图、List 自己的条目事件头，以及组件定义

- **字段未声明的对象**接不上，请用`Get JSON Field`读取

该节点原名**获取条目字段**（Get Item Field），只能读取 List 的行。类型 id 没有变化，已有的图仍保留该节点，在行中未连接的节点照旧读取当前行

## 把一个值按住

### Memo

`blueprint.data.memo`

执行经过它时读一次输入，把那个值留在输出上，直到执行下一次经过。第一次经过之前，输出读作 `null`。这个值和蓝图的[变量](/zh/docs/studio/blueprint/variables#蓝图变量)存在同一个 store 里：在 `Init` 里按住的值，之后的 `Mouse Click` 仍然读得到；宿主实例重新开始时，它也跟着重新开始。

它的输出可以喂给**多个**下游。算出来的数据输出只能接一个下游，从它再拉第二条连线会替换掉第一条，而且是两个不同的理由：纯节点每次被读都会重新求值，同一个 `Random Float` 读两次就是两个数字；执行节点的输出则属于产生它的那一次脉冲。Memo 只有一个写入方——它自己——所以每次读到的都是那次写入留下的东西，扇出去也不会让任何人意外。本页的常量节点、`Element` 绑定和 [`Fn`](/zh/docs/studio/blueprint/nodes/functions#fn) 的参数引脚同样可以扇出，因为每次读到的都是同一个值。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `in` | in · exec | — | |
| `value` | in · data | `any` | 执行经过时读一次 |
| `next` | out · exec | — | |
| `result` | out · data | `any` | 卡片上标作 Value |

它是同步的而不是 latent，这是刻意的：这里没有什么可等的，而 latent 节点会被内联故事值挡在门外。
