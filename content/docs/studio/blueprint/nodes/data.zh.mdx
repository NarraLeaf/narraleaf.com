Data 承载蓝图参与运算的值。需要一个常量、值的类型不对，或者要拆解字符串、数组、JSON 文档时，都用它。这里没有任何节点带执行引脚——Data 节点由连到它输出端的一方读取。

## 值类型

下面的引脚上一共出现九种`valueType`。

| `valueType` | 内容 | 产出方 |
| --- | --- | --- |
| `string` | 文本。 | `String`，以及所有字符串节点。 |
| `integer` | 整数。 | `Integer`，以及各类长度、下标、计数。 |
| `float` | 数字。 | `Float`、`To Float`、`Parse Float`。 |
| `boolean` | 真或假。 | `Boolean`，以及所有类型判断和字符串判断。 |
| `json` | 任意 JSON 值：object、array、string、number、boolean 或`null`。 | `JSON`、`Rect`、`Parse JSON`、`Get JSON Field`、`Make JSON Object`。 |
| `array` | JSON 数组，但作为独立类型存在。 | `Make JSON Array`、返回数组的那些`Array …`节点、`Object Keys`、`Object Values`。 |
| `any` | 任意值。 | —— |
| `RGBAColor` | `{ r, g, b, a }`。 | `Color`。 |
| `Vector2D` | `{ x, y }`。 | `Vector2D`。 |

两个数据引脚之间的连线，在类型完全相同时成立；此外还有以下几种：

| 来源 | 目标 | 原因 |
| --- | --- | --- |
| `integer` | `float` | 整数一定是浮点数。 |
| `integer`、`float` | `string` | 读取该输入时数字会被转成文本。这是唯一会改写值的隐式转换——其余允许的连线都原样传递。 |
| `array` | `json` | 数组本身就是一个 JSON 值。 |
| `any` | 任意类型 | `any`在两个方向上都匹配。 |
| 任意类型 | `any` | |

其余一律拒绝，包括那些作者以为能反过来用的：

- **`json` → `array`。** 这条规则只单向成立。
- **`float` → `integer`。** 插一个`To Integer`，它向零截断。
- **`string` → `integer`或`float`。** 插`Parse Int`、`Parse Float`、`To Integer`或`To Float`。
- **`boolean` → `string`、`json` → `string`。** 只有数字会隐式转成文本。插`To String`或`Stringify JSON`。
- **`string`、`integer`、`float`、`boolean` → `json`。** 只有`array`能隐式接进`json`输入。插`To JSON`。
- **`RGBAColor` → `json`、`Vector2D` → `json`。** 它们是各自独立的结构化类型，不是 JSON 文档。`Rect`是例外：它本来输出的就是`json`。

<Callout type="info">
`array`能接进`json`输入，反过来永远不行。一个恰好装着数组的`json`值——`Split`的结果、`Parse JSON`、`Get JSON Field`——不能接到`Array Length`或 List 的`Set Items`这类`array`输入上。[Flow](/zh/docs/studio/blueprint/nodes/flow)里的`For Each`收`json`，所以遍历仍然可行；`Array …`节点则不行。
</Callout>

## 约定

- **这里每个节点都是纯节点。** 没有执行引脚可连，所以 Data 节点不可能落在执行线路上。它的输出在下游读取时才计算，下一次读取时重新计算。
- **三种图类型都接受它们**——`event`、`function`、`macro`——Blueprint Value 图同样接受。
- **不存在原地修改。** 写入类节点在输出引脚上给出一个新值，输入原封不动。
- **只有`string`、`integer`、`float`、`boolean`引脚支持卡片内联输入。** `json`和`array`输入没有卡片编辑器，请接一个`JSON`常量或`Make JSON …`节点。
- **输入未连线不算错误。** 它读取该引脚的卡片内联值，没有内联值时读到空；各节点自行归一：缺失的数组读作空数组，缺失的字符串读作`""`，缺失的数字读作`0`。
- **一条纯节点链最多解析 32 层。** 超过之后读取静默地什么都取不到。

<Callout type="warn">
`Array Push`、`Set JSON Field`、`Object Set Field`，以及本页所有写入类节点，交给你的都是一个**新**值，输入保持不动。只把`Get Var → Array Push`连起来什么也不会发生——你必须把结果再连回`Set Var`。参见 [变量](/zh/docs/studio/blueprint/variables)。
</Callout>

## 转换

连接规则会把你引向这几个节点。它们都不会失败：读不出来的输入产出该类型的零值，而不是报错。

### To String

`blueprint.string.toString` · Pure

To String（转为字符串）：`null`和未连线的输入都读作`""`。object 和 array 会被序列化为 JSON 文本。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `string` | |

### To Integer

`blueprint.data.toInteger` · Pure

To Integer（转为整数）向零截断——`-2.7`得到`-2`而不是`-3`。`true`读作`1`，`false`读作`0`，数字字符串可以接受，其余一律得到`0`。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `integer` | |

### To Float

`blueprint.data.toFloat` · Pure

接受范围与`To Integer`相同，只是不截断。非有限数字得到`0`。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `float` | |

### To Boolean

`blueprint.data.toBoolean` · Pure

字符串在去除首尾空白并转小写后匹配：`""`、`"false"`、`"0"`、`"no"`为假；`"true"`、`"1"`、`"yes"`为真；其他非空字符串一律为真。`0`和非有限数字为假。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `boolean` | |

### To JSON

`blueprint.data.toJson` · Pure

字符串会尝试按 JSON 解析，解析不了就保留原字符串——所以这个节点绝不会毁掉文本。其他值会被转成 JSON-safe 值：非有限数字和循环引用变成`null`，函数和 symbol 变成它们的文本形式。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `any` | |
| `result` | out · data | `json` | |

### Parse Int

`blueprint.data.parseInt` · Pure

固定十进制，取开头的数字——`"12px"`得到`12`。一个数字都没有则得到`0`。

| 引脚 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| `value` | in · data | `string` | 可在卡片上内联输入。 |
| `result` | out · data | `integer` | |

### Parse Float

`blueprint.data.parseFloat` · Pure

Parse Float（解析浮点数）。

| 引脚 | 方向 | 类型 | 说明 |
