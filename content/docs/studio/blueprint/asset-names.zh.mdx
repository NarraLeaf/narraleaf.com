---
title: 资产名称
description: 游戏包会带上哪些资产名称，以及报告「按运行时拼出的名称选择资产」的项目检查
---

正式构建会带上项目中写明名称的每一个资产：在故事行、节点卡片或控件属性的资产选择器里选的，或者存放在由这些值设置的变量或列表行里的。游戏在运行时拼出名称再据此选择的资产不会进入游戏包，发布后的游戏里本该显示或播放它的地方什么都没有。开发模式读取整个资产库，所以在开发模式里这个资产仍然会出现

`blueprint/assembled-asset-name` 项目检查会在构建之前报告每一处这样的用法

## 会进入游戏包的名称 [#names-that-reach-the-package]

名称来自项目中写明的内容，并且原样传递，就会进入游戏包：

- 资产选择器：节点卡片上的字段，例如 `Play Sound` 的 `Audio Clip`、`Image Asset` 字面量，或属性面板中的属性
- 存着已选名称的变量或列表行，不论是蓝图还是故事行写入的
- 交出项目已有名称的节点，例如 Gallery 节点

## 运行时拼出的名称 [#names-assembled-at-run-time]

名称在传递途中经过任何拼接文本或从项目之外取值的步骤，就是运行时拼出的：`Concat`、`Format`、玩家在 Text Input 中输入的内容、`Fetch` 的响应。检查无法追溯到写入位置的值同样按运行时拼出处理，例如名称本身由连线传入的变量

## 检查 [#the-check]

规则是 `blueprint/assembled-asset-name`，标题为**运行时生成的资产名称**，默认严重级别为**错误**。它检查每一个接收资产的输入，例如 `Play Sound` 的 `Asset Id`、`Set Image Asset` 的 `Asset` 与 `Set Font` 的 `Font`，以及每一个绑定到显示资产的属性上的蓝图值，例如 Image 的图片。它会在整个项目中追踪一个值，包括故事行写入的变量和其他蓝图设置的列表行

| 位置 | 显示内容 |
| --- | --- |
| 蓝图编辑器 | 接收该名称的节点上显示一条错误。名称在另一个蓝图中或由属性使用时，错误显示在拼出名称的节点上 |
| **问题** | 每一处用法一行，编辑项目后自动更新 |
| 正式构建 | 构建中止，并给出同样的信息。无论该规则在**项目 → 项目 → 项目检查**中设为哪种严重级别，以及**构建前检查**是否关闭，构建都会中止 |

## 修复 [#fixing-it]

在资产选择器中选择资产，或把选好的资产存进变量或列表行，再从那里读取。例如要为每个角色播放不同的片段，把每个角色的片段存进列表行，再把该行的值连到 `Asset Id`

如果名称来自一个未加载的节点类型（提供它的插件缺失或已禁用），信息会改为指明该节点类型。安装或启用该插件，然后重新构建
