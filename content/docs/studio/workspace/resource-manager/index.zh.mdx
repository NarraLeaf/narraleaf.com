title: 素材
description: 把文件导入项目、分组管理，并查看项目实际用到了什么
---

**素材**面板存放项目用到的全部文件。侧边栏按六个类别归类：

| 类别 | 内容 |
| --- | --- |
| 图片 | 背景、立绘及其他静态图片 |
| 媒体 | 音频与视频 |
| 数据 | JSON 文件与蓝图 |
| 字体 | 字体文件 |
| 模型 | Live2D、Spine 及其他由运行时绘制的模型 |
| 其他 | 以上类别未覆盖的文件 |

## 导入

将文件拖到面板上，或使用导入按钮。拖入文件夹会导入其中的内容，并保留目录结构。

<Gif
    brief="从文件管理器拖几张图片到素材面板上，文件落入某个分组"
    duration="6s"
/>

**导入远程素材**接受一个 URL：文件会下载到项目中，与其他素材一样存放，并记录来源，项目在离线时仍可使用。

导入引擎无法播放的文件时，Studio 会给出提示并提供转换。是否受支持取决于容器格式以及其中每条流的编码，而不是文件扩展名。

模型通过专用向导导入，向导会认领清单文件及其同目录的文件。参见[模型运行时](/zh/docs/studio/model-runtimes)。

## 组织

素材可以分组、重命名、替换和删除。删除会记入工作区历史，可以撤销。

选中素材后，属性面板显示它的信息。将素材拖到 UI 画布上会创建一个与之关联的控件。

## 总览

**总览**视图给出素材库的整体情况：文件数量、其中被项目引用的数量，以及各组的体积。

它同时给出移除未引用文件后的体积。这是一项测量结果，不是构建设置——无论如何，构建都会打包整个素材目录。
