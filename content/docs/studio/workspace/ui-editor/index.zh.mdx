**UI** 面板存放项目中的全部界面。**界面类型**在两类之间切换列表。

| 类型 | 是 | 尺寸 |
| --- | --- | --- |
| **页面** | 标题、设置、存档、历史、画廊等完整界面 | 创建页面时指定 |
| **游戏 UI** | 游玩过程中的界面，如对话、选项、HUD、快捷操作和通知 | 项目分辨率 |

游戏 UI 创建在具体的位置上，每个位置只有一个界面。所有位置都已占用时，从列表中打开已有的游戏 UI，而不是再创建一个。

页面和游戏 UI 可以重命名、复制和删除。删除会一并移除其中的元素。

## 画布

界面以标签页打开：左侧是 UI 大纲，中央是画布，右侧是属性面板，下方是插入栏。

- 在插入栏选择控件，然后在画布上单击或拖动放置。
- 拖动控件可移动位置，拖动控制点可改变尺寸。智能吸附会将控件对齐到画布边缘、中心线和相邻控件。
- 对齐工具以所选内容的包围盒为基准。
- 比例框会在画布上叠加目标设备的安全区，播放按钮在开发模式中打开该界面。

画布不会裁切：运行时始终把整个舞台完整放入窗口，因此落在安全区之外的内容在部分设备上仍然可见。

## 组件

所选内容可以保存到**组件库**，并在别处再次放置。一组控件需要复用时，将其做成组件，而不是复制粘贴。

## 行为

控件行为写在蓝图中，而不是画布上。每个界面有自己的蓝图，项目另有一个全局蓝图，参见[蓝图](/zh/docs/studio/blueprint)。
