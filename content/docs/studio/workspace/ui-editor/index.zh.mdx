**UI** 面板存放项目中的全部界面。**界面类型**在两类之间切换列表

| 类型 | 是 | 尺寸 |
| --- | --- | --- |
| **页面** | 标题、设置、存档、历史、画廊等完整界面 | 创建页面时指定 |
| **游戏 UI** | 游玩过程中的界面，如对话、选项、HUD、快捷操作和通知 | 项目分辨率 |

游戏 UI 创建在具体的位置上，每个位置只有一个界面。所有位置都已占用时，从列表中打开已有的游戏 UI，而不是再创建一个

游戏启动时先显示**入口页面**，其余页面由蓝图打开；游戏 UI 在开始游戏后自动显示在游戏画面之上。两者在运行时如何叠放，参阅[运行时的界面](/zh/docs/studio/workspace/ui-editor/runtime)

任何页面都可以设为入口页面：右键页面卡片选择**设为入口页面**，或选中页面后在属性面板中点击**设为入口页面**。卡片随即标为**入口页面**，原来的入口页面成为普通页面。指向这两个页面的蓝图和 `Go Page` 节点不受影响

页面和游戏 UI 可以重命名、复制和删除。删除会一并移除其中的元素。入口页面不能删除，需先将其他页面设为入口页面

## 画布

界面以标签页打开：左侧是 UI 大纲，中央是画布，右侧是属性面板，下方是插入栏

<Figure
    src="/static/img/docs/studio/zh/ui-editor.webp"
    alt="画布上的一个页面，左侧是 UI 大纲，画布下方是插入栏，右侧是属性面板"
/>

- 在插入栏选择控件，然后在画布上单击或拖动放置
- 拖动控件可移动位置，拖动控制点可改变尺寸。智能吸附会将控件对齐到画布边缘、中心线和相邻控件
- 对齐工具以所选内容的包围盒为基准
- 比例框会在画布上叠加目标设备的安全区，播放按钮在开发模式中打开该界面
- 页面边缘之外的内容覆盖着一层画布底色的遮罩照常绘制，拖出页面的元素仍然可以选中并拖回来。被所在容器裁掉的已选元素，可以拖动它的选框移动。游戏里只显示页面范围内的内容

画布不会裁切：运行时始终把整个舞台完整放入窗口，因此落在安全区之外的内容在部分设备上仍然可见

## 文字 [#words]

**文本**的内容、**按钮**的文字和**文本输入框**的占位文本，各自从一个来源取得文字，在属性面板中选择：**直接输入**、**翻译键**，以及文本与按钮还可以选的**蓝图值**

- 使用蓝图值、列表行的**字段**或组件的**参数**时，控件自身的文字是**示例文字**：只在编辑器中显示，不进入构建出的游戏
- 游戏运行时由蓝图写入文字的控件，属性面板把它自身的文字标为**默认值**，并在**游戏中由以下蓝图写入**下列出这些蓝图。点选其中一项会打开该蓝图，选中写入的节点并将它移入视野

各个来源如何翻译，见[界面文本](/zh/docs/studio/workspace/localization#interface-text)

## 自动缩小

**文本**控件可以缩小到内容放进它所在的盒子。在**排版**中打开**自动缩小**：控件上设定的字号成为上限，文本会缩小到整体放得下为止，最小到**最小字号**。在**最小字号**下仍然放不下的文本会被裁切

**最小字号**在**自动缩小**打开时才出现。这两个属性在画布上与运行中的游戏里同样生效，**句子**与 **NVL 文本**控件也带有它们

**句子**控件出厂即打开**自动缩小**：一句对白只写一次，却要在游戏发行的每一种语言里显示。该行先按控件上的字号显示，文本抵达盒子末端后，随着余下内容逐字显示而缩小

## 音效 [#sound]

除界面的根元素外，每个元素在属性面板中都有**音效**一节，位于**动画**上方。元素设置音效之前，这一节是折叠的

| 音效 | 何时播放 |
| --- | --- |
| **悬停** | 指针移入元素时。在触摸屏上点按不会播放 |
| **点击** | 点击元素，或用键盘激活元素时 |

两者都可以选择一个音频资产或资产集；显示**未选择音效**表示没有设置。选好的音效下方有一行折叠的摘要，例如 **音量 1 · SFX**，点开是它的播放选项：**音量**（0 到 1）与**音轨**。音效默认在 SFX 音轨上播放，可在**音轨**中更换，玩家对该音轨的音量设置会生效。无论在哪条音轨上，每次悬停或点击只播放一次，不会循环

一次悬停或点击只播放一个音效。带音效的元素相互嵌套时，只播放最内层元素的音效：卡片里的按钮有自己的点击音效时，点按钮播放按钮的音效，点卡片的其他位置播放卡片的音效。被禁用的元素两种音效都不播放

音效在开发模式与游戏中播放，编辑器画布上不播放

关联组件的实例没有**音效**一节，播放的是组件本身设置的音效。取决于条件的声音，在蓝图中用 [Sound 节点](/zh/docs/studio/blueprint/nodes/sound)播放

## 组件 [#components]

所选内容可以保存到**组件库**，并在别处再次放置。一组控件需要复用时，将其做成组件，而不是复制粘贴

<Gif
    brief="在画布上选中若干控件，加入组件库，再把新组件拖到另一个页面上"
    duration="9s"
/>

**参数**在组件上声明，在每个放置处设置。**字符串**参数由组件的蓝图通过 [`Get Component Param`](/zh/docs/studio/blueprint/nodes/component) 读取。**文字**参数是玩家读到的文字：组件内的文本或按钮在**参数**中选择它，各放置处在画布和游戏中显示各自的文字，可以直接输入，也可以使用翻译键

## 行为

控件行为写在蓝图中，而不是画布上。每个界面有自己的蓝图，项目另有一个面向整个应用的蓝图，即**页面**列表中的第一张卡片**应用逻辑**，参见[蓝图](/zh/docs/studio/blueprint)
