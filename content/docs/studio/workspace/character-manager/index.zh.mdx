**角色**面板存放项目中的全部角色。角色可以分组、加标签，也可以按名称搜索

## 类型

角色类型在创建时选定。各类型之间没有共享数据，切换会丢弃前一种持有的内容

| 类型 | 绘制来源 |
| --- | --- |
| **成品差分** | 每个具名姿态一张成品图；单图角色即只有一个姿态 |
| **分层立绘** | 在运行时合成、按标签切换的图层，一个姿态可以同时改变多个图层 |
| **Live2D Cubism** / **Spine** / **自定义运行时** | 由随项目提供的运行时绘制的绑定模型，参见[模型运行时](/zh/docs/studio/model-runtimes) |

## 成品差分与分层立绘

成品差分角色是一组具名姿态，每个姿态对应一张图片素材，故事按姿态名称调用

分层立绘角色把图层叠放在同一张画布上。图层按轴分组，一个姿态在每条轴上各选一个选项，因此一个姿态可以同时改变多个图层

## 由运行时绘制的角色

模型角色需要两样东西：绘制运行时，以及要绘制的模型。两者就位后，Studio 会读取模型，填入它提供的动作、表情和皮肤，故事按名称调用。入口、尺寸和初始状态在编辑器中设置

运行时不随 Studio 分发。需要安装什么、适用哪些条款，参见[模型运行时](/zh/docs/studio/model-runtimes)

## 分组与删除

分组只用于整理面板，不影响游戏。角色可以在分组之间移动，也可以不属于任何分组

删除角色会记入工作区历史，可以撤销。在恢复之前，故事中引用该角色的行无法解析
