---
title: 角色管理器
---

角色在 **角色** 面板中创建。kind 在创建时选定，因为各 kind 之间没有共享数据，切换会丢弃前一种持有的内容：

| Kind | 是 |
| --- | --- |
| **成品差分** | 每个具名姿态一张成品图。单图角色只是 N = 1 的情形。 |
| **分层立绘** | 一叠在运行时合成、按标签切换的图层，因此一个「生气」可以同时带动眉毛和嘴。 |
| **Live2D Cubism** / **Spine** / **自定义运行时** | 由你提供的运行时绘制的绑定模型。见 [模型运行时](/zh/docs/studio/model-runtimes)。 |
