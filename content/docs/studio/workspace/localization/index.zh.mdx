**本地化**面板管理的是游戏本身的语言，与 Studio 界面显示的语言无关

其中一种语言是**源语言**，即故事的写作语言，其余语言都以它为基准翻译

## 语言

添加语言时填写语言代码（`en`、`ja`、`zh-CN`）和面向玩家显示的名称。列表中的任意语言都可以设为源语言

<Figure
    src="/static/img/docs/studio/zh/localization.webp"
    alt="本地化面板的语言部分，其中一种语言标记为源语言"
/>

移除语言会将其从游戏中去掉。它的翻译仍保留在磁盘上，重新添加该语言后会回来

每种语言都有**回退语言**。该语言下没有翻译的条目会回退到回退语言，再回退到源语言，因此翻译不完整的语言仍能正常显示。Studio 不接受会绕回自身的回退设置

## 游戏进行中切换语言 [#changing-language-during-a-game]

游戏通过 [`Set Language`](/zh/docs/studio/blueprint/nodes/localization#set-language) 节点切换语言，通常是在玩家打开的设置界面里。在标题画面切换时，新语言立即生效。玩家在游戏进行中切换语言时会发生什么，在**项目 → 游戏 → 语言**的**游戏进行中切换语言**中设定：

| 选项 | 玩家得到的结果 |
| --- | --- |
| **重启应用并回到原处** | 默认值。游戏重启，回到玩家所在的那一行，所有内容都换成新语言 |
| **重启应用，不保留当前进度** | 游戏像正常启动那样重启，停在标题画面。当前这局不保留，玩家的存档保留 |
| **下次启动时应用** | 当前会话什么都不变，界面文本也不变。下次启动游戏时使用新语言 |

## 翻译

翻译表将项目的源文本与各语言的译文并列显示，并给出每种语言的进度：已翻译的条目数，以及源文本变更后**待复查**的条目数

## 交换格式

翻译可以导出给外部译者，再导入回来

| 格式 | 常用工具 |
| --- | --- |
| CSV | Excel、Google 表格 |
| XLIFF 1.2 | Trados、memoQ、OmegaT |
| gettext PO | Poedit、Weblate、Crowdin |
| JSON | 脚本与自定义流程 |

导入完成后会报告结果：实际写入的条目、内容相同未变的条目、项目中没有对应键的条目，以及跳过的空条目
