**本地化**面板管理的是游戏本身的语言，与 Studio 界面显示的语言无关

其中一种语言是**源语言**，即故事的写作语言，其余语言都以它为基准翻译

## 语言

添加语言时填写语言代码（`en`、`ja`、`zh-CN`）和面向玩家显示的名称。列表中的任意语言都可以设为源语言

<Figure
    src="/static/img/docs/studio/zh/localization.webp"
    alt="本地化面板的语言部分，其中一种语言标记为源语言"
/>

移除语言会将其从游戏中去掉。它的翻译仍保留在磁盘上，重新添加该语言后会回来

每种语言都有**回退语言**。该语言下没有翻译的条目会回退到回退语言，再回退到源语言，因此翻译不完整的语言仍能正常显示。Studio 不接受会绕回自身的回退设置

## 游戏进行中切换语言 [#changing-language-during-a-game]

游戏通过 [`Set Language`](/zh/docs/studio/blueprint/nodes/localization#set-language) 节点切换语言，通常是在玩家打开的设置界面里。在标题画面切换时，新语言立即生效。玩家在游戏进行中切换语言时会发生什么，在**项目 → 游戏 → 语言**的**游戏进行中切换语言**中设定：

| 选项 | 玩家得到的结果 |
| --- | --- |
| **重启应用并回到原处** | 默认值。游戏重启，回到玩家所在的那一行，所有内容都换成新语言 |
| **重启应用，不保留当前进度** | 游戏像正常启动那样重启，停在标题画面。当前这局不保留，玩家的存档保留 |
| **下次启动时应用** | 当前会话什么都不变，界面文本也不变。下次启动游戏时使用新语言 |

## 翻译

翻译表将项目的源文本与各语言的译文并列显示，并给出每种语言的进度：已翻译的条目数，以及源文本变更后**待复查**的条目数

## 界面文本 [#interface-text]

页面上的每一处文字只有一个来源，在属性面板中文字上方选择：**直接输入**，即在控件上输入的文字；**翻译键**，即项目中某个翻译键的文字；**蓝图值**，即游戏运行时计算出的文字。**文本**的内容和**按钮**的文字三种都可以选，**文本输入框**的占位文本可以选前两种。文字只存一份，画布、游戏、翻译表、导出、项目检查与搜索读取的都是同一个来源

在翻译表的**范围**中选择**界面文本**即可翻译这些文字。各行先按页面和组件分组，再按插件分组，最后是**翻译键**

- **直接输入的文字**：项目有第二种语言时就会翻译。每个控件自身的文字在表中各占一行，仅由数字和符号组成的文字与示例文字除外。没有逐个控件的开关
- **翻译键**：多个控件共用的同一段文字，只翻译一次。用到它的控件都显示它的文字，与项目是否设置了源语言无关；项目中没有的键显示键名本身
- **移除翻译键**：用到该键的控件改为**直接输入**，保留该键的文字与译文。从别处粘贴或导入、使用了本项目没有的键的控件也一样
- **示例文字**：控件使用绑定（蓝图值、列表行的字段、组件的「界面文字」参数或页面的界面文字参数）时，控件自身的文字。只在编辑器中显示，不进入构建出的游戏，也不参与翻译
- **默认值**：游戏运行时由蓝图通过 `Set Text`、`Clear Text` 或 `Set Label` 写入文字的控件，属性面板把它自身的文字称为默认值。这些文字与其他文字一样进入构建并参与翻译，首次写入前游戏以玩家的语言显示它们。文字下方的**游戏中由以下蓝图写入**列出这些蓝图
- **蓝图写入的文字**：游戏运行时写入的文字按写入的内容显示，在所有语言中都优先于翻译键和蓝图值，直到页面重新打开
- **复制带译文**：复制或创建副本的控件如果文字来源为**直接输入**，会带上这些文字的译文；粘贴到另一个项目时同样带上，只写入该项目有的语言
- **新建控件的文字**使用项目的源语言
- **搜索**按源语言查找界面文本，点选结果会打开所在的页面或组件并选中该控件
- **插件**会把自己显示给玩家的文字交给翻译表，例如 [Menu Bar](/zh/docs/studio/blueprint/nodes/built-in-plugins) 的标签与 Gallery 的名称。它们按插件名列出，翻译之前游戏按原文显示

项目检查**缺少字形**会按控件每个状态的字体检查该控件；只有某个状态的字体缺字时，会写明是哪个状态

[组件](/zh/docs/studio/workspace/ui-editor#components)的「界面文字」参数按放置处翻译：放置处直接输入的文字各占一行

页面的文字[参数](/zh/docs/studio/workspace/ui-editor#page-params)在填写文字的位置翻译：默认值在该页面下占一行，无论有多少控件显示它；**页面**控件为它传入的文字在该控件下占一行。打开页面的节点传入的文字按原样显示；要以玩家的语言显示，用 `Translation Key Text` 为节点提供文字

### 早期版本的项目 [#projects-from-earlier-versions]

Studio 1.3.0 第一次打开早期版本建立的项目时，会把项目的界面文字升级到上述模型。如果这改变了某些控件文字的来源，Studio 会提示一次，列出这些控件，每个都带一个**定位**按钮，点击即选中该控件。此后，早期版本的 Studio 无法再打开该项目，见[升级到 1.3.0](/zh/docs/studio/installation#upgrading-to-1-3-0)

## 交换格式

翻译可以导出给外部译者，再导入回来

| 格式 | 常用工具 |
| --- | --- |
| CSV | Excel、Google 表格 |
| XLIFF 1.2 | Trados、memoQ、OmegaT |
| gettext PO | Poedit、Weblate、Crowdin |
| JSON | 脚本与自定义流程 |

导出的文件中，每个翻译键所在的行会把用到该键的页面与组件写作上下文

导入完成后会报告结果：实际写入的条目、内容相同未变的条目、项目中没有对应键的条目，以及跳过的空条目
