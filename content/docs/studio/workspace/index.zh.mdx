---
title: 工作区
description: 活动栏上的各个工具，以及它们各自管理的内容
---

工作区是编辑项目的地方。左侧活动栏的每一项在侧边栏中打开一个工具，它管理的内容以标签页的形式在中央打开。侧边栏、属性面板、底部面板和标签页等布局本身，参见[工作区概览](/zh/docs/studio/getting-started/workspace-overview)。

| 工具 | 管理的内容 |
| --- | --- |
| **项目** | 元数据、图标、依赖和项目设置 |
| **故事** | 故事、章节、场景，以及场景中的每一行 |
| **UI** | 页面、游戏 UI 和组件库 |
| **角色** | 角色、分组，以及角色的立绘或模型 |
| **素材** | 图片、音频、视频、数据、字体和模型 |
| **本地化** | 语言、翻译和审校状态 |

网络策略与资源保护这两项项目设置，参见[安全](/zh/docs/studio/security)。
