---
title: ワークスペース
description: アクティビティバー上の各ツールと、それぞれが管理するコンテンツ
---

ワークスペースはプロジェクトを編集する場所です。左側のアクティビティバーの各項目は、左サイドバーで 1 つのツールを開き、それが管理するコンテンツは中央にタブとして開きます。サイドバー、Properties パネル、ボトムバー、タブといったレイアウト自体については、[ワークスペースの概要](/ja/docs/studio/getting-started/workspace-overview) を参照してください。

<Figure
    src="/static/img/docs/studio/en/workspace-overview.webp"
    alt="左端に並ぶアクティビティバー。Story ツールが開き、その横にエディタのタブがある"
/>

| ツール | 管理する内容 |
| --- | --- |
| **Project**（プロジェクト） | メタデータ、アイコン、依存関係、プロジェクト設定 |
| **Story**（ストーリー） | ストーリー、チャプター、シーン、その中の台詞 |
| **UI** | ページ、ゲーム UI、コンポーネントライブラリ |
| **Characters**（キャラクター） | キャラクター、そのグループ、スプライトやモデル |
| **Assets**（アセット） | 画像、音声、動画、データ、フォント、モデル |
| **Localization**（ローカライゼーション） | 言語、翻訳、レビュー状態 |

ネットワークポリシーとアセット保護という 2 つのプロジェクト設定については、[セキュリティ](/ja/docs/studio/security) で説明しています。
