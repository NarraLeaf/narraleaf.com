**故事**面板存放剧本。一个项目可以包含多个故事，其中一个是默认故事；每个故事都有一个入口场景

## 结构

| 层级 | 内容 |
| --- | --- |
| 故事 | 章节。项目中有一个故事为默认故事 |
| 章节 | 按顺序排列的场景 |
| 场景 | 实际播放的行。其中一个场景是故事的入口 |

删除场景会一并删除其中的行，跳转到该场景的指令将无法解析。删除章节会删除其中的全部场景

## 场景编辑器

场景以标签页打开，内容按行编辑。一行要么是一句对话，要么是一条演出指令——显示图片、播放音频、移动镜头、设置变量、分支等

- 在行内输入 `@` 或 `/` 可直接插入演出指令，无需离开键盘
- **阅读密度**和行筛选决定一屏显示多少内容，筛选可以只显示对话
- **在场景中查找**在当前场景内搜索，支持区分大小写、全词匹配和正则表达式，并可替换匹配项
- 引用了缺失素材，或使用了角色模型中不存在的名称的行，会就地标出

## 分支与变量

选项、条件和跳转都作为演出指令写在场景中。故事流程图以图的形式显示场景之间的分支

变量在故事中声明和读取，其作用域决定值能保留多久，参见[变量](/zh/docs/studio/blueprint/variables)

## 剧本文件

单个场景或整个故事都可以导出为纯文本文件，并可再导入回来

| 模式 | 用途 |
| --- | --- |
| **往返** | 在 Studio 之外编辑。文件携带场景数据，可以再导入 |
| **审阅** | 阅读与比对。只含正文，无法导入 |

**导入剧本…**把往返模式的文件读回项目。将多行纯文本粘贴到场景中时，Studio 会提示按行拆分
