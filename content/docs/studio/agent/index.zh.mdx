---
title: Agent 接入
description: 通过 MCP 让 AI Agent 编辑 Studio 中打开的项目，每一处修改都实时呈现
---

Studio 可以在本机提供 MCP（Model Context Protocol）端点。支持 MCP 的 Agent 由此可以编辑 Studio 中打开的项目，包括 Claude Code、Claude Desktop、opencode、Codex、Cursor、Gemini CLI 等

Agent 的修改与手动编辑经过同一套服务：落地时即显示在画布上，由同一套自动保存写入磁盘，每次修改项目的调用记为一步撤销。作者可以随时暂停 Agent、撤销它的修改，或与它同时编辑

<Callout type="info">
Agent 接入需要 1.4.5 之后发布的 Studio 版本。Agent 工作期间 Studio 必须处于运行状态：端点是 Studio 的一部分，只有 Studio 运行时 Agent 才能连接
</Callout>

## Agent 能做什么

| 范围 | 工具涵盖的内容 |
| --- | --- |
| 项目 | 用骨架或空白模板新建项目、打开项目，修改名称、设计分辨率和游戏语言 |
| 资产 | 导入图片、音频、视频和字体，生成带说明文字的占位图，删除未被使用的资产，列出音轨 |
| 角色与变量 | 新建、更新和删除角色，设置图片姿态与登场位置；声明、重命名和删除全局变量 |
| 故事 | 以 `.story` 文本读写整个场景；新建、重命名和删除场景；设置入口场景；重命名故事 |
| 界面 | 以 `.ui` 文本读写页面、游戏 UI 和组件，对元素做小修改，应用界面模板，设置配色与字体，截取页面或单个控件在悬停、按下状态下的图像，读取作者当前的选择 |
| 蓝图 | 以 `.bp` 文本读写蓝图 |
| 检查与构建 | 运行项目检查和内置测试，在开发模式中逐行试玩，读取控制台，为当前系统、Windows、macOS、Linux 或 Web 构建 |

全部工具见[工具](/zh/docs/studio/agent/tools)

## Agent 不能做什么

- 编辑由插件管理的数据，例如 [Gallery](/zh/docs/studio/blueprint/nodes/built-in-plugins/gallery) 插件的画廊条目
- 编辑译文。可以增删游戏提供的语言，译文本身在[本地化](/zh/docs/studio/workspace/localization)中编辑
- 设置语音表、分层立绘、Live2D 或 Spine 模型。角色的姿态是单张图片资产，导入仅限图片、音频、视频和字体
- 修改音频总线。只能列出音轨
- 设置项目图标、签名凭据或其他构建设置，也不能构建 Android 或 iOS 版本
- 删除页面。游戏不需要的部分会被隐藏
- 在运行中的游戏里按下按钮。控件的各种状态通过截图检查
- 直接写入项目目录中的文件。所有修改都经由工具完成，作者可以看到并撤销

## 两个组成部分

**MCP 服务器**内置于 Studio，在作者开启之前不会运行。它为 Agent 提供工具

**`narraleaf-make-game` Skill** 是 Agent 遵循的指南：工作顺序、要写的文本格式、界面设计规则以及需要避开的陷阱。Studio 可以将它导出为文件夹。对于无法加载 Skill 的 Agent，服务器也会提供同一份指南
