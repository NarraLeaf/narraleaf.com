---
title: エージェント連携
description: MCP を通じて AI エージェントに Studio で開いているプロジェクトを編集させ、その変更をすべてその場で確認する
---

Studio は、自分のコンピューター上で MCP（Model Context Protocol）のエンドポイントを提供できます。MCP に対応したエージェントは、これを通じて Studio で開いているプロジェクトを編集できます。Claude Code、Claude Desktop、opencode、Codex、Cursor、Gemini CLI などが対応しています。

エージェントの変更は、手作業の編集と同じサービスを通ります。反映された時点でキャンバスに表示され、同じ自動保存で保存され、プロジェクトを変更する呼び出しは 1 回ごとに 1 ステップの取り消しになります。エージェントはいつでも一時停止でき、その変更を取り消すことも、並行して編集することもできます。

<Callout type="info">
エージェント連携には、1.4.5 より後にリリースされた Studio が必要です。エージェントが作業する間は Studio が起動している必要があります。エンドポイントは Studio の一部であり、Studio が動いているときにしか接続できません。
</Callout>

## エージェントにできること

| 範囲 | ツールが扱う内容 |
| --- | --- |
| プロジェクト | スケルトンまたは空のテンプレートからのプロジェクト作成、既存プロジェクトを開く、名前・デザイン解像度・ゲームの言語の変更 |
| アセット | 画像、音声、動画、フォントの読み込み、キャプション付きの仮画像の作成、使われていないアセットの削除、オーディオトラックの一覧 |
| キャラクターと変数 | 画像のポーズと登場位置を持つキャラクターの作成・更新・削除、グローバル変数の宣言・名前変更・削除 |
| ストーリー | シーン全体の `.story` テキストでの読み書き、シーンの作成・名前変更・削除、開始シーンの設定、ストーリーの名前変更 |
| インターフェース | ページ、ゲーム UI、コンポーネントの `.ui` テキストでの読み書き、要素の小さな編集、インターフェーステンプレートの適用、配色とフォントの設定、ページや個々のコントロールのホバー・押下状態のスクリーンショット、作者の選択の読み取り |
| ブループリント | ブループリントの `.bp` テキストでの読み書き |
| チェックとビルド | プロジェクトのチェックと組み込みテストの実行、Dev Mode での 1 行ずつのテストプレイ、コンソールの読み取り、現在のシステム・Windows・macOS・Linux・Web 向けのビルド |

ツールの一覧は[ツール](/ja/docs/studio/agent/tools)にあります。

## エージェントにできないこと

- プラグインが管理するデータの編集。たとえば [Gallery](/ja/docs/studio/blueprint/nodes/built-in-plugins/gallery) プラグインの項目。
- 翻訳の編集。ゲームが提供する言語の追加と削除はできますが、翻訳文そのものは[ローカライズ](/ja/docs/studio/workspace/localization)で編集します。
- ボイステーブル、レイヤー立ち絵、Live2D や Spine のモデルの設定。キャラクターのポーズは 1 枚の画像アセットで、読み込めるのは画像、音声、動画、フォントに限られます。
- オーディオバスの変更。オーディオトラックの一覧を見ることだけができます。
- プロジェクトのアイコン、署名の認証情報、その他のビルド設定の変更、Android と iOS 向けのビルド。
- ページの削除。ゲームに不要な部分は非表示にします。
- 実行中のゲームでボタンを押すこと。コントロールの状態はスクリーンショットで確認します。
- プロジェクトフォルダー内のファイルへの直接の書き込み。変更はすべてツールを通るので、作者はそれを見て取り消せます。

## 2 つの構成要素

**MCP サーバー**は Studio に組み込まれており、作者がオンにするまで動きません。エージェントにツールを提供します。

**`narraleaf-make-game` スキル**は、エージェントが従うガイドです。作業の順序、書くテキストの形式、インターフェースのデザインの決まり、避けるべき落とし穴が書かれています。Studio はこれをフォルダーとして書き出せます。スキルを読み込めないエージェントには、サーバーが同じガイドを提供します。
