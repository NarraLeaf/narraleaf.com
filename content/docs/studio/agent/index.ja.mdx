---
title: エージェント連携
description: MCP を通じて AI エージェントに Studio で開いているプロジェクトを編集させ、その変更をすべてその場で確認する
---

Studio は、自分のコンピューター上で MCP（Model Context Protocol）のエンドポイントを提供できます。MCP に対応したエージェントは、これを通じて Studio で開いているプロジェクトを編集できます。Claude Code、Claude Desktop、opencode、Codex、Cursor、Gemini CLI などが対応しています。

エージェントの変更は、手作業の編集と同じサービスを通ります。反映された時点でキャンバスに表示され、同じ自動保存で保存され、プロジェクトを変更する呼び出しは 1 回ごとに 1 ステップの取り消しになります。エージェントはいつでも一時停止でき、その変更を取り消すことも、並行して編集することもできます。

<Callout type="info">
エージェント連携には Studio 1.5.0 以降が必要です。エージェントが作業する間は Studio が起動している必要があります。エンドポイントは Studio の一部であり、Studio が動いているときにしか接続できません。
</Callout>

## エージェントにできること

| 範囲 | ツールが扱う内容 |
| --- | --- |
| プロジェクト | スケルトンまたは空のテンプレートからのプロジェクト作成、既存プロジェクトを開く、名前・デザイン解像度・ゲームの言語・プレイヤーの初期値の変更 |
| アセット | 画像、音声、動画、フォントの読み込み、キャプション付きの仮画像の作成、アセットの使用箇所の確認と使われていないアセットの削除、オーディオトラックの一覧、プロジェクト外のフォルダーの読み取りの要求 |
| キャラクターと変数 | 画像のポーズ、ダイアログのアバター、登場位置を持つキャラクターの作成・更新・削除、レイヤーとタグで名付けた画像や PSD からのレイヤー立ち絵の構成と見た目のプレビュー、グローバル変数の宣言・名前変更・削除 |
| ストーリー | シーン全体の `.story` テキストでの読み書き、シーンの作成・名前変更・削除、チャプターの名前変更・削除、開始シーンの設定、ストーリーの名前変更 |
| インターフェース | ページ、ゲーム UI、コンポーネントの `.ui` テキストでの読み書き、要素の小さな編集、空のテンプレートから作ったプロジェクトへの動作する標準画面の導入、ページの名前変更・削除と開始ページの設定、インターフェーステンプレートの適用、配色とフォントの設定、ページや個々のコントロールのホバー・押下状態のスクリーンショット、作者の選択の読み取り |
| ブループリント | ブループリントの `.bp` テキストでの読み書き、残ったブループリントの削除、ストーリーの行からの実行 |
| 翻訳とボイス | ストーリーのセリフ、名前、インターフェースのテキスト、名前付きキー、プラグインのテキストをゲームの各言語に翻訳する。翻訳は**機械翻訳**として記録され、作者の確認を待つ。ボイスの言語と収録ファイル名のパターンを設定し、収録音声を名前でまとめて、または 1 つずつセリフにリンクする |
| プラグイン | プロジェクトで読み込まれたプラグインのツールが提供する操作。組み込みの [Gallery](/ja/docs/studio/blueprint/nodes/built-in-plugins/gallery) プラグインのツールは、CG、回想、音楽、ボイスで鑑賞画面を埋める |
| チェックとビルド | プロジェクトのチェックと組み込みテストの実行、Dev Mode での 1 行ずつのテストプレイとその中でのクリック・ポインター操作・キー入力、コンソールの読み取り、現在のシステム・Windows・macOS・Linux・Web 向けのビルド |

ツールの一覧は[ツール](/ja/docs/studio/agent/tools)にあります。

## エージェントにできないこと

- プラグインが管理するデータの編集。ただし、プラグインがそのデータ用のエージェントツールを提供している場合は別です。[プラグインのツール](/ja/docs/studio/agent/tools#plugin-tools)を参照してください。
- Live2D や Spine のキャラクターの設定。モデルとそのランタイムは[キャラクターエディタ](/ja/docs/studio/workspace/character-manager)で設定します。エージェントは、それを動かすストーリーの行を書きます。
- オーディオバスの変更。オーディオトラックの一覧を見ることだけができます。
- プロジェクトのアイコン、署名の認証情報、その他のビルド設定の変更、Android と iOS 向けのビルド。
- プロジェクトフォルダー内のファイルへの直接の書き込み。変更はすべてツールを通るので、作者はそれを見て取り消せます。
- Studio 自身のフォルダー、ホームフォルダー全体、ドライブのルートの読み取り。フルアクセスがオンでも同じです。[プロジェクト外のフォルダー](/ja/docs/studio/agent/security#folders)を参照してください。

## 2 つの構成要素

**MCP サーバー**は Studio に組み込まれており、作者がオンにするまで動きません。エージェントにツールを提供します。

**`narraleaf-make-game` スキル**は、エージェントが従うガイドです。作業の順序、書くテキストの形式、インターフェースのデザインの決まり、避けるべき落とし穴が書かれています。Studio はこれをフォルダーとして書き出せます。スキルを読み込めないエージェントには、サーバーが同じガイドを提供します。

ソースのある Ren'Py のゲームを移植するには、もう 1 つのスキル **`narraleaf-port-renpy`** が必要です。これは **Ren2Leaf** ウィザードとともに [MewBaka/Ren2Leaf](https://github.com/MewBaka/Ren2Leaf) で公開されています。Studio が書き出すフォルダーにも 1 部入っていますが、リポジトリのものより古いことがあります。[Ren'Py のゲームを移植する](/ja/docs/studio/agent/make-a-game#renpy)を参照してください。
