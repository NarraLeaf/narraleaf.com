## Agent 无法连接

先查看**设置 → Agent 接入**。端点提供服务时 **地址** 下显示**运行中**，关闭时显示**未运行**，启动失败时显示 **无法启动：** 及原因

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| Agent 没有 NarraLeaf 的工具 | Studio 未运行，或 **允许 Agent 连接** 未打开 | 打开 Studio 并开启该开关，然后重启 Agent 或重新连接 |
| 连接被拒绝 | 端口已更改，或所设端口被占用、Studio 改用了其他端口 | 对照 **地址** 中的端口检查 Agent 的配置，重新复制配置并重启 Agent |
| Agent 报告令牌缺失或错误 | 令牌已重新生成，或配置是手工输入的 | 重新复制配置 |
| Agent 报告不接受来自网页的请求 | 客户端像浏览器一样发送了 `Origin` 请求头 | 改用在本机作为独立程序运行的客户端 |
| 客户端始终连不上，或以 HTTP 405 失败 | 客户端配置为旧的 HTTP+SSE 传输方式 | 改为 Streamable HTTP |
| Claude Code 只在某一个文件夹中有这些工具 | 添加服务器时没有加 `--scope user` | 在该文件夹中运行 `claude mcp remove narraleaf -s local`，再运行**复制配置 → Claude Code** 给出的命令 |
| Claude Desktop 提示 Agent 接入已关闭 | stdio 桥接程序已连上 Studio，但 **允许 Agent 连接** 未打开 | 打开该开关即可，桥接程序无需重启 |
| Claude Desktop 等待后提示 Studio 未运行或未能及时启动 | Studio 在一分钟内没有开始提供服务，或桥接程序带有 `--user-data-dir` 参数，此时它只连接、不启动 Studio | 打开 Studio，检查**设置 → Agent 接入**，然后重新连接 |
| Agent 操作了错误的项目 | 同时打开了多个项目 | 让 Agent 指明项目目录，或关闭其他项目 |

## Agent 看不到某个插件的工具

插件的工具只在加载了该插件的项目处于打开状态时存在。`agent_status` 会列出每个已打开项目提供的插件工具

| 原因 | 处理 |
| --- | --- |
| 客户端在插件加载之前获取了工具列表，并沿用旧列表 | 让 Agent 重新获取工具列表，或重新连接。保持 Studio 通知流打开的客户端会在列表变化时收到通知，其他客户端在下次获取列表时看到变化 |
| 使用该插件的项目没有打开 | 打开该项目。已关闭项目中插件的工具不会提供 |
| 该插件在项目中未启用，或加载失败 | 在项目中启用它，并在控制台中查看加载错误 |
| 该插件的工具已被关闭 | 在**设置 → Agent 接入 → 插件工具**中重新打开。调用已关闭的工具会以 `unavailable` 被拒绝 |
| 打开了多个项目，调用落到了没有加载该插件的项目 | 拒绝代码为 `unknown_tool`，消息中列出提供该工具的项目，让 Agent 指明其中一个 |

## 拒绝代码

Studio 拒绝一次调用时，Agent 会收到一个代码、一条消息，通常还有下一步建议；**Agent 日志** 中对应的行显示该代码的名称。指南已告诉 Agent 遇到每个代码该怎么做，下表说明作者需要做什么

| 代码 | Agent 日志显示 | 含义 | 作者的处理 |
| --- | --- | --- | --- |
| `writes_disabled` | **未允许修改** | **允许 Agent 修改工程** 未打开 | 需要 Agent 编辑时打开它，读取不受影响 |
| `paused` | **已暂停** | 作者在本项目中暂停了 Agent | 可以继续时选择 **继续 Agent** |
| `frozen` | **工程已冻结** | 项目暂不接受修改：正在查看历史版本、被手动冻结、合并未完成、Studio 处于恢复模式，或项目已被另一个窗口接管 | 完成或退出该状态，Agent 会重试 |
| `live_session` | **实时会话进行中** | 项目中正在进行 Team 实时会话 | 退出会话，或让 Agent 在会话结束前只读工作 |
| `stale_revision` | **内容已变更** | Agent 读取之后页面或场景发生了变化，通常是作者编辑了它 | 无需处理，Agent 会重新读取，并在作者的版本上重做修改 |
| `check_failed` | **检查未通过** | Agent 提交的文本无法编译，或检查发现了错误，没有写入任何内容 | 除非反复出现，否则无需处理，Agent 会修正问题后重新写入 |
| `not_found` | **未找到** | 调用中指定的场景、页面、元素、资产或角色不存在 | 除非反复出现，否则无需处理，Agent 会列出现有内容后重试 |
| `path_not_allowed` | **目录未授权** | 导入的文件位于项目目录和允许的文件夹之外 | 把该文件夹添加到 **允许导入素材的文件夹**，或把文件复制到项目目录中 |
| `untrusted` | **工程未受信任** | 项目未受信任，不能试玩、测试或构建 | 确认来源可信后，点击状态栏中的 **未受信任** 信任该项目 |
| `no_workspace` | **没有打开的工程** | 没有打开的项目，或打开了多个项目而调用没有指明是哪一个 | 打开项目，或让 Agent 指明项目目录 |
| `invalid_args` | **参数无效** | 参数不符合该工具的要求 | 无需处理，Agent 会修正调用 |
| `unknown_tool` | **未知工具** | 没有该名称的工具 | 无需处理，Agent 会重新获取工具列表 |
| `unavailable` | **无法执行** | 调用本身有效，但在当前状态下无法执行，例如推进一个并未运行的游戏、项目窗口没有及时响应，或调用了已被关闭的插件工具 | 查看 **Agent 日志** 中的消息，其中说明了缺少什么 |
| `internal` | **内部错误** | Studio 内部出错，并非 Agent 的问题 | 如果反复出现，查看控制台中的错误并反馈 |

对于 Agent 无法自行处理的代码，例如 `writes_disabled`、`paused` 或 `path_not_allowed`，它会停下来询问作者
