NarraLeaf Studio は、ビジュアルノベルを制作するためのデスクトップエディタです。1 つのプロジェクトには 1 本のゲームのストーリー、キャラクター、アセット、インターフェース、リリース設定が保存されており、Studio はそのすべてを編集します。

    alt="Studio のワークスペース。アクティビティバー、Story パネル、開いたシーン、Properties パネル"
/>

<Callout type="warning">
Studio は早期開発段階にあります。インターフェース名やプロジェクト形式はリリースごとに変更される可能性があります。プロジェクトはバージョン管理下に置くか、別途バックアップを保管してください。
</Callout>

## プロジェクトに含まれるもの

| 内容 | ツール |
| --- | --- |
| ストーリー、チャプター、シーン、アクション | Story |
| キャラクター、フォーム、バリアント | Characters |
| 画像、音声、その他のファイル | Assets |
| タイトル、設定、セーブ、履歴、ギャラリーなどのページ | UI |
| ダイアログ、選択肢、通知、NVL などのゲーム UI | UI |
| ページ、ウィジェット、ゲーム UI の動作を定義するブループリント | UI |
| 原文テキスト、翻訳、レビュー状態 | Localization |
| メタデータ、アイコン、依存関係、プロジェクト設定 | Project |

これらはすべてプロジェクトディレクトリに書き込まれます。移動、バックアップ、コミットは、このディレクトリ全体を単位として行ってください。

## ページとゲーム UI

どちらも UI エディタで作成しますが、対象とする範囲が異なります。

| 種類 | 内容 | サイズ |
| --- | --- | --- |
| ページ | タイトル、設定、セーブなどの完全な画面 | ページ作成時に指定 |
| ゲーム UI | ダイアログ、選択肢、通知、NVL などのステージ上のコンテンツ | プロジェクトのステージサイズ |

ゲーム UI はスロットにマウントされます。1 つのプロジェクトにおいて、各スロットで有効なインターフェースは 1 つです。

## 編集と実行

キャンバスにはレイアウトが表示されます。**Dev Mode**（開発モード）はプロジェクトを実際のランタイムで実行するもので、インタラクション、ブループリントの実行、セーブデータの動作はここで確認します。**Production Build…**（プロダクションビルド）はプレイヤーに配布するファイルを生成します。
