title: 介绍 Studio
description: NarraLeaf 项目包含哪些内容，各由哪个工具编辑
---

NarraLeaf Studio 是用于制作视觉小说的桌面编辑器。一个项目保存一部作品的故事、角色、素材、界面和发行设置，这些内容都在 Studio 中编辑

    alt="Studio 工作区：活动栏、故事面板、打开的场景和属性面板"
/>

<Callout type="warning">
Studio 仍处于早期开发阶段。界面名称和项目格式可能随版本调整。重要项目应使用版本控制或保留独立备份
</Callout>

## 项目包含的内容

| 内容 | 工具 |
| --- | --- |
| 故事、章节、场景和动作 | 故事 |
| 角色、形态和差分 | 角色 |
| 图片、音频及其他文件 | 素材 |
| 标题、设置、存档、历史、画廊等页面 | UI |
| 对话、选项、通知、NVL 等游戏 UI | UI |
| 页面、控件和游戏 UI 的行为蓝图 | UI |
| 源语言文本、翻译和审校状态 | 本地化 |
| 元数据、图标、依赖和项目设置 | 项目 |

这些内容全部写入项目目录。移动、备份和提交时都应把该目录作为一个整体

## 页面与游戏 UI

两者都在 UI 编辑器中制作，区别在于覆盖的范围

| 类型 | 内容 | 尺寸 |
| --- | --- | --- |
| 页面 | 标题、设置、存档等完整界面 | 创建页面时指定 |
| 游戏 UI | 对话、选项、通知、NVL 及其他舞台内容 | 项目的舞台尺寸 |

游戏 UI 按位置挂载，同一项目中每个位置只有一个活动界面

## 编辑与运行

画布用于排版。**开发模式** 在实际运行环境中运行项目，交互、蓝图执行和存档状态在这里检查。**正式构建…** 生成交付给玩家的文件
